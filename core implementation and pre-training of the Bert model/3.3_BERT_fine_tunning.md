BERT_fine_tunning.py代码实现了一个使用 PyTorch 和 Hugging Face `transformers` 库对 BERT 模型进行下游文本分类任务微调（Fine-tuning）的完整端到端流程。

代码涵盖了从自定义数据集、数据加载、模型初始化、优化器配置，到训练循环（Training Loop）和验证评估（Evaluation）的标准工程实践。

以下是对该代码各个核心模块的详细拆解：

---

### 1. 自定义数据集类 (`TextDataset`)

这是 PyTorch 标准的数据处理管道，继承自 `torch.utils.data.Dataset`。

* **`__init__`**：接收原始文本、标签、分词器（Tokenizer）以及最大序列长度（`max_length`）。
* **`__getitem__`**：当获取某个样本时，使用 `tokenizer` 对文本进行编码：
* `add_special_tokens=True`：自动添加 BERT 所需的特殊标记（如句首的 `[CLS]` 和句尾的 `[SEP]`）。
* `padding="max_length"` 与 `truncation=True`：将所有句子统一截断或填充到固定的 `max_length`（这里是 32），确保批次中的张量形状一致。
* 返回字典包含：`input_ids`（词 ID 序列）、`attention_mask`（注意力掩码，区分真实词和填充的 `<pad>`）以及 `label`（分类标签）。



---

### 2. 数据集加载与拆分

```python
# 数据集加载
texts = ["Example sentence 1", "Example sentence 2", "Example sentence 3"]
labels = [0, 1, 0]  # 示例标签
...

```

* 使用 `random_split` 将数据集按 8:2 的比例随机划分为训练集和验证集。
* 使用 `DataLoader` 将数据集包装成批次（`batch_size=2`），并在训练集上开启 `shuffle=True` 以打乱数据顺序防止模型过拟合。

---

### 3. 模型初始化 (`BertForSequenceClassification`)

```python
model = BertForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)

```

* **`BertForSequenceClassification`**：这是 Hugging Face 提供的用于分类任务的预置类。它在基础的 BERT 编码器顶部自动拼接了一个线性分类头（Linear Classification Head）。
* **`num_labels=2`**：代表这是一个**二分类任务**（例如情感分析的正向/负向分类）。

---

### 4. 优化器与损失函数

* **`optim.AdamW`**：Transformer 模型微调的标准优化器。它修正了传统 Adam 优化器在权重衰减（Weight Decay）上的缺陷，能带来更好的泛化性能。学习率设为了 `2e-5`（这是微调 BERT 的经典安全学习率）。
* **`nn.CrossEntropyLoss`**：交叉熵损失函数，适用于多分类或二分类的概率输出。

---

### 5. 训练函数 (`train_epoch`)

该函数负责模型在一个 Epoch 内的参数更新：

1. **`model.train()`**：将模型切换至训练模式（启用 Dropout 和 LayerNorm 的训练特性）。
2. **前向传播**：将 `input_ids` 和 `attention_mask` 送入模型，通过 `outputs.logits` 获取分类预测得分。
3. **计算损失与准确率**：通过交叉熵计算 Loss，并用 `torch.max` 统计当前批次的预测正确数量。
4. **反向传播与优化（Standard PyTorch Pattern）**：
* `optimizer.zero_grad()`：清空上一轮的梯度缓存。
* `loss.backward()`：计算当前批次的梯度。
* `optimizer.step()`：根据梯度更新模型权重。



---

### 6. 验证函数 (`eval_model`)

该函数负责评估模型在验证集上的表现：

1. **`model.eval()`**：切换至评估模式（关闭 Dropout 等随机性操作）。
2. **`torch.no_grad()`**：关闭梯度计算。在验证阶段不需要反向传播，这能大幅节省显存并加快计算速度。
3. 统计并返回验证集上的平均 Loss 和整体准确率（Accuracy）。

---

### 7. 主训练循环 (`Epochs Loop`)

* 设定训练轮数 `epochs = 3`。
* 在每个 Epoch 中，依次调用 `train_epoch` 进行学习，并调用 `eval_model` 观察模型在验证集上的泛化能力，最后将各项指标实时打印出来，方便监控训练状态。
