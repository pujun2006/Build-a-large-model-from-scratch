BERT_Encoding_stack.py这段代码是一个用 PyTorch 实现的 **BERT 编码器核心结构**（对应经典的 `BERT-Base` 配置）。它包含了多头自注意力机制（Multi-Head Self-Attention）、前馈神经网络（Feed-Forward Network）、Transformer 编码器块的堆叠。

下面为您逐模块详细拆解这段代码的实现原理和技术细节：

---

### 1. 多头自注意力机制 (`SelfAttention`)

这是 Transformer 的核心，能够让模型在处理某个词时同时关注句子中其他所有词（双向上下文）。

* **初始化 (`__init__`)**：
* `embed_size`: 词向量的维度（在 `BERT-Base` 中为 768）。
* `heads`: 注意力头的数量（在 `BERT-Base` 中为 12）。每个头的维度 `head_dim = 768 / 12 = 64`。
* 定义了四个线性层：`values`, `keys`, `queries` 用于生成 $V, K, Q$ 矩阵；`fc_out` 用于将多头拼接后的结果投影回原维度。


* **前向传播 (`forward`)**：
1. **线性变换**：将输入的 `values`, `keys`, `query` 通过线性层映射。
2. **多头切分与维度转置**：将形状从 `[N, Seq_Len, embed_size]` 转换为 `[N, heads, Seq_Len, head_dim]`。这一步把大维度拆成了多个独立的小维度，让不同的头关注不同的特征（如语法、语义等）。
3. **缩放点积注意力（Scaled Dot-Product Attention）**：

$$\text{Energy} = \frac{Q K^T}{\sqrt{d_k}}$$



通过计算 Query 和 Key 的相似度得到权重，并除以 $\sqrt{d_k}$（即 `head_dim ** 0.5`）以防止梯度消失。
4. **Mask 掩码处理**：如果传入了 `mask`，则将不需要注意力的位置（如填充的 `<pad>` 词）的值设为一个极小负数（`-1e20`），这样在经过 Softmax 后其权重会趋近于 0。
5. **Softmax 与加权求和**：通过 `softmax` 归一化注意力权重，再与 `Values` 相乘，得到加权后的特征。
6. **多头拼接与输出**：将多个头的输出拼接（通过 `transpose` 和 `view`）恢复为 `[N, Seq_Len, embed_size]`，最后通过 `fc_out` 输出。



---

### 2. 前馈神经网络 (`FeedForward`)

在自注意力机制对各个词之间的关系进行建模后，每个位置的向量会通过一个前馈神经网络进行更深层的非线性特征变换。

* **结构**：包含两个线性层和一个激活函数。
* 第一个线性层将维度从 `embed_size` 扩展到 `forward_expansion * embed_size`（在 BERT 中通常是 $4 \times 768 = 3072$）。
* 使用 **GELU（Gaussian Error Linear Unit）** 激活函数（这是 BERT 区别于早期标准 Transformer 使用 ReLU 的一个重要细节，能够带来更好的平滑性和性能）。
* 第二个线性层将维度缩减回 `embed_size`。



---

### 3. Transformer 编码器块 (`TransformerBlock`)

这一模块组合了自注意力和前馈网络，并引入了 **Post-LN（Post Layer Normalization）** 架构和残差连接（Residual Connection）。

* **前向传播流程**：
1. **自注意力子层**：输入 `x` 计算自注意力，经过 Dropout 后与原输入 `x` 相加（残差连接），然后进行 `LayerNorm`（`norm1`）。
2. **前馈网络子层**：将上一步的输出送入 `FeedForward`，同样经过 Dropout、残差连接和第二次 `LayerNorm`（`norm2`）。


* **残差连接的作用**：缓解深层网络中的梯度消失问题，让梯度能够直接反向传播到浅层。

---

### 4. BERT 编码器堆叠 (`BERTEncoder`)

* **结构**：通过 `nn.ModuleList` 将多个 `TransformerBlock` 串联起来（在 `BERT-Base` 中是 12 层，`BERT-Large` 是 24 层）。
* **前向传播**：输入数据和掩码依次穿过每一层 Transformer 块，最终输出包含全双向上下文信息的深层语义表示。

---

### 5. 模拟运行与参数对应 (`BERT-Base`)

代码末尾的模拟运行配置完全复刻了 **`BERT-Base`** 的标准超参数：

* `embed_size = 768` （隐藏层维度）
* `heads = 12` （注意力头数）
* `forward_expansion = 4` （FFN 隐层扩展倍数，即 $768 \times 4 = 3072$）
* `num_layers = 12` （Transformer 块堆叠层数）
* `seq_length = 20` （输入序列长度）
* `batch_size = 2` （批大小）

运行后输出的形状为 `[2, 20, 768]`，这代表模型成功为批次中的每句话（共 2 个样本，每个样本 20 个 Token）输出了每个 Token 长度为 768 维的高维双向语义向量。
