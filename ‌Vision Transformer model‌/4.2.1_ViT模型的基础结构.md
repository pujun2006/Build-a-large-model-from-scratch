**Vision Transformer (ViT)** 是谷歌团队在经典论文《An Image is Worth 16x16 Words》中提出的将 Transformer 架构直接引入计算机视觉领域的开创性模型。它彻底打破了传统卷积神经网络（CNN）对图像处理的统治地位，证明了纯基于自注意力机制（Self-Attention）的架构同样具备极强的图像表征与泛化能力。

ViT 的基础结构主要由以下 **四大核心模块** 组成：

---

### 1. 图像分块与线性投影（Patch Embedding）

Transformer 的标准输入是一维的 Token 序列（形如 B, seq_len, embed_size），而图像是二维像素矩阵。因此，ViT 需要将图像转换为类似文本的序列：

* **图像切块（Patches）**：将输入图像（尺寸为 H * W * C）切分成多个大小为 P * P 的不重叠 Patch。切分后的 Patch 总数量为：

<img width="396" height="84" alt="ccd645ce-7028-4341-8821-94f5a34c9616" src="https://github.com/user-attachments/assets/b11e01a0-442b-4e1a-89ff-b9b384f99338" />




*(例如：对于 224 * 224 的图像，当 P = 16 时，会得到 14 * 14 = 196 个 Patch)*
* **线性投影（Linear Projection / Conv2d）**：
* 将每个二维 Patch 展平并映射到一个固定的高维向量空间，维度大小为 embed_size（如 768）。
* 在代码实现中，这通常可以通过一个卷积核大小和步长均等于 P 的二维卷积层（`nn.Conv2d`）高效完成，输出形状变为 [B, embed_size, H/P, W/P]，随后展平并转置为 [B, num_patches, embed_size]。



---

### 2. 附加类别标记与位置编码（CLS Token & Position Embedding）

为了让 Transformer 能够处理图像序列并感知空间位置：

* **`[CLS]` Token（类别标记）**：
* 仿照 BERT 模型，ViT 在所有图像 Patch 序列的最前方拼接了一个可学习的向量，称为 `[CLS]` Token（形状为 [1, 1, embed_size]）。
* 经过多层 Transformer 交互后，这个 Token 最终会聚合整张图像的全局语义信息，专门用于最后的分类决策。此时序列总长度变为 num_patches + 1。


* **位置编码（Position Embeddings）**：
* 因为 Transformer 本身对序列顺序不敏感（具有排列不变性），所以必须加入可学习的一维位置编码（形状为 [1, num_patches + 1, embed_size]）。
* 位置编码与 Patch 嵌入直接相加，使模型能够感知每个 Patch 在图像中的相对空间位置。



---

### 3. Transformer 编码器块（Transformer Encoder）

编码器由多个相同的 Transformer 块堆叠而成（通常堆叠 6 层、12 层甚至更多）。每个块内部主要包含以下核心组件：

* **层归一化（Layer Normalization, LN）**：
* 现代 ViT 普遍采用 **Pre-LN** 结构，即在进行自注意力和前馈网络计算**之前**先对数据进行归一化，这能使深层网络训练更加稳定。


* **多头自注意力机制（Multi-Head Self-Attention, MSA）**：
* 允许图像中的每一个 Patch 与其他所有 Patch（包括 `[CLS]` Token）进行信息交互。
* 多头机制让模型能够同时从不同的表征子空间中捕获图像的不同局部与全局特征。


* **残差连接（Residual Connections）**：
* 在自注意力和前馈网络前后均设有残差连接（x = x + SubLayer(x)），有效缓解了深层网络的梯度消失问题。


* **多层感知机 / 前馈网络（MLP / Feed-Forward Network）**：
* 包含两层线性变换，中间使用非线性激活函数（ViT 原论文指定使用 **GELU**），用于对特征进行更深层次的非线性变换。



---

### 4. 分类预测头（MLP Head）

* 当输入数据流经所有的 Transformer 编码器块后，整个序列的特征已经高度融合。
* 模型不会使用全部的 Patch 特征，而是**只提取索引为 0 的 `[CLS]` Token 对应的特征向量**（形状降维至 $[B, \text{embed\_size}]$）。
* 最后，通过一个简单的多层感知机（通常包含 LayerNorm 和一个 Linear 线性层），将特征映射到对应的类别数（$\text{num\_classes}$），输出最终的分类 Logits。
