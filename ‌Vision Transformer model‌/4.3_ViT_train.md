## 一、 `PatchEmbedding` 模块：图像如何变成 Transformer 的输入？

Transformer 最初是为自然语言处理（NLP）设计的，输入是一串 Token 序列。ViT 的核心创新在于将图像切块（Patch）并展平，伪装成“单词序列”输入给 Transformer。

### 1. 代码流程与张量形状追踪

假设输入一个批次（Batch Size）为 32 的图像：`x` 的形状是 **`(32, 3, 224, 224)`**（$B, C, H, W$）。

* **步骤 1：卷积分块投影 (`self.projection`)**
```python
self.projection = nn.Conv2d(in_channels, embed_size, kernel_size=patch_size, stride=patch_size)

```


* `kernel_size=16, stride=16` 且不重叠。
* 图像被切成 $14 \times 14 = 196$ 个不重叠的小方块（因为 $224 / 16 = 14$）。
* 卷积核将每个 $16 \times 16 \times 3$ 的 Patch 映射为维数为 768 的向量。
* **输出形状**：`(32, 768, 14, 14)` —— 变成了具有 768 个通道的“特征图”。


* **步骤 2：展平与转置 (`flatten` & `transpose`)**
```python
x = self.projection(x).flatten(2).transpose(1, 2)

```


* `.flatten(2)`：从第 2 维开始展平，将 $14 \times 14$ 变成 $196$（即 `num_patches`）。此时形状为 `(32, 768, 196)`。
* `.transpose(1, 2)`：交换第 1 维和第 2 维，适配 Transformer 所需的 `(Batch, Seq_Len, Embed_Dim)` 格式。
* **输出形状**：`(32, 196, 768)`。


* **步骤 3：拼接分类标记 (`cls_token`)**
```python
cls_tokens = self.cls_token.expand(x.shape[0], -1, -1) # (32, 1, 768)
x = torch.cat((cls_tokens, x), dim=1)                 # (32, 197, 768)

```


* 引入一个可学习的参数 `cls_token`（形状 `(1, 1, 768)`），通过 `.expand()` 复制到整个 Batch。
* 将它拼在 196 个 Patch 的最前面，序列长度从 196 变为 **197**。


* **步骤 4：加上位置编码 (`position_embeddings`)**
```python
x = x + self.position_embeddings

```


* `position_embeddings` 的形状是 `(1, 197, 768)`。由于广播机制（Broadcasting），它会直接加到 Batch 中的每一张图上。
* **最终输出形状**：`(32, 197, 768)`。

## 二、 `TransformerBlock` 模块：特征交互的核心

ViT 抛弃了传统卷积的“局部感受野”，通过多头自注意力机制（Multi-Head Attention）让图片中任意两个 Patch 之间都能直接发生交互。

### 1. 结构特点：Pre-LN（先归一化）

传统 Transformer 使用 Post-LN（计算完注意力后再做 LayerNorm），而现代 Transformer 更倾向于 **Pre-LN**：

```python
norm_x = self.norm1(x)
attention = self.attention(norm_x, norm_x, norm_x)[0]
x = x + self.dropout(attention) # 残差连接

```

* **为什么要 Pre-LN？** 它可以让梯度直接通过残差路径反向传播，训练过程更加稳定，不容易出现梯度消失或爆炸。

### 2. 多头自注意力与前馈网络

* **`nn.MultiheadAttention`**：计算 Q（Query）、K（Key）、V（Value）。通过多头机制，模型可以同时关注图像的不同特征（例如：一个头关注猫的耳朵，另一个头关注背景）。
* **前馈网络 (`feed_forward`)**：
```python
nn.Sequential(
    nn.Linear(embed_size, forward_expansion * embed_size), # 768 -> 3072
    nn.GELU(),
    nn.Dropout(dropout),
    nn.Linear(forward_expansion * embed_size, embed_size), # 3072 -> 768
    nn.Dropout(dropout)
)

```


维度先放大 4 倍（`forward_expansion=4`，即 $768 \times 4 = 3072$），经过非线性激活后降维回 768。

## 三、 `VisionTransformer` 整体组装与分类头

```python
class VisionTransformer(nn.Module):
    def __init__(self, ...):
        ...
        self.transformer = nn.ModuleList([
            TransformerBlock(...) for _ in range(num_layers) # 堆叠 6 层
        ])
        self.mlp_head = nn.Sequential(
            nn.LayerNorm(embed_size),
            nn.Linear(embed_size, num_classes)
        )

```

### 前向传播逻辑：

1. **输入图片**通过 `PatchEmbedding` $\rightarrow$ 形状变为 `(32, 197, 768)`。
2. 依次通过 **6 层** `TransformerBlock` 进行特征深度提取。每一层输入输出形状都是 `(32, 197, 768)`。
3. **提取分类结果**：
```python
cls_token_out = x[:, 0]
return self.mlp_head(cls_token_out)

```


* 经过多层交互后，只有第一个位置的向量（即 `cls_token`）汇总了整张图的全局信息。
* 取出序列的第一个元素 `x[:, 0]`（形状从 `(32, 197, 768)` 变为 `(32, 768)`）。
* 丢进 `mlp_head` 映射为 `(32, 10)`，对应 CIFAR-10 的 10 个类别的预测得分（Logits）。

## 四、 训练与数据流转细节

### 1. 数据预处理

```python
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

```

* **为什么 Resize 到 224x224？** 代码中的 Patch 大小固定为 16，位置编码长度是按 $14 \times 14 + 1 = 197$ 预设的。CIFAR-10 原图是 $32 \times 32$，必须放大到 $224 \times 224$ 才能完美匹配该 ViT 架构。
* **ImageNet 归一化**：ViT 通常在大数据集上预训练，这里使用 ImageNet 的均值和标准差有助于保持特征分布一致。

### 2. 优化器选择

```python
optimizer = optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.01)

```

* **AdamW** 是训练 Transformer 模型的标配优化器。相比标准 Adam，它将权重衰减（Weight Decay）从梯度更新中独立出来，能够有效防止过拟合，提升泛化能力。
