在计算机视觉中，**自注意力（Self-Attention）**与**多头自注意力（Multi-Head Self-Attention, MSA）**是 Vision Transformer（ViT）的核心灵魂。它们彻底打破了传统卷积神经网络（CNN）依赖局部感受野（Local Receptive Field）的限制，使模型在处理图像时能够从第一层开始就建立**全局的像素/块间长距离依赖关系**。

以下是自注意力和多头自注意力在图像处理中的详细解析：

### 1. 自注意力机制（Self-Attention）在图像中的工作原理

在传统的 CNN 中，卷积核只能逐层扩大感受野，浅层网络只能看到局部的边缘和纹理。而自注意力机制通过数学上的“查询-键-值”模型，让图像中的每一个 Patch（图像块）都能直接与图像中的**所有其他 Patch** 进行信息交互。

#### 三要素的图像映射 ($Q, K, V$)

当输入的图像 Patch 序列表示为矩阵 $X \in \mathbb{R}^{B \times N \times D}$（其中 B 是批次大小，N 是 Patch 总数， D 是嵌入维度 `embed_size`）时：

* **Query（查询 $Q$）**：当前正在关注的 Patch。
* **Key（键 $K$）**：图像中所有 Patch 的特征标识，用来与 $Q$ 匹配。
* **Value（值 $V$）**：图像中所有 Patch 的实际内容信息。

通过对输入矩阵 $X$ 分别乘以三个可学习的权重矩阵 $W_Q, W_K, W_V$，得到 $Q, K, V$：


$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$

#### 注意力权重计算

自注意力的核心计算公式为：


$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

* **相似度计算 ($QK^T$)**：计算图像中任意两个 Patch 之间的相关性。例如，当处理一只猫的图像时，猫耳朵位置的 Patch 与猫眼睛位置的 Patch 会产生很高的相似度权重。
* **归一化与缩放 ($\text{softmax}$)**：除以维度缩放因子 $\sqrt{d_k}$ 防止梯度消失，并通过 softmax 转化为概率分布。
* **特征聚合 ($V$)**：用计算出的权重去加权求和所有 Patch 的值 $V$，输出一个融合了全局上下文的新特征矩阵。

### 2. 多头自注意力（Multi-Head Self-Attention, MSA）的作用

如果只有单一的自注意力机制，模型往往只能聚焦于某一种单一的关系（例如纯粹的空间几何位置）。多头机制（Multi-Head）类似于 CNN 中的“多通道（Channels）”，它将高维特征空间切分为多个子空间（即“头”），让模型在不同的视角下并行提取图像特征：

* **多维度特征捕获**：
* **Head 1** 可能专注于捕捉图像的**全局空间结构与轮廓**（例如车轮在哪里、车身轮廓是什么）。
* **Head 2** 可能专注于捕捉**局部材质与纹理**（例如车身的金属反光、树叶的纹理）。
* **Head 3** 可能专注于建立**语义与上下文关联**（例如天空与云朵的关系、路面与汽车的关系）。


* **数学实现**：
模型将通道维度 $D$ 均分为 $h$ 个头（d_k = D / h），每个头独立进行自注意力计算，最后将所有头的输出拼接起来，再通过一个线性投影层整合：

$$\text{MSA}(Q, K, V) = \text{Concat}(\text{head}_1, \text{head}_2, \dots, \text{head}_h) W_O$$



---

### 3. 图像处理中的直观体现与优势

* **天然的全局感受野**：在 CNN 中，要让左上角的像素和右下角的像素产生直接交互，需要堆叠非常多的卷积层。而在 ViT 的自注意力层中，**第一层**的每个 Patch 就可以直接和图像对角线另一端的 Patch 计算相关性。
* **动态自适应权重**：CNN 的卷积核权重在训练完成后是固定的（静态的）。而自注意力的权重是由图像内容动态决定的（动态的）——输入一张狗的图像和一张猫的图像，模型对各个 Patch 关注的权重完全不同，这赋予了 ViT 极强的图像表征和泛化能力。
