Text Classification Based on Knowledge Distillation.py代码使用 Hugging Face 的 `transformers` 和 `datasets` 库，实现了一个**基于知识蒸馏（Knowledge Distillation）的高级文本分类模型训练脚本**。

它利用大模型（`bert-base-uncased` 作为教师模型）来指导小模型（`distilbert-base-uncased` 作为学生模型）进行 IMDB 电影评论情感分类任务的微调。

下面进行全方位的详细说明：

---

### 一、 环境与模型初始化

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments
from datasets import load_dataset
import torch
import torch.nn.functional as F
import numpy as np

# 自动检测设备
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

teacher_model_name = "bert-base-uncased"
student_model_name = "distilbert-base-uncased"

# 加载教师模型和分词器，并移动到对应设备
teacher_model = AutoModelForSequenceClassification.from_pretrained(teacher_model_name, num_labels=2)
teacher_model.to(device)
teacher_model.eval()  # 固定教师模型为评估模式
teacher_tokenizer = AutoTokenizer.from_pretrained(teacher_model_name)

# 加载学生模型和分词器
student_model = AutoModelForSequenceClassification.from_pretrained(student_model_name, num_labels=2)
student_tokenizer = AutoTokenizer.from_pretrained(student_model_name)

```

* **设备分配**：通过 `torch.device` 自动检测并优先使用 GPU 训练。
* **教师模型（Teacher）**：加载 12 层的标准 BERT，将其移动到 GPU 上并设为 `.eval()`（冻结状态，不计算梯度、不更新参数），作为知识的“输出源”。
* **学生模型（Student）**：加载 6 层的 DistilBERT（参数量和计算量约为 BERT 的一半），作为待训练的目标模型。

---

### 二、 数据集加载与预处理

```python
# 加载数据集
dataset = load_dataset("stanfordnlp/imdb")

# 预处理数据：不仅要分词，还要将 'label' 重命名/映射为 'labels' 以适配 Trainer
def preprocess_data(examples):
    result = teacher_tokenizer(examples['text'], truncation=True, padding='max_length', max_length=128)
    result['labels'] = examples['label']  # 适配 Trainer 的 labels 键名
    return result

# 预处理并移除原文字段，避免传给模型时多余
encoded_dataset = dataset.map(preprocess_data, batched=True, remove_columns=["text", "label"])

```

* **IMDB 数据集**：加载标准的二分类情感数据集（正面/负面）。
* **文本分词**：使用 `teacher_tokenizer` 将文本转化为数字序列（`input_ids` 等），并截断/填充统一长度为 `max_length=128`。
* **标签适配**：Hugging Face 的 `Trainer` 内部默认查找名为 `labels`（复数）的字段。这里将原数据集的 `label` 映射为 `labels`，并使用 `remove_columns` 删除了模型不需要的原始文本和旧标签列，保证批次输入干净。

### 三、 教师模型推理与蒸馏损失函数

```python
def get_teacher_logits(batch, device):
    # 将 batch 数据移动到与教师模型相同的设备上
    inputs = {k: v.to(device) for k, v in batch.items() if k in teacher_tokenizer.model_input_names}
    with torch.no_grad():
        outputs = teacher_model(**inputs)
    return outputs.logits

def distillation_loss(student_logits, teacher_logits, labels, alpha=0.5, temperature=2.0):
    # 1. 软标签损失 (KL 散度)
    student_probs = F.log_softmax(student_logits / temperature, dim=-1)
    teacher_probs = F.softmax(teacher_logits / temperature, dim=-1)
    kd_loss = F.kl_div(student_probs, teacher_probs, reduction="batchmean") * (temperature ** 2)

    # 2. 硬标签损失（真实标签交叉熵）
    ce_loss = F.cross_entropy(student_logits, labels)

    # 加权组合 (注：原始代码最后一行带有语法错误残留的连字符，实际运行需写作 (1 - alpha))
    return alpha * kd_loss + (1 - alpha) * ce_loss

```

1. **`get_teacher_logits`**：在训练每一个 Batch 时，将输入数据动态推送到教师模型所在的设备（GPU），并在 `with torch.no_grad()` 下前向传播，获取教师模型高维的 Logits 输出（即“暗知识”）。
2. **`distillation_loss`**：结合了两种损失：
* **软标签损失（Soft Loss）**：通过温度系数 $T=2.0$ 放大类别间的相对概率关系，利用 `KLDivLoss` 让学生模型去模仿教师模型的思维。
* **硬标签损失（Hard Loss）**：使用标准的交叉熵（Cross Entropy）对齐真实世界标签。
* **平衡系数 $\alpha$**：将两者按 `alpha=0.5` 的比例进行加权相加。

### 四、 自定义训练器（Custom Trainer）

```python
class DistillationTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False, **kwargs):
        # 从 inputs 中安全取出 labels 并从 inputs 中弹出，防止传给模型的 forward 报错
        labels = inputs.pop("labels")

        # 学生模型输出
        outputs = model(**inputs)
        student_logits = outputs.logits

        # 获取教师模型输出（需要确保在同一设备）
        teacher_logits = get_teacher_logits(inputs, teacher_model.device)

        # 计算综合蒸馏损失
        loss = distillation_loss(student_logits, teacher_logits, labels)

        return (loss, outputs) if return_outputs else loss

```

* **重写 `compute_loss**`：Hugging Face 的标准 `Trainer` 默认只计算基于真实标签的交叉熵。这里通过继承并重写 `compute_loss` 方法，拦截了训练流程。
* **流程拦截**：
1. 弹出 `labels` 标签。
2. 让学生模型前向传播获取 `student_logits`。
3. 调用教师模型获取 `teacher_logits`。
4. 将两者和标签一同送入自定义的 `distillation_loss` 计算出**蒸馏总损失**并返回。

### 五、 训练参数配置与执行

```python
# 设置训练参数
training_args = TrainingArguments(
    output_dir="./distilled_model",
    eval_strategy="epoch",  # 每个 epoch 结束时进行评估
    learning_rate=5e-5,     # 学习率
    per_device_train_batch_size=8,  # 训练批次大小
    per_device_eval_batch_size=8,   # 评估批次大小
    num_train_epochs=3,             # 训练轮次
    fp16=True if torch.cuda.is_available() else False,  # 自动启用混合精度加速训练
)

# 初始化训练器
trainer = DistillationTrainer(
    model=student_model,
    args=training_args,
    train_dataset=encoded_dataset["train"],
    eval_dataset=encoded_dataset["test"],
)

# 开始训练
trainer.train()

```

* **`TrainingArguments`**：集中管理所有超参数（如批次大小、学习率、轮次、输出目录等）。同时开启了 `fp16=True`，在支持 CUDA 的显卡上使用半精度浮点数训练，能大幅节省显存并加快训练速度。
* **`trainer.train()`**：一键启动训练循环。`Trainer` 会自动处理数据集分批（Batching）、梯度清零、反向传播、优化器更新（AdamW）、学习率调度以及定期评估。
