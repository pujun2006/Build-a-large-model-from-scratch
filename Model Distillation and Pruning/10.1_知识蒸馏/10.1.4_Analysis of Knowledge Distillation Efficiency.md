Analysis of Knowledge Distillation Efficiency.py代码是一个**完整的基准测试脚本**。它不再直接进行复杂的知识蒸馏损失计算，而是将教师模型（BERT-base）**和**学生模型（DistilBERT）分别在同一份精简的 IMDB 数据集上进行微调（Fine-tuning），随后在训练时间、推理/评估时间、准确率以及模型参数量四个维度上进行横向对比。

下进行详细的逐段拆解：

---

### 一、 数据集加载与切片

```python
# 1. 加载数据集并选择子集
dataset = load_dataset("stanfordnlp/imdb")
train_dataset = dataset["train"].shuffle(seed=42).select(range(2000))
test_dataset = dataset["test"].shuffle(seed=42).select(range(500))

```

* **高效采样**：IMDB 完整数据集包含 5 万条数据，直接全量训练耗时较长。这里通过 `.shuffle(seed=42).select(range(...))` 抽取了 **2000 条训练集** 和 **500 条测试集**，既保证了随机性，又能让脚本在普通电脑或显卡上快速跑完。

---

### 二、 文本分词预处理

```python
# 2. 加载对应的分词器（这里使用 BERT 的分词器处理两个模型均可）
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

# 数据预处理函数：将文本转换为 Token ID
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True, max_length=128)

# 对训练集和测试集进行分词，并将原文字段移除
train_dataset = train_dataset.map(tokenize_function, batched=True, remove_columns=["text"])
test_dataset = test_dataset.map(tokenize_function, batched=True, remove_columns=["text"])

```

* **分词器（Tokenizer）**：使用 `bert-base-uncased` 的分词器，将人类可读的英文文本转化为模型可识别的张量。
* **填充与截断**：设置 `max_length=128`、`padding="max_length"` 和 `truncation=True`，将所有文本统一长度，以便按 Batch 矩阵化输入。
* **清洗列名**：通过 `remove_columns=["text"]` 删除了原始的字符串文本列，防止 `Trainer` 在接收批次数据时因为包含非数值类型而报错。

---

### 三、 自定义评估指标

```python
# 3. 定义准确率计算函数（解决 KeyError 问题）
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    acc = np.mean(predictions == labels)
    return {"accuracy": acc}

```

* **指标扩展**：Hugging Face 的 `Trainer` 默认只返回损失（Loss）。通过传入这个 `compute_metrics` 函数，模型在验证阶段输出的 `logits`（预测概率对数）会与真实标签 `labels` 进行比较：
* 用 `np.argmax` 获取预测的类别。
* 计算预测正确的比例，最终在返回的字典中生成 `eval_accuracy` 键。



---

### 四、 模型初始化

```python
# 初始化教师模型（BERT-base）和学生模型（DistilBERT）
teacher_model = BertForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)
student_model = DistilBertForSequenceClassification.from_pretrained("distilbert-base-uncased", num_labels=2)

```

* **教师模型**：加载标准 12 层的 `BertForSequenceClassification`。
* **学生模型**：加载 6 层的 `DistilBertForSequenceClassification`。两者均针对二分类任务（`num_labels=2`）初始化。

---

### 五、 核心评测函数：`train_and_evaluate`

```python
def train_and_evaluate(model, train_data, test_data, model_name=""):
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=train_data,
        eval_dataset=test_data,
        compute_metrics=compute_metrics
    )

    # 1. 记录训练时间
    start_train = time.time()
    trainer.train()
    train_time = time.time() - start_train

    # 2. 记录推理/评估时间
    start_eval = time.time()
    metrics = trainer.evaluate()
    eval_time = time.time() - start_eval

    # 3. 计算模型参数量（百万单位）
    model_size = sum(p.numel() for p in model.parameters()) / 1e6

    # 4. 输出格式化报告
    print(f"\n--- {model_name} 模型 ---")
    print(f"训练时间: {train_time:.2f} 秒")
    print(f"推理评估时间: {eval_time:.2f} 秒")
    print(f"验证集损失: {metrics['eval_loss']:.4f}")
    print(f"验证集准确率: {metrics['eval_accuracy']:.4f}")
    print(f"模型参数量: {model_size:.2f}M\n")

```

这个函数封装了完整的“训练 $\rightarrow$ 评估 $\rightarrow$ 统计”流水线：

1. **计时器**：利用 Python 的 `time.time()` 精准捕捉 `trainer.train()`（训练耗时）和 `trainer.evaluate()`（验证评估耗时）的运行时间。
2. **参数量统计**：通过遍历模型的全部参数 `model.parameters()`，累加其元素个数 `p.numel()`，并除以 $10^6$ 得到以 **百万（M）** 为单位的模型体积。
3. **指标提取**：从 `metrics` 字典中安全地读取 `eval_loss` 和 `eval_accuracy`。

---

### 六、 执行对比

```python
# 依次训练和评估教师模型与学生模型
train_and_evaluate(teacher_model, train_dataset, test_dataset, model_name="教师模型 (BERT-base)")
train_and_evaluate(student_model, train_dataset, test_dataset, model_name="学生模型 (DistilBERT)")

```
* 脚本会**串行执行**：先完整训练并评估教师模型，打印其性能报表；随后重置环境并训练评估学生模型，打印其性能报表。
* 通过这份输出，可以直观地对比出：在相同的缩减子集上，DistilBERT 的参数量和推理速度相比 BERT-base 有多大优势，而准确率又损失了多少。
