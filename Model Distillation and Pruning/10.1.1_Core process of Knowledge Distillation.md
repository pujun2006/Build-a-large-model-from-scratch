Core process of Knowledge Distillation.py代码实现了一个基于 **知识蒸馏（Knowledge Distillation, KD）** 的模型轻量化训练流程。它将一个标准的 12 层预训练教师模型（`bert-base-uncased`）的知识，迁移到一个缩减为 4 层的随机初始化学生模型中。

下面为进行逐段详细拆解：

---

### 1. 导入依赖与加载教师模型

```python
import torch
import torch.nn as nn
import torch.optim as optim
from transformers import BertForSequenceClassification, BertTokenizer, BertConfig

# 1. 加载BERT的教师模型和分词器
teacher_model = BertForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

```

* **教师模型（Teacher Model）**：使用了 Hugging Face 的 `bert-base-uncased`（包含 12 层 Transformer），这是一个已经预训练好的大模型。在蒸馏过程中，它充当“知识输出者”，负责对输入文本提供丰富的软标签（Soft Targets / 概率分布）。
* **分词器（Tokenizer）**：用于将文本转化为模型能够理解的 Token ID 和 Attention Mask。

---

### 2. 定义学生模型结构

```python
# 2. 构建真正的学生模型：通过修改 Config 来减少层数
class StudentModel(nn.Module):
    def __init__(self):
        super(StudentModel, self).__init__()
        # 获取基础配置并修改层数
        student_config = BertConfig.from_pretrained("bert-base-uncased", num_labels=2)
        student_config.num_hidden_layers = 4  # 缩减BERT层数为4层
        # 使用该配置初始化学生模型（权重为随机初始化）
        self.bert = BertForSequenceClassification(student_config)

    def forward(self, input_ids, attention_mask):
        return self.bert(input_ids=input_ids, attention_mask=attention_mask)

student_model = StudentModel()

```

* **模型轻量化**：通过 `BertConfig.from_pretrained` 获取基础配置，并将 `num_hidden_layers` 从 12 修改为 4。这样实例化的学生模型层数更少、参数量更小、推理速度更快。
* **随机初始化**：由于是基于修改后的配置直接创建的，学生模型的权重并没有直接继承教师模型的预训练权重，而是**随机初始化**的（通常后续需要进行长时间的蒸馏训练来赋予其能力）。

---

### 3. 定义知识蒸馏损失函数

```python
# 3. 修正后的蒸馏损失函数
def distillation_loss(student_logits, teacher_logits, labels, T=2.0, alpha=0.5):
    loss_fn = nn.CrossEntropyLoss()

    # 软标签损失（软化概率分布），使用 batchmean 保证数学严谨性
    soft_loss = nn.KLDivLoss(reduction='batchmean')(
        nn.functional.log_softmax(student_logits / T, dim=1),
        nn.functional.softmax(teacher_logits / T, dim=1)
    ) * (T * T)

    # 硬标签损失（真实标签交叉熵）
    hard_loss = loss_fn(student_logits, labels)

    # 组合总损失
    return alpha * soft_loss + (1 - alpha) * hard_loss

```

知识蒸馏的核心在于结合了“软标签”和“硬标签”：

1. **软标签损失（Soft Loss / KL 散度）**：
* 通过温度系数 $T$（Temperature，这里设为 2.0）对教师和学生的 Logits 进行平滑，放大模型对“非正确类别”的概率输出（即暗知识，例如某个样本有 80% 概率是正类，15% 是负类）。
* 使用 `nn.KLDivLoss` 计算学生概率分布与教师概率分布之间的差异。
* 乘以 $T^2$ 是为了补偿由于温度缩放导致的梯度幅度变化，确保梯度平稳。


2. **硬标签损失（Hard Loss / 交叉熵）**：
* 计算学生模型的输出与真实标签（Labels）之间的常规交叉熵损失，确保模型不会偏离真实的标签方向。


3. **加权组合**：通过超参数 `alpha`（这里为 0.5）平衡软标签损失和硬标签损失各自的权重。

---

### 4. 准备微型数据集与预处理

```python
# 4. 假设一个简单的数据集
texts = ["This is a positive example.", "This is a negative example."]
labels = torch.tensor([1, 0])

# 数据预处理
inputs = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")
input_ids = inputs["input_ids"]
attention_mask = inputs["attention_mask"]

```

* 这里仅构造了 2 条极简的测试文本，分别对应标签 `1`（正向）和 `0`（负向）。
* 通过 `tokenizer` 将文本转换为 PyTorch 张量格式，包含 `input_ids` 和 `attention_mask`。

---

### 5. 优化器与训练循环

```python
# 优化器设置
optimizer = optim.Adam(student_model.parameters(), lr=1e-4)

# 5. 蒸馏训练过程
epochs = 3
for epoch in range(epochs):
    student_model.train()
    teacher_model.eval()

    # 教师模型输出（不计算梯度）
    with torch.no_grad():
        teacher_outputs = teacher_model(input_ids=input_ids, attention_mask=attention_mask)
        teacher_logits = teacher_outputs.logits

    # 学生模型输出
    student_outputs = student_model(input_ids=input_ids, attention_mask=attention_mask)
    student_logits = student_outputs.logits

    # 计算蒸馏损失
    loss = distillation_loss(student_logits, teacher_logits, labels)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    print(f"Epoch {epoch + 1}/{epochs}, Loss: {loss.item():.4f}")

```

* **模式切换**：`student_model.train()` 开启学生模型的训练模式（启用 Dropout 等），`teacher_model.eval()` 将教师模型设为评估模式。
* **教师模型冻结**：在 `with torch.no_grad():` 下获取教师模型的输出，说明在训练中**只更新学生模型的参数**，教师模型保持不变。
* **单步迭代**：前向传播计算出学生和教师的 logits 后，送入 `distillation_loss` 计算总损失，接着进行标准的清空梯度 (`zero_grad`)、反向传播 (`backward`) 和参数更新 (`step`)。
