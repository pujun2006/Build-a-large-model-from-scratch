Weight Pruning.py代码是一个标准的、具备完整闭环的 **PyTorch 权重剪枝（Weight Pruning / 非结构化剪枝）** 示范工程。它完整模拟了深度学习模型从预训练、剪枝、稀疏度检查、微调（Fine-tuning）到最终固化（Mask Removal）的全生命周期。

下面进行拆解说明：


---

### 一、 核心步骤逐段拆解

#### 1. 模型与训练环境的初始化

```python
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(784, 256)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)
...

```

* **作用**：定义了一个典型的前馈神经网络（多层感知机 MLP），包含三个全连接层（`fc1`、`fc2`、`fc3`）和一个激活函数。
* **损失与优化器**：使用经典的交叉熵损失函数（`CrossEntropyLoss`）和随机梯度下降优化器（`SGD`），这是训练基础分类模型的标准配置。

#### 2. 模拟预训练阶段 (`Pre-training`)

```python
def train_epoch(model, dataloader, criterion, optimizer):
    model.train()
    for inputs, labels in dataloader:
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

```

* **作用**：在剪枝之前，模型需要先具备一定的特征提取能力（即经过预训练）。这里通过构建虚拟的随机张量数据集（`dummy_train_loader`），让模型走完前向传播、计算损失、反向传播和参数更新的标准流程。

#### 3. 稀疏度计算与监控 (`check_sparsity`)

```python
def check_sparsity(model):
    total_weights = 0
    zero_weights = 0
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            total_weights += module.weight.nelement()
            zero_weights += (module.weight == 0).sum().item()
    ...

```

* **作用**：这是监控剪枝效果的关键工具函数。
* **实现原理**：
* 遍历模型中的所有模块，筛选出全连接层（`nn.Linear`）。
* 利用 `.nelement()` 计算权重张量包含的总元素个数。
* 利用 `(module.weight == 0).sum().item()` 统计其中数值正好等于 `0` 的权重数量。
* 二者相除即可得出当前模型的**稀疏度百分比（Sparsity Rate）**。



#### 4. 应用 L1 非结构化剪枝 (`prune.l1_unstructured`)

```python
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        prune.l1_unstructured(module, name='weight', amount=0.5)

```

* **核心机制**：
* **L1 范数评分**：PyTorch 会计算每个权重绝对值的大小（|w|）。
* **置零决策**：将所有全连接层中绝对值最小的 50%（`amount=0.5`）的权重挑选出来并置为 0。
* **Mask 机制**：在这一步，PyTorch 并没有直接从物理内存中删掉这些参数，而是为每个层动态注册了一个名为 `weight_mask` 的二进制缓冲区（Buffer）。最终的权重输出由 `weight = weight_orig * weight_mask` 决定。



#### 5. 微调恢复阶段 (`Fine-tuning / Retraining`)

```python
print("开始进行剪枝后的微调（Fine-tuning）...")
fine_tune_optimizer = optim.SGD(model.parameters(), lr=0.001) 
for epoch in range(3):
    train_epoch(model, dummy_train_loader, criterion, fine_tune_optimizer)

```

* **为什么必不可少**：直接将 50% 的权重清零会瞬间破坏网络的内部表示，导致模型准确率大幅下降。
* **微调的作用**：通过几轮低学习率（`lr=0.001`）的反向传播，让剩下的、未被剪掉的 50% 权重通过梯度更新来“补偿”已丢失的连接，从而使模型精度恢复到接近剪枝前的水平。

#### 6. 固化剪枝结果与清理 (`prune.remove`)

```python
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        prune.remove(module, 'weight')

```

* **核心机制**：
* 微调结束后，如果我们不再需要动态调整或撤销剪枝，就可以调用 `prune.remove`。
* 这一步会将当前的 `weight_mask` 永久乘入 `weight` 中，并从模块中删掉 `weight_mask` 缓冲区。
* **结果**：权重矩阵中的 0 变成了真正的物理零值，模型结构恢复成干净的标准 PyTorch 模块，非常便于后续导出为 ONNX、TorchScript 或进行端侧部署。
