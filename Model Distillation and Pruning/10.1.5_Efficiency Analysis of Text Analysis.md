Efficiency Analysis of Text Analysis.py代码是一个**用于大模型与轻量级模型性能对比的基准测试脚本**。它通过 Hugging Face 的 `datasets` 和 `transformers` 库，加载了 GLUE 任务中的 SST-2（情感分析）数据集，分别对 **`roberta-large`（教师模型/大模型）** 和 **`distilroberta-base`（学生模型/轻量化模型）** 进行了微调训练，并在训练完后从**训练时间、推理评估时间、验证集损失、准确率以及参数量**五个维度对它们进行全面的横向对比。

下面分进行详尽的解析：

---

### 一、 数据集加载与命名空间指定

```python
# 1. 加载SST-2数据集并选择子集
dataset = load_dataset("nyu-mll/glue", "sst2")
train_dataset = dataset["train"].shuffle(seed=42).select(range(2000))
test_dataset = dataset["validation"].shuffle(seed=42).select(range(500))

```

* **显式命名空间**：使用了 `nyu-mll/glue` 来加载 GLUE 数据集，避免了旧版本 `datasets` 库在解析官方短名称时可能产生的 URI 格式错误。
* **高效采样**：SST-2 原训练集较大，这里通过 `.shuffle(seed=42).select(range(...))` 抽取了 **2000 条训练样本** 和 **500 条验证样本**，确保脚本能够在常规显卡上快速跑通。

---

### 二、 数据分词与列清理预处理

```python
# 2. 加载分词器并对数据进行预处理（SST-2 的文本字段名为 "sentence"）
tokenizer = AutoTokenizer.from_pretrained("roberta-base")

def tokenize_function(examples):
    return tokenizer(examples["sentence"], padding="max_length", truncation=True, max_length=128)

train_dataset = train_dataset.map(tokenize_function, batched=True, remove_columns=["sentence", "idx"])
test_dataset = test_dataset.map(tokenize_function, batched=True, remove_columns=["sentence", "idx"])

```

* **分词器（Tokenizer）**：使用 `roberta-base` 的分词器（RoBERTa 和 DistilRoBERTa 架构兼容该分词器）将文本转化为数字张量。
* **填充与截断**：设置 `max_length=128`，确保每条文本长度一致，便于张量矩阵批次运算。
* **清理无用列**：通过 `remove_columns=["sentence", "idx"]` 删除了原始的字符串文本列和 GLUE 任务自带的索引列，防止 `Trainer` 在接收批次输入时因为包含非数值类型而报错。

---

### 三、 自定义评估指标函数

```python
# 3. 定义准确率计算函数（解决 KeyError 问题）
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    acc = np.mean(predictions == labels)
    return {"accuracy": acc}

```

* **补充准确率**：Hugging Face 的 `Trainer` 默认只计算并返回 Loss。通过传入该函数，验证阶段输出的 `logits` 会与真实标签 `labels` 进行比对，通过 `np.argmax` 计算出预测准确率，并以 `accuracy` 键返回（在指标字典中会显示为 `eval_accuracy`）。

---

### 四、 模型初始化

```python
# 4. 初始化教师模型 (RoBERTa-large) 和学生模型 (DistilRoBERTa)
teacher_model = RobertaForSequenceClassification.from_pretrained("roberta-large", num_labels=2)
student_model = RobertaForSequenceClassification.from_pretrained("distilroberta-base", num_labels=2)

```

* **教师模型**：加载了参数量巨大的 `roberta-large`（通常约 3.55 亿参数），代表高性能上限。
* **学生模型**：加载了轻量化的 `distilroberta-base`（通常约 8200 万参数），代表高推理效率。两者均针对二分类任务（`num_labels=2`）进行初始化。

---

### 五、 训练参数配置

```python
# 5. 训练参数设置
training_args = TrainingArguments(
    output_dir="./results",
    eval_strategy="epoch",
    num_train_epochs=1,
    per_device_train_batch_size=8,

```

* **控制参数**：设定训练 1 个 Epoch、批次大小为 8。
* **混合精度（FP16）**：如果检测到 GPU，自动开启 `fp16=True`，能显著减少显存占用并加快训练速度。

---

### 六、 核心评测流水线：`train_and_evaluate`

```python
# 6. 创建Trainer函数
def train_and_evaluate(model, train_data, test_data, model_name=""):
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=train_data,
        eval_dataset=test_data,
        compute_metrics=compute_metrics
    )

    # 记录训练时间
    start_train = time.time()
    trainer.train()
    train_time = time.time() - start_train

    # 记录推理时间
    start_eval = time.time()
    metrics = trainer.evaluate()
    eval_time = time.time() - start_eval

    # 模型大小（百万参数量）
    model_size = sum(p.numel() for p in model.parameters()) / 1e6

    # 输出结果
    print(f"\n--- {model_name} 模型 ---")
    print(f"训练时间: {train_time:.2f} 秒")
    print(f"推理时间: {eval_time:.2f} 秒")
    print(f"验证集损失: {metrics['eval_loss']:.4f}")
    print(f"验证集准确率: {metrics['eval_accuracy']:.4f}")
    print(f"模型参数量: {model_size:.2f}M\n")

```

该函数封装了完整的自动化评测逻辑：

1. **时间监控**：使用 Python 的 `time.time()` 分别对 `trainer.train()`（训练耗时）和 `trainer.evaluate()`（推理/评估耗时）精准计时。
2. **参数量统计**：遍历模型的所有参数 `model.parameters()`，累加其张量元素总数 `p.numel()` 并换算成 **百万（M）** 单位。
3. **指标提取**：从 `trainer.evaluate()` 返回的 `metrics` 字典中提取 `eval_loss` 和 `eval_accuracy` 并打印格式化报告。

---

### 七、 依次执行评测

```python
# 7. 依次训练和评估教师模型与学生模型
train_and_evaluate(teacher_model, train_dataset, test_dataset, model_name="教师模型 (RoBERTa-large)")
train_and_evaluate(student_model, train_dataset, test_dataset, model_name="学生模型 (DistilRoBERTa)")

```

* 脚本会**串行运行**：先跑完大模型（RoBERTa-large）的训练与测试并输出报告，再跑轻量模型（DistilRoBERTa）的训练与测试并输出报告。
* 运行结束后，你可以直观地看到大模型与小模型在**准确率**与计算开销（参数量、训练/推理时间）之间的鸿沟，这也是为什么要通过“知识蒸馏”来让小模型去模仿大模型的原因所在。
