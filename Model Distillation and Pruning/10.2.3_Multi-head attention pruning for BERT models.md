Multi-head attention pruning for BERT models.py代码演示了如何在实际工程中对 **BERT 这样的大语言模型/Transformer 架构**进行**结构化剪枝（Structured Pruning）**。它涵盖了模型加载、数据集处理、注意力头剪枝、层剪枝、配置同步以及推理性能和物理文件大小的综合评估。

---


## 一、逐段详细代码拆解

### 1. 模型与数据集初始化

```python
model_name = "bert-base-uncased"
tokenizer = BertTokenizer.from_pretrained(model_name)
model = BertForSequenceClassification.from_pretrained(model_name, num_labels=2)

dataset = load_dataset("stanfordnlp/imdb")
train_dataset = dataset["train"].map(lambda e: tokenizer(e['text'], truncation=True, padding='max_length'), batched=True)
test_dataset = dataset["test"].map(lambda e: tokenizer(e['text'], truncation=True, padding='max_length'), batched=True)

```

* **核心动作**：加载标准预训练的 `bert-base-uncased` 模型（用于二分类任务 `num_labels=2`）和分词器。
* **数据集处理**：使用 `stanfordnlp/imdb`（显式带命名空间路径，避免路径解析报错），将文本截断并填充至统一的最大长度，以便进行批量训练和评估。

### 3. 注意力头剪枝（Attention Head Pruning）

```python
# 使用 Hugging Face 标准接口进行注意力头剪枝
# 剪枝掉第3层的第2和第3个注意力头
model.prune_heads({3: [2, 3]})

```

* **工作原理**：BERT 的多头自注意力机制（Multi-Head Attention）包含多个独立的注意力头。某些头可能冗余。调用全局标准的 `model.prune_heads({layer_index: [head_indices]})` 可以精确移除指定层的特定注意力头，从而在保持整体层数不变的情况下减少内部计算量。

### 4. 层剪枝（Layer Pruning / Depth Pruning）

```python
def prune_layers(model, prune_layer_nums):
    layers = [layer for i, layer in enumerate(model.bert.encoder.layer) if i not in prune_layer_nums]
    model.bert.encoder.layer = torch.nn.ModuleList(layers)
    # 【关键修复】同步更新模型的隐藏层总数配置
    model.config.num_hidden_layers = len(layers)

# 移除第11层以减少模型深度
prune_layers(model, prune_layer_nums=[11])

```

* **工作原理**：Transformer 是由多个相同结构的 Block 堆叠而成的。层剪枝直接移除整层的 Transformer Block（例如将 12 层减为 11 层）。
* **为什么必须更新 `model.config.num_hidden_layers**`：如果不修改配置文件的层数记录，后续调用 `model.save_pretrained()` 或重新加载时，PyTorch 会因为实际物理层数与配置不匹配而抛出加载异常。

### 5. 性能与大文件尺寸综合评估

```python
def evaluate_model_metrics(model, test_dataset, device="cuda"):
    model.to(device)
    
    # 评估模型物理文件大小
    model_path = "pruned_bert_model.pth"
    torch.save(model.state_dict(), model_path)
    model_size = os.path.getsize(model_path) / 1e6  # 转换为 MB
    print(f'Model Size after Pruning: {model_size:.2f} MB')

    # 单次前向推理耗时评估（抽样测试）
    model.eval()
    dummy_input = tokenizer("This is a test sentence for inference speed evaluation.", return_tensors="pt").to(device)
    
    # 预热 (Warm-up)
    with torch.no_grad():
        for _ in range(10):
            _ = model(**dummy_input)
            
    # 正式计时
    start_time = time.time()
    num_iters = 50
    with torch.no_grad():
        for _ in range(num_iters):
            _ = model(**dummy_input)
    
    avg_inference_time = (time.time() - start_time) / num_iters * 1000 # 转换为毫秒 (ms)
    print(f'Average Inference Time per forward pass: {avg_inference_time:.2f} ms')

```

* **物理文件大小计算**：通过 `torch.save` 将剪枝后的权重保存到本地，利用 `os.path.getsize` 真实反映模型体积的减小。
* **高精度推理耗时测量**：避开了用整个验证集评估的杂音，采用固定单条输入、多次循环并包含 **Warm-up（预热）** 的方式，能够极其准确地测算出单次前向传播的毫秒级（ms）推理延迟。
