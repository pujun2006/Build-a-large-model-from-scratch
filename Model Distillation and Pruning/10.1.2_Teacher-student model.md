Teacher-student model.py代码实现了一个完整、标准的 **Transformer 知识蒸馏（Knowledge Distillation）训练流程**。它将一个预训练好的大模型（`bert-base-uncased` 作为教师模型）的知识迁移到一个预训练的轻量级模型（`distilbert-base-uncased` 作为学生模型）中。

下面进行详细拆解说明：

---

### 一、 数据准备与加载

```python
import torch
from torch import nn, optim
from transformers import BertTokenizer, BertForSequenceClassification, DistilBertForSequenceClassification
from torch.utils.data import DataLoader, TensorDataset

# 假设已有预处理后的数据集
X_train = ["The movie was great!", "I did not like the film.", "An excellent experience."]
X_labels = [1, 0, 1]  # 假设标签为 1 表示正面，0 表示负面

tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
inputs = tokenizer(X_train, return_tensors="pt", padding=True, truncation=True, max_length=32)
labels = torch.tensor(X_labels)

train_data = TensorDataset(inputs['input_ids'], inputs['attention_mask'], labels)
train_loader = DataLoader(train_data, batch_size=2)

```

* **分词器（Tokenizer）**：使用 `bert-base-uncased` 的分词器将文本转换为模型输入的 `input_ids` 和 `attention_mask`。
* **数据管道（DataLoader）**：将数据封装为 PyTorch 的 `TensorDataset` 并通过 `DataLoader` 按批次（`batch_size=2`）加载，以便进行小批量（Mini-batch）迭代训练。

---

### 二、 加载教师模型与学生模型

```python
# 加载教师模型（预训练的 BERT）
teacher_model = BertForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)
teacher_model.eval()  # 设为评估模式，不更新教师模型的权重

# 加载学生模型（DistilBERT）
student_model = DistilBertForSequenceClassification.from_pretrained("distilbert-base-uncased", num_labels=2)
student_model.train()  # 设为训练模式

# 1. 补充定义优化器
optimizer = optim.Adam(student_model.parameters(), lr=5e-5)

```

* **教师模型（Teacher Model）**：加载了标准的 12 层 `bert-base-uncased`。调用 `teacher_model.eval()` 确保其处于评估模式（关闭 Dropout 等随机性），且在后续训练中不计算梯度。
* **学生模型（Student Model）**：加载了 6 层的 `distilbert-base-uncased`（DistilBERT 比 BERT 更轻量、运行更快）。调用 `student_model.train()` 开启训练模式。
* **优化器（Optimizer）**：使用 Adam 优化器，学习率设为适合微调 Transformer 的较小值（`5e-5`），且**只传入学生模型的参数**（`student_model.parameters()`），教师模型的参数在训练中保持不变。

---

### 三、 修正后的蒸馏损失函数（核心）

```python
def distillation_loss(student_logits, teacher_logits, true_labels, alpha=0.5, temperature=2.0):
    # 教师模型输出使用 softmax 转为概率分布
    soft_targets = nn.functional.softmax(teacher_logits / temperature, dim=-1)
    # 学生模型输出使用 log_softmax 转为对数概率
    student_log_probs = nn.functional.log_softmax(student_logits / temperature, dim=-1)
    
    # 软标签的 KL 散度损失 (乘以 T^2 保持梯度平稳)
    kd_loss = nn.functional.kl_div(student_log_probs, soft_targets, reduction="batchmean") * (temperature ** 2)

    # 使用真实标签的交叉熵损失
    ce_loss = nn.CrossEntropyLoss()(student_logits, true_labels)
    
    # 2. 修复了漏掉的减号
    return alpha * kd_loss + (1 - alpha) * ce_loss

```

这是知识蒸馏的灵魂所在，包含三个关键要点：

1. **软标签损失（KD Loss / KL 散度）**：
* 分别对教师和学生的 logits 除以温度 $T$（`temperature=2.0`）进行平滑，放大非正确类别的概率（即“暗知识”）。
* 教师端使用 `softmax` 得到概率分布，学生端使用 `log_softmax` 得到对数概率。
* 使用 `nn.functional.kl_div` 计算两者差异，并乘以 $T^2$（`temperature ** 2`）来补偿温度缩放对梯度幅度的影响。


2. **硬标签损失（CE Loss / 交叉熵）**：
* 计算学生模型的原始 logits 与真实标签（`true_labels`）之间的标准交叉熵，防止学生被教师的错误完全带偏。


3. **加权组合**：
* 通过超参数 `alpha`（`0.5`）将软标签损失和硬标签损失加权求和（已修正原代码中的语法错误，写为 `(1 - alpha)`）。



---

### 四、 训练循环（Training Loop）

```python
epochs = 3
for epoch in range(epochs):
    epoch_loss = 0
    for batch in train_loader:
        input_ids, attention_mask, batch_labels = batch
        
        # 教师模型预测
        with torch.no_grad():
            teacher_outputs = teacher_model(input_ids=input_ids, attention_mask=attention_mask)
            teacher_logits = teacher_outputs.logits

        # 学生模型预测
        student_outputs = student_model(input_ids=input_ids, attention_mask=attention_mask)
        student_logits = student_outputs.logits

        # 计算蒸馏损失
        loss = distillation_loss(student_logits, teacher_logits, batch_labels)
        epoch_loss += loss.item()

        # 反向传播和优化
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    avg_loss = epoch_loss / len(train_loader)
    print(f"Epoch {epoch + 1}/{epochs}, Loss: {avg_loss:.4f}")

```

整个训练过程按 Epoch 和 Batch 推进：

1. **教师前向传播**：在 `with torch.no_grad():` 上下文中运行，不计算梯度、不更新教师权重，仅提取其输出的 `teacher_logits`。
2. **学生前向传播**：正常计算学生的输出 `student_logits`（会记录计算图以便后续反向传播）。
3. **计算总损失**：将学生 logits、教师 logits 和真实标签送入 `distillation_loss`。
4. **反向传播与参数更新**：
* `optimizer.zero_grad()`：清空上一轮的梯度缓存。
* `loss.backward()`：通过链式法则计算学生模型各参数的梯度。
* `optimizer.step()`：使用 Adam 优化器根据梯度更新学生模型的参数。


5. **打印日志**：每个 Epoch 结束时，计算并打印平均 Loss（`avg_loss`），观察训练收敛情况。
