Comprehensive Case Study on Data Augmentation.py代码实现了一个经典的 **NLP 文本数据增强（Text Data Augmentation）** 脚本，其核心思路类似于经典的 **EDA（Easy Data Augmentation）** 算法。它通过对原始英文文本进行分词，并借助语言学知识库 **WordNet** 进行语义层面的扰动，从而生成多样化的训练样本。这在机器学习任务（如文本分类、情感分析）中常用于**扩充小数据集、防止模型过拟合**。

下面对代码的整体架构和四个核心步骤进行详细拆解。

---

### 一、 核心架构与准备工作

```python
import nltk
import random
import re
from nltk.corpus import wordnet as wn

# 下载所需资源
nltk.download('wordnet')
nltk.download('omw-1.4')

```

* **NLTK 与 WordNet**：`wordnet` 是 NLTK（自然语言处理工具包）内置的一个大型英语词典语义网络，它把单词按照语义关系（如同义词集 synsets）组织起来。`omw-1.4`（Open Multilingual WordNet）是其扩展支持包。
* **分词预处理 `preprocess_text(text)**`：
```python
def preprocess_text(text):
    words = re.findall(r'\b\w+\b', text.lower())  # 将文本分割成单词
    return words

```


* 使用正则表达式 `\b\w+\b` 干净地提取出所有英文单词，并用 `.lower()` 将其全部转换为小写，同时自动过滤掉了标点符号和特殊符号。



---

### 二、 核心辅助函数：获取同义词 (`get_synonyms`)

文本增强的基础是能够找到意思相近的替换词：

```python
def get_synonyms(word):
    synonyms = []
    for syn in wn.synsets(word):          # 获取该词在 WordNet 中的所有语义概念（Synset）
        for lemma in syn.lemmas():        # 遍历该概念下的所有词元（Lemma/具体单词）
            if lemma.name() != word:      # 排除原词本身
                synonyms.append(lemma.name())
    return list(set(synonyms))            # 去重并转为列表

```

* **原理**：例如对于单词 `good`，WordNet 会检索出它的不同含义，并找出诸如 `fine`、`exceptional` 等同义词，为后续的替换和插入提供候选池。

### 三、 四种数据增强策略详解

#### 1. 同义词替换 (Synonym Replacement, SR)

```python
def synonym_replacement(words, n=5):
    new_words = words[:]
    for _ in range(n):
        idx = random.randint(0, len(words) - 1)  # 随机选定一个词的位置
        word = words[idx]
        synonyms = get_synonyms(word)            # 获取该词的同义词
        if synonyms:
            new_words[idx] = random.choice(synonyms) # 随机替换为一个同义词
    return new_words

```

* **作用**：随机挑选句中的 $n$ 个单词，将其替换为它们的同义词。
* **目的**：在**不改变句子整体语义**的前提下，改变局部的表达形式，增加文本的多样性。

#### 2. 随机插入 (Random Insertion, RI)

```python
def random_insertion(words, n=5):
    new_words = words[:]
    for _ in range(n):
        word = words[random.randint(0, len(words) - 1)] # 随机选一个词
        synonyms = get_synonyms(word)                  # 找它的同义词
        if synonyms:
            insert_pos = random.randint(0, len(new_words)) # 随机选一个插入位置
            new_words.insert(insert_pos, random.choice(synonyms))
    return new_words

```

* **作用**：随机找出一个词的同义词，然后将其**随机插入**到句子中的任意位置，重复 $n$ 次。
* **目的**：模拟人类写作时可能出现的语序微调或附加修饰，丰富句式结构。

#### 3. 随机删除 (Random Deletion, RD)

```python
def random_deletion(words, p=0.2):
    if len(words) == 1:
        return words
    return [word for word in words if random.uniform(0, 1) > p]

```

* **作用**：遍历句子中的每个单词，以概率 $p$（例如 20%）独立决定是否将该单词**随机删除**。
* **目的**：迫使模型学会从“残缺”或包含噪声的文本中提取关键特征，提高模型面对不完整输入时的鲁棒性（Robustness）。
