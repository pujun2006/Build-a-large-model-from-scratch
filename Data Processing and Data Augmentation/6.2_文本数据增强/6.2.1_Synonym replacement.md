Synonym replacement.py代码实现了一个基于**词典匹配的中文文本同义词替换增强**脚本。它结合了 `pandas`（数据处理）和 `jieba`（中文分词），核心目的是在保证语义基本不变的前提下，对中文文本进行轻量级的扰动和扩展。

以下是代码各个模块的详细拆解说明：

---

### 一、 准备工作与数据初始化

```python
import random
import jieba
import pandas as pd

# 示例数据集
data = {
    'text': [
        '自然语言处理是人工智能的一个重要领域，它涉及人机交互中的语言理解和生成。',
        '机器学习和深度学习的进步推动了自然语言处理的发展。',
        '同义词替换是一种数据增强技术，能在保持语义不变的情况下扩展数据集。',
    ]
}
df = pd.DataFrame(data)

```

* **依赖库**：`random` 用于随机挑选词语和同义词；`jieba` 用于中文分词（因为中文不像英文有天然的空格分隔）；`pandas` 用于构建和操作表格数据集。
* **数据集**：创建了一个包含三条中文句子的 DataFrame，作为待增强的原始文本。

---

### 二、 同义词典定义

```python
# 简单的中文同义词典示例（实际项目中可使用更完整的“同义词词林”或词向量模型）
synonym_dict = {
    '重要': ['关键', '核心', '主要'],
    '发展': ['前进', '进展', '演进'],
    '保持': ['维持', '维系', '坚持'],
    '扩展': ['扩充', '扩大', '拓宽'],
    '领域': ['范畴', '板块', '界别'],
}

```

* 这是一个硬编码的**映射字典**（键为原词，值为同义词列表）。
* 在真实的项目生产环境中，这个字典通常会替换为更大规模的专业词典（如“哈工大同义词词林”），或者通过词向量（Word2Vec / BERT）计算语义相似度动态获取。

---

### 三、 核心增强函数：`synonym_replacement_cn`

这是整个脚本最关键的逻辑，负责对单条句子进行分词和替换：

```python
def synonym_replacement_cn(sentence, n=1):
  # 1. 使用 jieba 进行分词
  words = list(jieba.cut(sentence))
  new_words = words[:]

  # 2. 筛选出词典中存在的词的索引
  candidate_indices = [i for i, word in enumerate(words) if word in synonym_dict]

  replaced = 0
  # 3. 循环条件增加 candidate_indices 非空判断，防止死循环
  while replaced < n and candidate_indices:
    idx = random.choice(candidate_indices)
    candidate_indices.remove(idx)  # 移除已选过的索引，避免重复选中

    word = words[idx]
    synonyms = synonym_dict[word]

    if synonyms:
      new_words[idx] = random.choice(synonyms)
      replaced += 1

  # 4. 将分词拼接回完整句子
  return ''.join(new_words)

```

1. **分词处理**：`list(jieba.cut(sentence))` 将长句切分为独立的词语列表（例如将“自然语言处理”切开）。
2. **候选索引定位**：列表推导式遍历分词结果，找出哪些词在我们的 `synonym_dict` 中存在，并记录它们在列表中的位置（索引）。
3. **安全循环与替换**：
* `while replaced < n and candidate_indices:` 这一行是防止程序陷入死循环的保障。如果句子中没有包含在词典里的词（`candidate_indices` 为空），或者已经达到了替换次数 `n`，循环就会安全退出。
* `candidate_indices.remove(idx)` 确保在同一条句子中，不会对同一个词重复进行多次替换操作。


4. **拼回文本**：`''.join(new_words)` 把修改后的词语列表重新无缝拼接成一串完整的中文句子。

### 四、 批量处理与输出

```python
# 定义增强函数，对数据集每一行进行同义词替换
def augment_text(df, num_replacements=1):
  augmented_texts = []

  for text in df['text']:
    augmented_text = synonym_replacement_cn(text, num_replacements)
    augmented_texts.append(augmented_text)

  df['augmented_text'] = augmented_texts
  return df


# 增强数据集，指定每条句子替换1个词
df = augment_text(df, num_replacements=1)

# 显示增强结果
print('原始文本：')
for i, t in enumerate(df['text']):
  print(f'[{i}] {t}')

print('\n增强后的文本：')
for i, t in enumerate(df['augmented_text']):
  print(f'[{i}] {t}')

```

* **`augment_text` 函数**：遍历 DataFrame 的 `text` 列，逐行调用单句替换函数，并将生成的新文本存入新的列 `augmented_text` 中。
* **结果展示**：通过 `enumerate` 循环格式化输出原始文本与增强后的对比效果，方便直观查看替换结果。
