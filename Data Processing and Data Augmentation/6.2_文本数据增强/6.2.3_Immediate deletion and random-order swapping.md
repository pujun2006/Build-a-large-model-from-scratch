Immediate deletion and random-order swapping.py这段修改后的代码针对中文文本的特点进行了全面改造，成功实现了中文随机删除（Random Deletion, RD）**与**中文随机顺序交换（Random Swap, RS）两种经典的 EDA 数据增强策略。

以下是代码各个模块和核心逻辑的详细拆解说明：

```python
    ]

```

* **依赖库**：引入 `random`（控制随机概率与索引选择）、`jieba`（**核心：解决中文分词问题**）、`pandas`（构建和管理表格数据集）。
* **数据集**：定义了三条包含专业术语的中文长句，作为待增强的原始文本。

### 二、 中文随机删除函数：`random_deletion_cn`

该函数模拟人类说话时偶尔漏掉某些不重要词汇的场景，迫使模型不依赖单一关键词进行判断。

```python
def random_deletion_cn(sentence, p=0.2):
  # 1. 使用 jieba 将中文句子切分为独立的词语列表
  words = list(jieba.cut(sentence))
  if len(words) <= 1:
    return sentence  # 如果分词后词数太少，直接返回原句

  new_words = []
  for word in words:
    # 2. 以概率 p 随机决定是否丢弃当前词（保留概率为 1 - p）
    if random.uniform(0, 1) > p:
      new_words.append(word)

  # 3. 安全兜底：如果运气不好把所有词都删光了，随机保留原分词中的一个词
  if len(new_words) == 0:
    return random.choice(words)

  # 4. 无缝拼回中文句子
  return ''.join(new_words)

```

* **分词基石**：通过 `list(jieba.cut(sentence))` 将整句拆解为真实的词语数组，从而避开了 `split()` 在中文上失效的问题。
* **概率保留机制**：`random.uniform(0, 1)` 生成一个 0 到 1 之间的随机小数。若该值大于设定的删除概率 `p`（默认 0.2），则保留该词；否则丢弃。
* **空列表保护**：若极端情况下所有词都被删除了，代码会触发 `len(new_words) == 0` 的判断，随机挑回原分词列表中的一个词，防止返回空字符串。
* **无缝拼接**：使用 ` ''.join(new_words)` 将幸存的词语拼接回完整的中文句子。

### 三、 中文随机顺序交换函数：`random_swap_cn`

该函数通过打乱句子中词语的先后顺序，创造句法噪声，从而提高模型对语序变化的容错能力。

```python
def random_swap_cn(sentence, n=1):
  # 1. 使用 jieba 分词
  words = list(jieba.cut(sentence))
  if len(words) < 2:
    return sentence  # 词数少于2个无法交换

  new_words = words[:]
  for _ in range(n):
    # 2. 随机抽取两个不同的下标索引
    idx1, idx2 = random.sample(range(len(new_words)), 2)
    # 3. 交换两个位置的词语
    new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]

  # 4. 拼回中文句子
  return ''.join(new_words)

```

* **长度校验**：如果分词后的词数小于 2，无法进行交换，直接返回原句，避免报错。
* **安全抽样**：`random.sample(range(len(new_words)), 2)` 能够确保随机抽出的两个索引 `idx1` 和 `idx2` **绝对不重复**。
* **Pythonic 交换**：利用 Python 的元组赋值特性 `new_words[idx1], new_words[idx2] = new_words[idx2], new_words[idx1]` 优雅地完成了两个词位置的对调。
* **循环控制**：通过 `for _ in range(n):` 可以控制对同一句话进行多次（如 `n=1` 或 `n=2`）随机交换。

### 四、 批量处理与数据集成：`augment_text_with_delete_swap`

该函数负责将上述两个单句增强逻辑应用到整个 Pandas DataFrame 中：

```python
def augment_text_with_delete_swap(df, delete_prob=0.2, swap_times=1):
  augmented_texts_delete = []
  augmented_texts_swap = []

  for text in df['text']:
    # 对每条文本执行随机删除
    augmented_text_delete = random_deletion_cn(text, delete_prob)
    augmented_texts_delete.append(augmented_text_delete)

    # 对每条文本执行随机顺序交换
    augmented_text_swap = random_swap_cn(text, swap_times)
    augmented_texts_swap.append(augmented_text_swap)

  # 将生成的新文本分别存入 DataFrame 的新列中
  df['augmented_text_delete'] = augmented_texts_delete
  df['augmented_text_swap'] = augmented_texts_swap
  return df


# 运行增强
df = augment_text_with_delete_swap(df, delete_prob=0.2, swap_times=1)

```

* 遍历 `df['text']` 列，逐行调用 `random_deletion_cn` 和 `random_swap_cn`。
* 分别创建两个新列 `augmented_text_delete`（随机删除结果）和 `augmented_text_swap`（随机交换结果），方便与原图进行横向对比。
