Text Data Cleaning.py这段代码是一个基于 **Python** 的文本预处理（Text Preprocessing）脚本，主要利用 `pandas` 库处理 DataFrame 中的文本数据，并结合 `re`（正则表达式）和 `zhon` 库对中文及混合文本进行清洗、去噪、去停用词和去重。

下面详细拆解说明：

---

### 一. 准备工作与库导入

```python
import re
import pandas as pd
from zhon.hanzi import punctuation as zh_punctuation

```

* **`re`**: Python 自带的正则表达式模块，用于文本匹配、替换和过滤。
* **`pandas`**: 数据处理库，这里用于构建 DataFrame，方便批量处理文本。
* **`zhon.hanzi.punctuation`**: 第三方库 `zhon` 中的模块，包含了几乎所有的中文标点符号（如 `，`、`。`、`！` 等），常用于中文文本清洗。

---

### 二. 示例数据集与停用词定义

```python
# 示例数据集
data = {
    'text': [
        "这是一段包含HTML标签的文本。<html>标签内容</html>此外，文本中还有特殊字符：#、@、$以及一些无用信息。",
        "这里是包含重复词汇的示例。比如，比如，这里有一些重复的词汇需要去除。",
        "这是一段含有停用词的文本。停用词包括：和、是、的、了、不等。",
        "  此文本包含了前后空格以及多余的空白     间隔。   ",
        "此文本中包含英文标点符号，例如: ! @ # $, 需要将这些符号进行处理。"
    ]
}
df = pd.DataFrame(data)

# 中文停用词表
stop_words = set(["和", "是", "的", "了", "不", "等"])

```

* 构建了一个包含 5 条不同“噪声”文本的 Pandas 数据集（包含 HTML 标签、中英文标点、特殊符号、多余空格、重复词汇和停用词）。
* 定义了一个简单的中文停用词集合 `stop_words`。

---

### 三. 核心清洗函数：`clean_text(text)`

该函数对输入的文本依次执行 7 步清洗操作：

#### 1. 去除 HTML 标签

```python
text = re.sub(r'<.*?>', '', text)

```

* **作用**：使用正则表达式 `<.*?>` 匹配并删除类似 `<html>`、`</html>` 的 HTML 标签。`.*?` 表示非贪婪匹配。

#### 2. 去除特殊字符

```python
text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)

```

* **作用**：保留中文字符（`\u4e00-\u9fa5`）、英文字母（`a-z`, `A-Z`）、数字（`0-9`）以及空白字符（`\s`），将其他所有特殊符号（如 `#`、`@`、`$` 等）替换为空字符串。

#### 3. 去除中文标点符号

```python
text = re.sub(f'[{zh_punctuation}]', '', text)

```

* **作用**：利用前面导入的 `zhon` 中文标点库，精准清除文本中残留的中文标点符号。

#### 4. 去除前后空格

```python
text = text.strip()

```

* **作用**：去掉文本开头和结尾多余的空白字符。

#### 5. 删除多余空格

```python
text = re.sub(r'\s+', ' ', text)

```

* **作用**：将文本中连续的多个空格（或制表符、换行符）压缩为一个标准的半角空格 ` `。

#### 6. 去除停用词

```python
text = ' '.join([word for word in text.split() if word not in stop_words])

```

* **作用**：以空格为分隔符将文本拆分，过滤掉属于 `stop_words` 集合的词，再重新拼接。

> 💡 **注意**：由于该代码没有使用专业的分词工具（如 `jieba`），直接用 `.split()` 切分中文时，会将每个**汉字**视为一个独立的词。因此这里的停用词过滤实际上是针对单字的。

#### 7. 去除重复词汇

```python
words = text.split()
unique_words = []
for word in words:
    if word not in unique_words:
        unique_words.append(word)
text = ' '.join(unique_words)

```

* **作用**：遍历切分后的词列表，去除重复出现的词，同时保持原有的先后顺序（类似于有序去重）。

---

### 四. 应用与输出

```python
# 应用清洗函数
df['cleaned_text'] = df['text'].apply(clean_text)

# 显示清洗结果
print("清洗前的文本：")
print(df['text'])
print("\n清洗后的文本：")
print(df['cleaned_text'])

```

* 使用 `.apply(clean_text)` 将定义好的清洗逻辑向量化应用到 DataFrame 的 `text` 列中，并将结果存入新列 `cleaned_text`。
* 最后分别打印清洗前后的对比结果。
