在大模型（LLM）的架构中，分词（Tokenization）**和**嵌入层（Embedding Layer）是连接人类自然语言与神经网络底层数学计算的两个核心桥梁。

简而言之，分词器将连续的文本切割成模型能够理解的“最小离散单元”（Token），而嵌入层则将这些离散的符号映射为连续的、高维的稠密向量（Dense Vectors），供后续的Transformer层进行矩阵运算和语义建模。

---

## 一、 分词层（Tokenization）：文本到离散符号的转化

计算机无法直接处理人类的文字，必须将文本转化为数字ID。分词就是将一段文本切分为一系列子词（Subword）或词元的过程。

### 1. 主流分词算法

早期的深度学习模型使用基于词（Word-level）或字符（Character-level）的分词，但它们面临严重的“词表爆炸”或“语义丢失”问题。现代大模型普遍采用**子词分词算法（Subword Tokenization）**，核心思想是：**高频词保留全称，低频词或罕见词拆分为更小的音节或字符组合**。

* **BPE (Byte-Pair Encoding)**：
* **原理**：从基础字符（及字节）词表开始，统计语料中所有相邻字节对的出现频率，将最高频的字节对合并为一个新的符号，迭代进行直到达到预设的词表大小（Vocabulary Size）。
* **代表模型**：GPT-2, GPT-3, GPT-4, LLaMA 系列。


* **WordPiece**：
* **原理**：与BPE类似，但不是基于频率合并，而是基于语言模型概率（最大似然估计）来评估合并某个字节对后对模型困惑度（Perplexity）的改善程度。
* **代表模型**：BERT, DistilBERT。


* **Unigram Language Model**：
* **原理**：从一个超大的初始子词表开始，通过计算每个子词对整个语料库对数似然的贡献，逐步裁剪掉那些贡献最小、可被其他子词替代的子词，直到达到目标词表大小。它支持对同一文本输出多种可能的切分概率。
* **代表模型**：T5, ALBERT, Gemma。



### 2. 分词在LLM中的关键作用与挑战

* **词表大小（Vocab Size）**：现代大模型的词表通常在 $32,000$ 到 $256,000$ 之间（例如 LLaMA-3 的词表大小达到了 $128,256$）。词表过大，输出层的 Softmax 计算开销会急剧增加；词表过小，会导致长文本被切得太碎，消耗更多的上下文长度（Context Window）。
* **多语言与特殊字符处理**：现代分词器（如基于 Byte-fallback 的 BPE）能够通过操作底层 UTF-8 字节，完美处理Emoji、罕见汉字及多国语言，避免了传统的 `[UNK]`（未知词）问题。
* **代码与数字的痛点**：由于分词器通常针对自然语言优化，空格、缩进（如 Python 中的代码缩进）以及长数字往往会被切分得非常零散，这也是大模型在数学计算和代码编写上有时表现不稳定的底层原因之一。

## 二、 嵌入层（Embedding Layer）：离散符号到连续向量的映射

经过分词后，输入的文本变成了一串整数 ID 序列（例如 `[101, 2054, 2003, 1037]`）。嵌入层的作用就是通过查表（Lookup Table）或矩阵乘法，将每一个 Token ID 转换为一个固定维度的稠密向量。

### 1. 核心组件

在大模型中，嵌入层通常包含两个主要部分：

* **Token Embedding（词嵌入矩阵）**：
* **形状**：Vocab_Size * model（例如 LLaMA-7B 中，d_model = 4096）。
* **作用**：将离散的 Token ID 映射到 $d_{\text{model}}$ 维的连续语义空间中。在这个空间里，语义相近的词（如“国王”与“女王”）在向量空间中的距离会比较近。


* **Position Embedding / Positional Encoding（位置嵌入）**：
* **痛点**：Transformer 架构本身是基于自注意力机制（Self-Attention）的，对输入序列的顺序是无感的（即把句子打乱，注意力机制算出的结果是一样的）。
* **解决方案**：必须引入位置信息。早期的模型使用**绝对位置嵌入**（如 BERT 的可学习位置编码、Transformer 原版的正余弦编码）；现代大模型则广泛采用**相对位置编码**或**旋转位置编码（RoPE, Rotary Position Embedding）**，将位置信息直接注入到 Query 和 Key 的计算中，极大地提升了模型处理超长文本的泛化能力。

### 2. 现代大模型中的设计优化

* **RMSNorm 与嵌入缩放**：部分现代架构在嵌入层之后会立即应用归一化或对嵌入向量进行特定的数值缩放，以稳定超大规模模型（如千亿参数以上）在训练初期的梯度。
* **权重绑定（Weight Tying）**：在某些模型架构中，输入层的 Token Embedding 矩阵与输出层（Language Modeling Head）的线性投影矩阵会共享同一套参数。这不仅大幅减少了模型的参数量，还能在理论上拉近“输入语义空间”与“输出预测空间”的距离，提升训练效率。
