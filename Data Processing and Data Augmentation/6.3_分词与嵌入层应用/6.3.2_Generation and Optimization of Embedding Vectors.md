Generation and Optimization of Embedding Vectors.py代码是一个完整的、可直接运行的 **Word2Vec 词向量训练与降维可视化脚本**。它结合了中文分词、嵌入模型训练、主成分分析（PCA）降维以及 Matplotlib 绘图，展示了如何将高维的词向量降维并在二维平面上进行可视化。

下面对代码的各个组成部分和核心逻辑进行详细说明。

---

### 一、 核心模块与环境配置

```python
import pandas as pd
import gensim
from gensim.models import Word2Vec
import numpy as np
from sklearn.decomposition import PCA

import matplotlib
matplotlib.use('Agg')  # 强制使用非交互式后端
import matplotlib.pyplot as plt
import jieba

# 指定字体（解决中文乱码问题）
plt.rcParams['font.sans-serif'] = ['SimHei']  # 设置黑体
plt.rcParams['axes.unicode_minus'] = False  # 解决保存图像时负号 '-' 显示为方块的问题

```

* **`matplotlib.use('Agg')`**：由于在部分集成开发环境（如 PyCharm 的某些配置）中，默认的图形交互后端容易引发兼容性冲突或导致窗口无法弹出，这里显式指定了 `Agg`（非交互式后端）。它会让 Matplotlib 专注于将图表渲染为静态图片文件，而不会尝试打开 GUI 窗口。
* **`plt.rcParams` 设置**：确保图表中的中文标签（如标题、坐标轴名称、散点旁的词语标注）能够正常显示，而不会变成乱码或方块。

---

### 二、 数据准备与中文分词

```python
# 示例数据集
data = {
    'text': [
        "自然语言处理是人工智能的重要分支。",
        "数据增强可以提高模型的泛化能力。",
        "深度学习和机器学习是现代人工智能的核心。",
        "词向量能表示词汇的语义信息。",
    ]
}
df = pd.DataFrame(data)

# 分词处理函数
def preprocess_text(text):
    words = jieba.lcut(text)
    # 过滤掉纯空白字符以及常见的标点符号
    return [w for w in words if w.strip() and w not in ['。', '，', '、']]

df['tokenized'] = df['text'].apply(preprocess_text)

```

* **Pandas DataFrame**：用来组织和管理文本数据集。
* **`jieba.lcut(text)`**：这是关键的**中文分词**步骤。由于中文句子不像英文那样天然用空格隔开，必须借助结巴分词（`jieba`）将连续的句子切分成独立的词语列表（例如将 `"自然语言处理"` 切为 `['自然', '语言', '处理']`）。
* **过滤逻辑**：通过列表推导式剔除了无实际语义的标点符号（如 `。`、`，`、`、`）和空白字符，确保送入模型训练的都是干净的有效词汇。

---

### 三、 训练 Word2Vec 模型

```python
# 训练 Word2Vec 模型
model = Word2Vec(sentences=df['tokenized'], vector_size=10, window=3, min_count=1, workers=1)

```

利用 `gensim.models.Word2Vec` 对分词后的语料进行训练：

* **`sentences=df['tokenized']`**：输入数据，要求是一个由词列表组成的迭代器（每个元素对应一句话的分词结果）。
* **`vector_size=10`**：将每个词映射为 **10 维**的稠密向量（在生产环境中通常设为 100、300 甚至更高，这里因为示例语料极少，设为 10 防止维度过高过拟合）。
* **`window=3`**：上下文窗口大小，即预测中心词时，考虑前后各 3 个词的范围。
* **`min_count=1`**：词频阈值。因为这里样本非常少，设为 1 以确保所有出现过的词都被收录进词表中（默认通常是 5）。
* **`workers=1`**：训练使用的线程数。

---

### 四、 提取词向量并进行 PCA 降维

```python
# 提取词向量并转化为数组形式
words = list(model.wv.index_to_key)
word_vectors = np.array([model.wv[word] for word in words])

# PCA降维
n_comp = min(2, len(words), len(word_vectors[0]))
pca = PCA(n_components=n_comp)
word_vectors_2d = pca.fit_transform(word_vectors)

```

1. **提取向量**：
* `model.wv.index_to_key` 获取模型词表中所有词的列表。
* 列表推导式 `[model.wv[word] for word in words]` 取出每个词对应的 10 维稠密向量，并转换为 NumPy 矩阵。


2. **PCA 降维（Principal Component Analysis）**：
* 神经网络学到的词向量通常是高维的（这里是 10 维，实际大模型中是几千维）。人类无法直接在脑海中想象高维空间，因此需要降维。
* `n_comp = min(2, ...)` 动态计算降维后的维度（通常降至 2 维以便在平面坐标系中画图）。
* `pca.fit_transform(word_vectors)` 将 10 维的词向量压缩投影到 2 维平面上，得到 `word_vectors_2d`。



---

### 五、 可视化与本地保存

```python
# 绘制图表
plt.figure(figsize=(8, 6))
for i, word in enumerate(words):
    x = word_vectors_2d[i, 0]
    y = word_vectors_2d[i, 1] if n_comp > 1 else 0  
    plt.scatter(x, y)
    plt.annotate(word, (x, y), fontsize=12)

plt.title("2D PCA后的词嵌入可视化")
plt.xlabel("PCA 元素 1")
plt.ylabel("PCA 元素 2")
plt.grid(True)

# 保存到当前脚本所在的目录下
plt.savefig('embedding_plot.png', dpi=300, bbox_inches='tight')
print("图表已成功保存为 'embedding_plot.png'，请在项目文件夹中查看！")

```

* **`plt.scatter(x, y)`**：在二维坐标系中为每个词画一个散点。
* **`plt.annotate(word, (x, y))`**：在对应的散点旁边标上该词的文字（如“人工智能”、“模型”等），方便肉眼识别。
* **`plt.savefig(...)`**：因为前面开启了 `Agg` 后端，这里将绘制好的画布高分辨率（`dpi=300`）保存为当前目录下的 `embedding_plot.png` 图片文件。打开该图片，你就能直观地看到这些中文词汇在降维后的二维向量空间中的相对位置分布。

这张图表展示了通过前述 Python 脚本运行后生成的 **Word2Vec 词向量降维与可视化结果**。它将模型从极小语料中学习到的高维词向量，通过主成分分析（PCA）压缩投影到了二维平面（PCA 元素 1 和 PCA 元素 2）上。

以下是对该运行结果的详细解读：

---

#### 1. 核心现象与解读

* **空间距离与语义关系**：
* 在 Word2Vec 的向量空间中，**语义相近或经常在相同上下文中出现的词，在图中的距离会相对较近**。
* 例如，右侧靠近的 `“分支”`、`“核心”`、`“人工智能”`、`“自然语言”`，以及右上方的 `“机器”`，都处于同一个语义场中，反映了它们在文本中围绕“人工智能/自然语言处理”主题的共现关系。


* **极小语料带来的局限性**：
* 图中有些词的分布显得比较分散或孤立（例如左侧的 `“模型”`、顶部的 `“能力”`、`“信息”`、右下角的 `“学习”` 等）。
* **原因**：正如前面所分析的，输入的初始语料库**非常小**（仅有 4 句话）。Word2Vec 模型需要海量文本才能充分捕捉词与词之间的深层统计规律。在语料极少的情况下，模型无法学习到完美的语义聚类，因此降维后的点显得较为散乱，部分直观语义相近的词未必能完美聚拢在一起。



#### 2. 坐标轴的含义

* **PCA 元素 1（横轴）与 PCA 元素 2（纵轴）**：
* 它们是通过 PCA（主成分分析）从原始的 10 维词向量空间中提取出的两个**正交的主成分**。
* 横轴代表方差最大（包含信息最多）的第一个主成分方向，纵轴代表第二个主成分方向。
* 图中的数值（如横轴从 `-0.15` 到 `0.15`，纵轴从 `-0.15` 到 `0.15`）表示词向量在投影后对应主成分轴上的相对坐标值。

1. `jieba` 中文分词成功切分了句子。
2. `Word2Vec` 成功基于词频训练出了嵌入矩阵。
3. `PCA` 成功完成了高维到低维的降维转化。
