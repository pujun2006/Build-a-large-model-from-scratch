Text Data Preprocessing.py代码展示了在自然语言处理（NLP）中非常经典的**文本数据预处理（Text Preprocessing）**流程。代码分别针对**英文文本**和**中文文本**构建了清洗函数，利用 `pandas` 处理数据表格，并使用 `re`（正则表达式）模块来清除噪声、统一格式。

以下是对整段代码的详细拆解和说明：

---

### 一、 英文文本预处理部分

这部分演示了如何清洗包含杂质、HTML标签、数字和标点的英文文本。

#### 1. 准备示例数据

```python
data = {
    'text': [
        "  Hello world! This is an example text with numbers 123 and symbols #, @, and so on.   ",
        "Here's another sentence: it contains HTML tags like <html> and & symbols.",
        "Numbers, punctuations...and STOP words are in this sentence!"
    ]
}
df = pd.DataFrame(data)

```

创建了一个包含 3 行原始英文文本的 Pandas DataFrame，文本中故意夹杂了多余的空格、标点符号、数字以及 HTML 标签。

#### 2. 定义英文预处理函数 `preprocess_text(text)`

```python
def preprocess_text(text):
    # 1. 去除前后空格
    text = text.strip()

    # 2. 转换为小写
    text = text.lower()

    # 3. 去除HTML标签
    text = re.sub(r'<.*?>', '', text)

    # 4. 去除数字
    text = re.sub(r'\d+', '', text)

    # 5. 去除特殊字符（保留字母和空格）
    text = re.sub(r'[^a-zA-Z\s]', '', text)

    # 6. 去除多余空格
    text = re.sub(r'\s+', ' ', text)

    return text

```

* **步骤 1 (`strip`)**：去除字符串首尾的空白字符（如空格、换行符）。
* **步骤 2 (`lower`)**：将所有字母转换为小写。这是为了避免模型将 "Hello" 和 "hello" 视为两个不同的词，减少词表大小。
* **步骤 3 (`re.sub(r'<.*?>', '', text)`)**：使用正则表达式匹配并删除 HTML 标签（如 `<html>`、`<div>` 等）。`.*?` 表示非贪婪匹配，防止误删大段内容。
* **步骤 4 (`re.sub(r'\d+', '', text)`)**：`\d+` 匹配一个或多个连续的数字，将其替换为空字符串（即删除所有数字）。
* **步骤 5 (`re.sub(r'[^a-zA-Z\s]', '', text)`)**：
* `^` 在中括号内表示**取反（否定）**。
* `a-zA-Z` 表示所有大小写英文字母，`\s` 表示空白字符。
* 整体含义是：**删除所有既不是英文字母、也不是空格的字符**（比如 `#`, `@`, `!`, `.` 等标点符号）。


* **步骤 6 (`re.sub(r'\s+', ' ', text)`)**：`\s+` 匹配一个或多个连续的空格、制表符或换行符，将其统一压缩为**单个半角空格**，清理由于前面删掉标点或数字后留下的多余空白。

#### 3. 应用与输出

```python
df['processed_text'] = df['text'].apply(preprocess_text)

```

利用 Pandas 的 `.apply()` 方法将函数作用于每一行文本，生成清洗后的新列 `processed_text`。

### 二、 中文文本预处理部分

中文文本的结构与英文不同，没有严格的词间空格，且包含中文标点、全角字符和汉字。

#### 1. 准备示例数据

```python
data = {
    'text': [
        """
        在自然语言处理领域，数据预处理是不可或缺的重要步骤。对于中文文本数据来说...
        （包含大量中文长文本、标点符号、全角空格及数字等）
        """
    ]
}
df = pd.DataFrame(data)

```

定义了一段包含丰富中文标点、英文单词、数字和换行的中文长文本段落。

#### 2. 定义中文预处理函数 `preprocess_chinese_text(text)`

```python
def preprocess_chinese_text(text):
    # 1. 去除前后空格
    text = text.strip()

    # 2. 转换为小写
    text = text.lower()

    # 3. 去除标点符号和特殊字符（保留汉字、字母和数字）
    text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)

    # 4. 处理全角空格转换为半角空格
    text = re.sub(r'\u3000', ' ', text)

    # 5. 去除多余空格
    text = re.sub(r'\s+', ' ', text)

    return text

```

* **步骤 1 & 2**：同样先去除首尾空白并转小写（对中文无影响，但能规范化文本中可能夹杂的英文字母）。
* **步骤 3 (`re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', '', text)`)**：
* `\u4e00-\u9fa5` 是 Unicode 编码中常用汉字（基本区）的范围。
* `a-zA-Z0-9\s` 分别代表英文字母、数字和空白。
* `^` 取反，意味着**删去所有不属于汉字、英文字母、数字和空白的字符**（如中文的 `，`、`！`、`“ ”` 等标点符号）。


* **步骤 4 (`re.sub(r'\u3000', ' ', text)`)**：`\u3000` 是中文排版中常见的**全角空格**（占一个汉字宽度的空格），这里将其统一转换为标准的半角空格 `' '`。
* **步骤 5**：将连续的空格、换行符压缩为单个空格，保持文本整洁。

---

### 三、 总结

这段代码的核心价值在于：

1. **标准化（Normalization）**：通过大小写转换、全半角转换、空格规整，消除文本表面的格式差异。
2. **去噪（Noise Reduction）**：利用正则表达式精准剥离 HTML 标签、数字、各类标点符号和特殊符号，保留对自然语言理解有价值的核心内容（英文单词或汉字）。
3. **向量化前置准备**：为后续的词表构建、分词（Tokenization）和模型输入打下干净、高质量的基础。
