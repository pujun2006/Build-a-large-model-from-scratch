Cyclical Learning Rate Scheduling.py代码的核心目标是：**在 PyTorch 中使用官方内置的 `CyclicLR` 模块，对一个简单的神经网络进行训练，并通过 Matplotlib 将学习率在训练过程中的周期性波动曲线直观地画出来。**

---

## 一、 代码整体架构

整个脚本可以清晰地划分为 6 个核心部分：

1. **模型定义**（构建一个双层全连接神经网络）
2. **初始化与配置**（实例化模型、损失函数、优化器）
3. **循环学习率调度器设置**（配置 `CyclicLR` 的上下界与周期）
4. **模拟数据生成**（构造虚拟的输入与标签）
5. **核心训练循环**（前向传播、反向传播、权重更新、学习率更迭、指标记录）
6. **可视化展示**（绘制学习率随 Step 变化的波动曲线）

---

## 二、 逐段详细拆解

### 1. 模型定义部分

```python
class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.fc1 = nn.Linear(10, 50)
        self.fc2 = nn.Linear(50, 1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

```

* 构建了一个包含一个隐藏层的多层感知机（MLP）：
* 输入层：10 维特征。
* 隐藏层：50 维神经元，并使用非线性激活函数 `ReLU`。
* 输出层：1 维输出。



### 2. 初始化与优化器配置

```python
model = SimpleModel()
criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)

```

* **`MSELoss`**：均方误差损失函数，常用于回归任务。
* **`optim.SGD`**：使用随机梯度下降优化器。初始学习率设为 `0.01`（虽然会被后续的 `CyclicLR` 动态接管）。

### 3. 循环学习率调度器设置（核心亮点）

```python
scheduler = CyclicLR(
    optimizer, 
    base_lr=0.001,    # 最小学习率 (下界)
    max_lr=0.01,      # 最大学习率 (上界)
    step_size_up=50,  # 学习率从 base_lr 上升到 max_lr 所需的步数 (Step)
    mode='triangular' # 循环模式：标准三角波
)

```

* **`base_lr` 与 `max_lr**`：规定了学习率波动的上下边界（在 `0.001` 到 `0.01` 之间循环）。
* **`step_size_up=50`**：表示学习率从下界爬升到上界需要经历 50 个训练步（Step）。下降阶段通常默认与上升阶段对称（也是 50 步），即一个完整的循环周期是 100 个 Step。
* **`mode='triangular'`**：采用标准的“三角波”模式，即上升和下降都是线性的，且振幅保持恒定。

### 4. 模拟数据准备

```python
data = torch.randn(50, 10)
target = torch.randn(50, 1)

```

* 构造了 50 个样本（每个样本 10 维特征）以及对应的 50 个随机标签，用于模拟真实的训练数据集。

### 5. 核心训练循环（Training Loop）

```python
num_epochs = 20  # 总共训练 20 个 Epoch (总计 20 * 50 = 1000 个 Step)
for epoch in range(num_epochs):
    for batch in range(len(data)):
        inputs = data[batch].unsqueeze(0)  # 单个样本输入
        labels = target[batch].unsqueeze(0)

        # ① 前向传播
        outputs = model(inputs)
        loss = criterion(outputs, labels)

        # ② 反向传播与权重更新
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        # ③ 更新学习率 (必须紧跟在 optimizer.step 之后)
        scheduler.step()

        # ④ 实时记录当前的学习率
        lr_list.append(optimizer.param_groups[0]['lr'])

```

* **步数计算**：每个 Epoch 有 50 个 Batch，总共 20 个 Epoch，因此整个训练过程会执行 **1000 个训练步（Step）**。
* **学习率记录**：通过 `optimizer.param_groups[0]['lr']` 准确抓取了每一歩更新后的实际生效学习率，并存入 `lr_list` 数组中。

### 6. 可视化模块

```python
plt.figure(figsize=(10, 5))
plt.plot(lr_list, label="Cyclic Learning Rate", color="blue")
plt.xlabel("Training Step", fontsize=12)
plt.ylabel("Learning Rate", fontsize=12)
plt.title("Cyclic Learning Rate Schedule (Triangular Mode)", fontsize=14)
plt.legend()
plt.grid(True, linestyle="--", alpha=0.6)
plt.show()

```

* 使用 `matplotlib` 将 1000 个 Step 中学习率的变化轨迹绘制成折线图。
* 你会从图中清晰地看到：学习率呈周期性地从 `0.001` 线性上升到 `0.01`，再线性下降回 `0.001`，周而复始（在 1000 步内刚好完整循环了 10 个周期）。
