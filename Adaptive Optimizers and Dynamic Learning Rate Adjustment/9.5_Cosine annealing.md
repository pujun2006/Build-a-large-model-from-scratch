Cosine annealing.py代码展示了在 PyTorch 中使用官方的 `LambdaLR` 模块，实现“Warmup（预热） + 余弦退火（Cosine Annealing）”组合学习率调度策略的标准工业级写法。

---

## 一、 代码整体架构

整个脚本分为 5 个核心部分：

1. **模型与优化器准备**：定义简单的线性层，并使用大模型训练标配的 `AdamW` 优化器。
2. **超参数定义**：设定总步数、Warmup 步数以及最大学习率与最小学习率。
3. **核心 Lambda 映射函数**：通过数学逻辑精确控制每一步的学习率缩放比例。
4. **调度器初始化**：将优化器与 Lambda 函数绑定。
5. **训练循环模拟**：在每一步训练中同步更新模型权重与学习率。

---

## 二、 逐段详细拆解

### 1. 模型与优化器初始化

```python
model = nn.Linear(10, 1)
optimizer = optim.AdamW(model.parameters(), lr=1e-3)

```

* **`AdamW`**：大模型预训练中最常用的优化器，它将权重衰减（Weight Decay）从梯度更新中解耦出来，能有效防止过拟合。
* **`lr=1e-3`**：这是该优化器的**基础学习率（Base LR）**。在 PyTorch 的 `LambdaLR` 中，所有由 Lambda 函数计算出来的值，最终都会**乘以**这个基础学习率。

---

### 2. 超参数定义

```python
total_steps = 1000     # 整个训练周期的总步数 (Step)
warmup_steps = 100     # 前 100 步进行预热
max_lr = 1e-3          # 最大学习率（与优化器初始 lr 保持一致）
min_lr = 1e-4          # 最小学习率（余弦退火终点，通常为 max_lr 的 10%）

```

* 这里明确了时间维度是以 **Step（批次步数）** 为单位，而不是 Epoch，这符合大模型训练的实际工程习惯。

---

### 3. 核心学习率映射函数（`lr_lambda`）—— **全代码精华**

`LambdaLR` 要求传入一个接收当前步数 `current_step` 并返回一个乘数因子（Multiplier）的函数。这个乘数因子乘以 Base LR（`1e-3`）就等于当前步的实际学习率。

该函数分为两个阶段：

#### 阶段 A：Warmup（预热）阶段（`current_step < warmup_steps`）

```python
if current_step < warmup_steps:
    return float(current_step) / float(max(1, warmup_steps))

```

* **逻辑**：当步数从 `0` 增长到 `100` 时，返回值从 `0.0` 线性增长到 `1.0`。
* **实际学习率**：`0.0 * 1e-3 = 0` 逐渐增长到 `1.0 * 1e-3 = 1e-3 (max_lr)`。
* **作用**：防止初期模型参数随机、梯度巨大时发生数值崩溃。

#### 阶段 B：余弦退火阶段（`current_step >= warmup_steps`）

```python
else:
    # 1. 计算余弦衰减的归一化进度 (从 0 变到 1)
    progress = float(current_step - warmup_steps) / float(max(1, total_steps - warmup_steps))
    
    # 2. 计算余弦衰减系数 (值域在 0 到 1 之间)
    cosine_decay = 0.5 * (1.0 + torch.cos(torch.tensor(progress * 3.1415926535)))
    
    # 3. 将其线性映射到 [min_lr, max_lr] 对应的乘数区间
    lr_range = (max_lr - min_lr) / max_lr
    return min_lr / max_lr + lr_range * cosine_decay

```

* **进度计算**：`progress` 表示度过 Warmup 后，剩余训练进程完成了百分之多少（从 0% 到 100%）。
* **余弦波动**：`torch.cos(...)` 让数值按照余弦曲线平滑下降。`0.5 * (1.0 + cos(...))` 将余弦函数原本的 `[-1, 1]` 范围完美压缩到 `[0, 1]`。
* **区间映射**：通过 `min_lr / max_lr + lr_range * cosine_decay`，确保最终算出来的乘数因子在 `min_lr / max_lr`（即 `0.1`）到 `1.0` 之间平滑过渡，最终乘以 Base LR 就能得到位于 `[1e-4, 1e-3]` 之间的实际学习率。

---

### 4. 调度器初始化

```python
scheduler = LambdaLR(optimizer, lr_lambda=lr_lambda)

```

* 将优化器与自定义规则绑定。此后每调用一次 `scheduler.step()`，它就会自动把当前的 `current_step` 传给 `lr_lambda`，计算出因子并更新到 `optimizer.param_groups[0]['lr']` 中。

---

### 5. 训练循环与步进更新

```python
for step in range(total_steps):
    # 实际项目中这里会有：forward -> loss -> backward
    optimizer.step()
    scheduler.step()  # 必须在 optimizer.step() 之后调用！
    
    # 每 200 步打印一次验证
    if step % 200 == 0:
        print(f"Step {step}, LR: {optimizer.param_groups[0]['lr']:.6f}")

```

* **调用顺序规范**：在 PyTorch 的现代训练规范中，**`optimizer.step()` 负责更新模型权重，`scheduler.step()` 负责更新学习率**。两者通常成对出现，且 `scheduler.step()` 紧跟在 `optimizer.step()` 后面。
