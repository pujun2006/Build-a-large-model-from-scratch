Dynamic learning rate.py代码的核心目的是**演示如何在 PyTorch 中定义一个简单的神经网络模型，并使用自定义的线性衰减策略（Linear Decay）在训练过程中动态调整优化器的学习率（Learning Rate）**。

---

## 一、 代码整体架构

整个脚本可以分为以下 5 个核心部分：

1. **模型定义**（构建一个简单的线性回归模型）
2. **初始化**（实例化模型与优化器）
3. **学习率调度函数**（自定义线性衰减逻辑）
4. **训练循环**（前向传播、计算损失、反向传播、更新参数、动态调参）
5. **结果记录与输出**（打印每个周期的学习率与损失）

---

## 二、 逐段代码详细拆解

### 1. 模型定义部分

```python
import torch
import torch.optim as optim
import torch.nn as nn
import numpy as np

# 简单的模型
class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.fc = nn.Linear(10, 1) # 输入维度 10，输出维度 1

    def forward(self, x):
        return self.fc(x)

# 模型实例化
model = SimpleModel()
# 使用随机梯度下降优化器，初始学习率设为 0.1
optimizer = optim.SGD(model.parameters(), lr=0.1)

```

* **`nn.Module`**：PyTorch 中所有神经网络的基类。
* **`nn.Linear(10, 1)`**：定义了一个全连接线性层，包含 10 个输入特征和 1 个输出特征，内部包含权重 $W$ 和偏置 $b$。
* **`optim.SGD`**：使用随机梯度下降（Stochastic Gradient Descent）作为优化器，传入模型的参数 `model.parameters()`，让其能够根据梯度更新权重。

---

### 2. 自定义学习率衰减函数

```python
# 自定义线性衰减学习率调度器
def linear_decay(epoch, total_epochs, initial_lr, final_lr):
    # 根据线性衰减公式，计算当前的学习率
    return initial_lr - (initial_lr - final_lr) * (epoch / total_epochs)

```

* **核心数学逻辑**：这是一个简单的线性插值/衰减公式。
* 当 `epoch = 0` 时，计算结果为 `initial_lr`（0.1）。
* 当 `epoch = total_epochs` 时（虽然代码中 `epoch` 从 0 到 19，刚好在结束前），学习率会逐渐靠近 `final_lr`（0.01）。
* 随着 `epoch` 增加，`epoch / total_epochs` 逐渐变大，减去的数值也变大，从而实现学习率随训练进行而**线性下降**的效果。



---

### 3. 超参数与记录容器定义

```python
# 超参数定义
total_epochs = 20
initial_lr = 0.1
final_lr = 0.01

# 记录学习率变化，用于后续观察
lr_history = []

```

* 定义了总训练轮数（20轮）、起始学习率（0.1）和结束学习率（0.01）。
* `lr_history` 用于把每轮调整后的学习率保存下来，方便最后核对。

---

### 4. 核心训练循环（Training Loop）

这是代码中最关键的部分，每一轮（Epoch）执行以下步骤：

```python
for epoch in range(total_epochs):
    # ① 动态调整学习率
    lr = linear_decay(epoch, total_epochs, initial_lr, final_lr)
    for param_group in optimizer.param_groups:
        param_group['lr'] = lr
    lr_history.append(lr)
    
    # ② 模拟训练过程（生成随机数据）
    model.train()
    inputs = torch.randn(5, 10) # 5个样本，每个样本10维特征
    labels = torch.randn(5, 1)  # 5个对应的真实标签
    
    # ③ 优化器梯度清零
    optimizer.zero_grad()
    
    # ④ 前向传播：计算模型预测值
    outputs = model(inputs)
    
    # ⑤ 计算损失（均方误差损失 MSE）
    loss = nn.MSELoss()(outputs, labels)
    
    # ⑥ 反向传播：计算梯度
    loss.backward()
    
    # ⑦ 参数更新：优化器根据当前学习率调整模型权重
    optimizer.step()
    
    # 打印当前的 epoch、学习率和损失
    print(f"Epoch {epoch+1}/{total_epochs}, Learning Rate: {lr:.6f}, Loss: {loss.item():.6f}")

```

#### 关键细节说明：

1. **动态修改学习率**：
```python
for param_group in optimizer.param_groups:
    param_group['lr'] = lr

```


PyTorch 的优化器通过 `param_groups`（参数组列表）来管理学习率。这里通过直接修改 `param_group['lr']`，将自定义函数算出来的 `lr` 赋给优化器，这样下一步 `optimizer.step()` 就会使用更新后的学习率。
2. **标准训练五部曲**：
* `optimizer.zero_grad()`：清空上一轮残留的梯度。
* `outputs = model(inputs)`：前向计算。
* `loss = ...`：计算预测值与真实值的差距。
* `loss.backward()`：自动求导，计算出每个参数的梯度。
* `optimizer.step()`：根据梯度和当前学习率更新模型参数。



---

### 5. 结果输出

```python
# 显示学习率随epoch的变化
print("\nLearning rate schedule:")
for epoch, lr in enumerate(lr_history):
    print(f"Epoch {epoch+1}: Learning Rate = {lr:.6f}")

```

* 训练结束后，遍历记录的 `lr_history`，打印出每一轮对应的学习率，直观展示随时间推移线性递减的过程。
