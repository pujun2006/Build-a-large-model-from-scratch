Warmup.py代码展示了如何按照 PyTorch 官方的标准开发规范，编写一个自定义的 **Warmup（预热）学习率调度器**，并在训练循环中正确地与优化器配合使用。

---

## 一、 代码整体架构

整个脚本分为 5 个核心模块：

1. **模型与优化器初始化**：构建基础线性模型，并配置优化器。
2. **自定义调度器类（继承 `LRScheduler`）**：重写 `get_lr()` 方法，精确控制前期的线性增长与后期的稳定。
3. **调度器实例化**：传入超参数。
4. **模拟训练数据与损失函数**：搭建一个标准的训练框架。
5. **双循环训练与实时更新**：在每个 Batch 结束后同步更新权重与学习率。

---

## 二、 逐段详细拆解

### 1. 模型与优化器准备

```python
model = SimpleModel()
# 优化器的初始 lr 直接设为你期望的目标峰值学习率
optimizer = optim.Adam(model.parameters(), lr=0.01)  

```

* **`Adam` 优化器**：使用自适应动量优化器。
* **`lr=0.01`**：这里设定的初始学习率代表了 **Peak LR（峰值学习率）**。在后续的调度器中，`self.base_lrs` 会自动捕获这个值，作为计算时的基准。

---

### 2. 自定义调度器类（核心精华）

这是代码中最关键的部分，它继承自 PyTorch 2.0+ 推荐的公开基类 `LRScheduler`。

```python
class WarmupScheduler(LRScheduler):
    def __init__(self, optimizer, warmup_steps, peak_lr, last_epoch=-1):
        self.warmup_steps = warmup_steps
        self.peak_lr = peak_lr
        super(WarmupScheduler, self).__init__(optimizer, last_epoch)

    def get_lr(self):
        # 获取当前训练的步数 (PyTorch 的 last_epoch 从 -1 开始，每调用一次 step() 会加 1)
        current_step = self.last_epoch + 1
        
        if current_step < self.warmup_steps:
            # 阶段一：线性 Warmup 增长
            return [self.peak_lr * (current_step / self.warmup_steps) for _ in self.base_lrs]
        else:
            # 阶段二：保持峰值学习率不变
            return [self.peak_lr for _ in self.base_lrs]

```

#### 关键技术点解析：

1. **`self.last_epoch` 的妙用**：
* 在 PyTorch 的调度器基类中，`self.last_epoch` 记录了当前的步数（或者 Epoch 数）。在初始化时它默认是 `-1`。
* 每当执行一次 `scheduler.step()`，`last_epoch` 就会自动加 `1`。因此，用 `current_step = self.last_epoch + 1` 可以精准追踪当前是第几步。


2. **返回列表的形式 (`[ ... for _ in self.base_lrs ]`)**：
* 为什么 `get_lr()` 返回的是一个列表？因为 PyTorch 的优化器支持**多参数组（Parameter Groups）**（即不同的网络层可以设置不同的学习率）。
* 代码中使用列表推导式，确保优化器中有几个参数组，就返回几个对应的学习率。这里只有一个 `linear` 层，所以返回含一个元素的列表。


3. **两段式逻辑**：
* 当 `current_step < warmup_steps`（例如前 100 步）：学习率从 `0` 线性增加到 `peak_lr`（0.01）。
* 当 `current_step >= warmup_steps`（第 100 步及之后）：学习率锁定在 `peak_lr` 不变。



---

### 3. 调度器初始化

```python
warmup_steps = 100  
peak_lr = 0.01     # 峰值学习率
scheduler = WarmupScheduler(optimizer, warmup_steps=warmup_steps, peak_lr=peak_lr)

```

* 将优化器对象与我们写好的 `WarmupScheduler` 绑定，并设定前 100 步进行预热，峰值为 0.01。

---

### 4. 模拟训练循环与步进更新

```python
for epoch in range(5):  # 训练 5 个 Epoch
    for batch in range(50):  # 每个 Epoch 内包含 50 个 Batch (总计 250 步)
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()      # ① 优化器更新模型权重
        scheduler.step()      # ② 调度器更新学习率 (必须紧跟在 optimizer.step 之后)

        # 获取当前生效的学习率用于观察
        current_lr = scheduler.get_last_lr()[0]
        print(f"Epoch: {epoch + 1}, Batch: {batch + 1}, Learning Rate: {current_lr:.6f}, Loss: {loss.item():.6f}")

```

#### 训练时的学习率演变轨迹：

* **第 1 个 Epoch 的前 50 步**：`current_step` 从 0 增长到 49，学习率从 `0.000000` 线性增长到 `0.004900`。
* **第 2 个 Epoch 的前 50 步**：`current_step` 从 50 增长到 99，学习率继续增长到 `0.009900`。
* **第 2 个 Epoch 的第 51 步开始（即 `current_step >= 100`）**：触发 `else` 分支，学习率正式达到峰值 `0.010000`，并在后续的所有训练中保持不变。
