LAMB.py代码实现了一个使用 **PyTorch** 从零手写的 **LAMB 优化器**（Layer-wise Adaptive Moments Optimizer），并用它来训练一个简单的线性回归模型（拟合 $y = 3x + 2$ 的噪声数据），最后绘制出训练过程中的损失曲线并输出训练后的参数。

下面对该代码的各个部分进行详细的拆解说明。

---

### 一、 各步骤代码详解

#### 1. Step 1: 导入所需库

```python

import torch.optim as optim
import math
import matplotlib

```

* 导入了 PyTorch 核心模块、神经网络模块 (`nn`)、优化器基类 (`optim`)、数学库 (`math`) 以及画图库 (`matplotlib`)。
* `matplotlib.use('TkAgg')` 用于指定图形渲染后端，防止在某些操作系统或 IDE 中执行 `plt.show()` 时报错或无法弹出窗口。

---

#### 2. Step 2: 定义 LAMB 优化器

LAMB 优化器是一种结合了 **Adam** 的自适应动量特性和 **Layer-wise（分层）信任比率调整** 的优化算法，非常适合大批量（Large Batch）训练深度学习模型。

* **`__init__` 初始化方法**：
继承自 `optim.Optimizer`。接收超参数：学习率 `lr`、动量参数 `betas`（$\beta_1, \beta_2$）、数值稳定常数 `eps` 以及权重衰减系数 `weight_decay`。
* **`step` 参数更新核心逻辑**：
遍历网络中每一层的参数组和具体参数：
1. **初始化状态**：如果当前参数是第一次更新，为其创建并初始化步数 (`step`)、一阶动量 (`exp_avg`) 和二阶动量 (`exp_avg_sq`)。
2. **更新动量**：
计算梯度的一阶矩（指数加权平均）和二阶矩。
3. **计算自适应学习率与偏差修正**：
类似 Adam，计算带有偏差修正的一阶和二阶矩估计。
4. **计算信任比率（Trust Ratio）的核心精髓**：
计算参数自身的范数 $r_1 = \Vert{}w\Vert{}$ 与更新方向（动量）的范数 $r_2 = \Vert{}r\Vert{}$。如果两者均不为 0，则计算比率 `trust_ratio = r1 / r2`。这一步能够防止不同层的更新步幅过大或过小，使网络各层能自适应地调整学习步长。
5. **权重衰减与参数更新**：
应用权重衰减并根据计算出的 `step_size` 和 `trust_ratio` 更新模型参数。

#### 3. Step 3: 定义简单模型与数据集

```python
class SimpleLinearModel(nn.Module):
    def __init__(self):
        super(SimpleLinearModel, self).__init__()
        self.linear = nn.Linear(1, 1)  # 输入维度1，输出维度1

    def forward(self, x):
        return self.linear(x)

# 生成带有随机噪声的线性训练数据
torch.manual_seed(42)
x_train = torch.linspace(0, 10, 100).view(-1, 1)
y_train = 3.0 * x_train + 2.0 + torch.randn(x_train.size()) * 2.0

```

* **模型结构**：定义了一个单入单出的线性全连接层（即一元线性回归模型 $y = wx + b$）。
* **数据生成**：在 $0$ 到 $10$ 之间均匀采样 $100$ 个点作为输入 $x$，真实函数为 $y = 3x + 2$，并加入了服从正态分布的随机噪声（标准差为 2），用来测试优化器的拟合能力。

---

#### 4. Step 4 & 5: 初始化与训练循环

```python
model = SimpleLinearModel()
optimizer = LAMB(model.parameters(), lr=0.01)
criterion = nn.MSELoss()  # 均方误差损失函数

losses = []
num_epochs = 200

for epoch in range(num_epochs):
    y_pred = model(x_train)
    loss = criterion(y_pred, y_train)  # 计算均方误差
    losses.append(loss.item())

    optimizer.zero_grad()  # 梯度清零
    loss.backward()        # 反向传播计算梯度
    optimizer.step()       # 使用自定义的 LAMB 优化器更新参数

    if (epoch + 1) % 20 == 0:
        print(f'Epoch [{epoch + 1}/{num_epochs}], Loss: {loss.item():.4f}')

```

* 标准的 PyTorch 训练流程：**前向传播 $\rightarrow$ 计算 Loss $\rightarrow$ 梯度清零 $\rightarrow$ 反向传播 $\rightarrow$ 优化器更新**。
* 每隔 20 个 epoch 打印一次当前的损失值（Loss），以便观察训练收敛情况。

---

#### 5. Step 6 & 7: 结果可视化与参数输出

```python
# 绘制损失下降曲线
plt.plot(range(num_epochs), losses)
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training Loss with LAMB Optimizer')
plt.show()

# 输出最终学到的权重和偏置
print("\n模型的权重和偏置：")
for name, param in model.named_parameters():
    print(f"{name}: {param.data}")

```

* **绘图**：画出 200 个 Epoch 内 Loss 随时间下降的曲线图。
* **参数打印**：输出训练结束后模型学到的权重。
