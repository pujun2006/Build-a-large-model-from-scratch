5 Classic Learning Rate Schedulers.py代码将原本独立的、分散的学习率调度器写法进行了模块化封装，通过一个**工厂函数（`get_scheduler`）**和一个统一的**训练框架（`train_with_scheduler`）**，让您可以轻松对比和测试不同的学习率衰减方案。

## 一、 代码整体架构

整个脚本可以划分为 5 个核心部分：

1. **模型定义**（构建一个简单的线性回归神经网络）
2. **模拟数据与损失函数准备**（生成固定伪数据以保证实验结果稳定）
3. **调度器工厂函数**（根据输入的名称字符串创建并返回对应的学习率调度器）
4. **统一的训练与调度主函数**（封装了模型训练、学习率更新、指标监控与日志打印）
5. **批量测试入口**（循环调用 5 种调度器，直观对比它们的学习率演变效果）

### 2. 调度器工厂函数（`get_scheduler`）

这是整段代码的核心切换枢纽，分别实现了 PyTorch 中最具代表性的 5 种学习率调度器：

```python
def get_scheduler(optimizer, scheduler_type):
    if scheduler_type == "StepLR":
        # 1. 阶梯衰减：每 10 个 epoch 将学习率乘以 0.1
        return StepLR(optimizer, step_size=10, gamma=0.1)
    
    elif scheduler_type == "ExponentialLR":
        # 2. 指数衰减：每个 epoch 学习率衰减为原来的 95% (lr = lr * 0.95^epoch)
        return ExponentialLR(optimizer, gamma=0.95)
    
    elif scheduler_type == "ReduceLROnPlateau":
        # 3. 自适应平台衰减：当 loss 连续 5 个 epoch 不下降时，学习率乘以 0.5
        return ReduceLROnPlateau(optimizer, mode='min', factor=0.5, patience=5)
    
    elif scheduler_type == "CosineAnnealingLR":
        # 4. 标准余弦退火：在 T_max (50个epoch) 内将学习率平滑衰减到最小值
        return CosineAnnealingLR(optimizer, T_max=50)
    
    elif scheduler_type == "CosineAnnealingWarmRestarts":
        # 5. 带热重启的余弦退火：T_0=10代表首个周期10个epoch，T_mult=2代表每次重启后周期翻倍
        return CosineAnnealingWarmRestarts(optimizer, T_0=10, T_mult=2)

```

### 3. 统一训练函数与监控逻辑（`train_with_scheduler`）

```python
def train_with_scheduler(scheduler_name, num_epochs=50):
    model = SimpleModel()
    optimizer = optim.SGD(model.parameters(), lr=0.1)  # 初始学习率设为 0.1
    scheduler = get_scheduler(optimizer, scheduler_name)
    
    for epoch in range(num_epochs):
        model.train()
        optimizer.zero_grad()
        
        # 前向传播与计算损失
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        
        # 反向传播与权重更新
        loss.backward()
        optimizer.step()
        
        # 获取当前生效的学习率
        current_lr = optimizer.param_groups[0]['lr']
        
        # 【核心区别点】ReduceLROnPlateau 需要传入当前的性能指标（loss）
        if scheduler_name == "ReduceLROnPlateau":
            scheduler.step(loss.item())
        else:
            scheduler.step()  # 其他调度器直接无参调用
            
        # 打印日志
        if (epoch + 1) % 10 == 0 or epoch == 0:
            print(f"Epoch {epoch+1:2d}/{num_epochs} | Loss: {loss.item():.4f} | Learning Rate: {current_lr:.6f}")

```

#### 代码中的关键工程细节：

1. **隔离性**：每次调用 `train_with_scheduler` 时，都会重新实例化一个新的 `model` 和 `optimizer`，确保 5 种调度器互不干扰、各自从头开始演变。
2. **`ReduceLROnPlateau` 的特殊调用方式**：
* 前 4 种调度器（`StepLR`、`ExponentialLR` 等）是“时间驱动”的，只要调用 `scheduler.step()` 就会机械地根据 epoch 数改变学习率。
* 唯独 `ReduceLROnPlateau` 是“指标驱动”的，它必须把当前的 `loss.item()` 传进去（`scheduler.step(loss.item())`），以便它内部去判断模型是不是遇到了性能瓶颈（Plateau）。

### 4. 批量执行入口

```python
if __name__ == "__main__":
    schedulers_to_test = [
        "StepLR", 
        "ExponentialLR", 
        "ReduceLROnPlateau", 
        "CosineAnnealingLR", 
        "CosineAnnealingWarmRestarts"
    ]
    
    for name in schedulers_to_test:
        train_with_scheduler(name, num_epochs=50)

```

* 通过一个列表将这 5 种经典策略串联起来，程序会依次运行每种调度器并打印出对应的 50 个 Epoch 里的 Loss 和 Learning Rate 变化轨迹，方便直观比对它们的衰减特性。
