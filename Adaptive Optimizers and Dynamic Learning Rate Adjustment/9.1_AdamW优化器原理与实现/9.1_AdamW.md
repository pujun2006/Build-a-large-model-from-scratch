AdamW.py代码使用 **PyTorch** 框架构建并训练了一个简单的**一元线性回归模型**（模拟目标函数 $y = 2x + 3 + \text{噪声}$），并使用 **AdamW 优化器**来更新参数。


下面按步骤详细拆解和说明这段代码的运行逻辑：

---

### 一、 核心步骤逐段解析

#### 1. 导入依赖（Step 1）

```python
import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib
matplotlib.use('TkAgg')  # 解决 IDE 绘图后端报错问题
import matplotlib.pyplot as plt

```

* 导入 PyTorch 核心模块、神经网络工具箱 (`nn`)、优化器 (`optim`) 以及用于可视化的 `matplotlib`。
* `matplotlib.use('TkAgg')` 用于在部分 IDE（如 PyCharm）中强制指定独立的 GUI 绘图窗口，避免因兼容性引发 `FigureCanvas` 报错。

#### 2. 定义线性回归模型类（Step 2）

```python
class LinearRegressionModel(nn.Module):
    def __init__(self):
        super(LinearRegressionModel, self).__init__()
        self.linear = nn.Linear(1, 1)  # 输入维度1，输出维度1

    def forward(self, x):
        return self.linear(x)

```

* **面向对象建模**：继承自 `nn.Module`。
* **`nn.Linear(1, 1)`**：定义了一个全连接线性层，内部包含一个权重（Weight，w）和一个偏置（Bias，b），数学表达式为 $y = wx + b$。
* **`forward` 函数**：定义了模型的前向传播逻辑，输入 $x$ 经过线性层后输出预测值。

#### 3. 生成模拟训练数据（Step 3）

```python
torch.manual_seed(0)
x_train = torch.linspace(0, 10, 100).view(-1, 1)
y_train = 2 * x_train + 3 + torch.randn(x_train.size()) * 2

```

* `torch.manual_seed(0)` 固定随机种子，确保每次运行生成的随机数据和初始权重一致，结果可复现。
* `torch.linspace(0, 10, 100).view(-1, 1)` 生成在 $[0, 10]$ 之间均匀分布的 100 个点，并通过 `.view(-1, 1)` 转换为形状为 `(100, 1)` 的二维列向量（适配线性层的输入要求）。
* 构造真实关系：y = 2x + 3，并加上服从正态分布的随机噪声 `torch.randn(...) * 2`，用来模拟真实世界中存在误差的观测数据。

#### 4. 初始化模型、优化器与损失函数（Step 4 - 6）

```python
model = LinearRegressionModel()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=0.01)
criterion = nn.MSELoss()

```

* **初始化模型**：实例化 `LinearRegressionModel`（此时权重和偏置是随机初始化的）。
* **AdamW 优化器**：传入模型的参数 `model.parameters()`，设置学习率 `lr=0.01` 和权重衰减系数 `weight_decay=0.01`。
* **损失函数**：使用均方误差（Mean Squared Error, MSE）作为衡量预测值与真实值差距的标准。

#### 5. 训练循环（Step 7 - 8）

```python
num_epochs = 200
losses = []

for epoch in range(num_epochs):
    y_pred = model(x_train)          # 1. 前向传播：计算预测值
    loss = criterion(y_pred, y_train)  # 2. 计算损失
    
    losses.append(loss.item())       # 记录当前损失值用于画图
    
    optimizer.zero_grad()            # 3. 梯度清零（防止历史梯度累加）
    loss.backward()                  # 4. 反向传播：计算梯度
    optimizer.step()                 # 5. 参数更新：AdamW 根据梯度和权重衰减更新 w 和 b

```

整个训练过程重复 200 次（Epoch）：

1. **前向传播**：将输入送入模型，得到当前的预测输出。
2. **计算损失**：计算 MSE Loss。
3. **梯度清零**：清空上一轮残留的梯度。
4. **反向传播**：求导计算损失函数对 $w$ 和 $b$ 的梯度。
5. **参数更新**：调用 `optimizer.step()`，利用 AdamW 算法调整模型的权重和偏置。

#### 6. 可视化与结果输出（Step 9 - 10）

```python
plt.plot(range(num_epochs), losses)
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training Loss with AdamW Optimizer')
plt.show()

print("\n模型参数（权重和偏置）：")
for name, param in model.named_parameters():
    print(f"{name}: {param.data}")

```

* 绘制一条随训练轮数增加而逐渐下降的损失曲线图（Loss Curve），直观展示模型收敛的过程。
* 打印最终学到的参数。由于生成数据时设定的真实参数是 $w=2$、$b=3$，训练结束后，输出的权重和偏置会非常接近这两个数值（例如 $w \approx 2.0$, $b \approx 3.0$ 左右）。
