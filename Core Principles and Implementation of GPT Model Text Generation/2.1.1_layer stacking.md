layer stacking.py代码用 PyTorch 实现了一个简易版的 **GPT-2 核心 Transformer 层堆叠结构**。它完整包含了自注意力机制（Self-Attention）、前馈神经网络（Feed-Forward Network）、LayerNorm 以及层堆叠逻辑。

下面对代码的各个核心模块逐一进行详细拆解说明：

---

### 一、 `SelfAttention`（自注意力机制）

这是整个模型最核心的计算单元，实现了多头自注意力（Multi-Head Attention）。

1. **初始化部分 (`__init__`)**：
* `self.head_dim = embed_size // heads`：将总嵌入维度（`embed_size`）平分给每个注意力头（`heads`）。
* `self.values`, `self.keys`, `self.queries`：定义了用于生成 V（值）、K（键）、Q（查询）的线性变换层。
* `self.fc_out`：多头注意力计算完成后，将所有头拼接起来的输出重新映射回原本的 `embed_size`。


2. **前向传播部分 (`forward`)**：
* **分头变形 (`view`)**：将输入张量形状从 `(N, seq_len, embed_size)` 转换为 `(N, seq_len, heads, head_dim)`，让多头可以并行计算。
* **线性变换**：通过矩阵乘法分别对 Q、K、V 进行投影。
* **计算注意力得分 (`energy`)**：
* `torch.einsum("nqhd,nkhd->nhqk", [queries, keys])`：通过爱因斯坦求和约定计算 Query 和 Key 的点积，得到每个头在各个位置上的相似度得分。
* `/ (self.head_dim ** 0.5)`：缩放因子（Scaling），防止维度过大时点积数值过大导致 Softmax 梯度趋近于 0。


* **掩码处理 (`masked_fill`)**：若传入了 `mask`，则将对应位置填入极小值（如 `-1e20`），经过 Softmax 后权重趋近于 0（GPT-2 在自回归生成时通常会用到因果掩码，确保当前词看不到未来的词）。
* **Softmax 与加权求和**：
* `attention = torch.softmax(energy, dim=-1)`：将得分转换为概率分布。
* 再次通过 `einsum` 将注意力权重与 `values` 相乘求和，得到加权后的特征。


* **多头拼接与输出**：通过 `.reshape()` 将多头的特征拼回原维度，最后通过 `self.fc_out` 输出。



---

### 二、 `FeedForward`（前馈神经网络）

在自注意力机制捕捉到全局上下文特征后，通过 FFN 进行更深层的非线性特征变换。

* 包含两个线性层（Linear）：
1. `fc1`：将维度从 `embed_size` 放大到 `hidden_dim`（通常是 4 倍）。
2. `relu`：使用 ReLU 激活函数（标准的 GPT-2 使用的是更平滑的 **GELU**，这里简化为了 ReLU）。
3. `fc2`：将维度从 `hidden_dim` 降回 `embed_size`。



---

### 三、 `TransformerBlock`（Transformer 单层结构）

这一层组合了自注意力、前馈网络和 **残差连接（Residual Connection）**、**层归一化（Layer Normalization）**。

* **代码中的执行顺序（Post-LN 的微调形态或标准残差结构）**：
1. `attention = self.attention(x, x, x, mask)`：自注意力计算（此处采用自注意力，即 $Q=K=V=x$）。
2. `x = self.norm1(attention + x)`：残差连接（`attention + x`）后进行 Layer Normalization。
3. `forward = self.feed_forward(x)`：通过前馈网络。
4. `out = self.norm2(forward + x)`：再次进行残差连接和归一化。
5. `return self.dropout(out)`：通过 Dropout 防止过拟合。



---

### 四、 `GPT2LayerStack`（GPT-2 整体层堆叠）

* 负责将多个 `TransformerBlock` 串联起来。
* 在 `__init__` 中使用 `nn.ModuleList` 创建了 `num_layers` 个 Transformer 层。
* 在 `forward` 中，输入文本的张量 `x` 会依次穿过这堆叠的若干层（代码中设为了 4 层），逐层提取并丰富语义特征，最终输出深层语义表示。

---

### 五、 模拟输入与运行结果

代码最后通过一组超参数模拟了一次前向推理：

* `batch_size = 2`（批大小为 2）
* `seq_length = 10`（每个样本 10 个 Token）
* `embed_size = 128`（每个 Token 的特征维度为 128）

输出的张量形状为 `(2, 10, 128)`，这表明经过 4 层 Transformer 堆叠后，每个样本的每一个 Token 都被成功转化为融合了全局上下文信息的 128 维特征向量。
