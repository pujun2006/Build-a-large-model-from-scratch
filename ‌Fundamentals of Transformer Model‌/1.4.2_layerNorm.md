layerNorm.py代码不仅实现了**层归一化（Layer Normalization）**的前向与反向传播，还设计了一套完整的**对照实验与多维度验证框架**，直观地演示了 LayerNorm 在面对**输入分布漂移（Distribution Shift）**和**极端数值输入**时的强大稳定性。



下面深度拆解这段代码的设计逻辑与实验原理。

---

## 一、 代码整体架构概述

整个脚本由四个核心阶段组成：

1. **模型定义阶段**：构建了采用 Pre-LN（先归一化后线性映射）结构的 `SimpleLayerNormModel`，以及用于对比的纯全连接网络 `NoLayerNormModel`。
2. **训练模拟阶段**：使用标准正态分布数据 $\mathcal{N}(0, 1)$ 进行了一次前向推理与梯度更新。
3. **分布漂移验证（维度 1 ~ 3）**：构造均值偏移 5、标准差放大 2 倍的测试数据，从**统计量、向量距离、Softmax 置信度**三个维度评估特征稳定性。
4. **极端情况对照实验（维度 4）**：将输入放大 100 倍并偏移 50，直接对比“有 LayerNorm”与“无 LayerNorm”模型的数值抗压能力。

---

## 二、 核心模块与模型结构解析

### 1. `LayerNormBlock`（层归一化基础模块）

```python
class LayerNormBlock(nn.Module):
    def __init__(self, embed_size):
        super(LayerNormBlock, self).__init__()
        self.layer_norm = nn.LayerNorm(embed_size)
        self.fc = nn.Linear(embed_size, embed_size)
        self.relu = nn.ReLU()

    def forward(self, x):
        out = self.layer_norm(x)
        out = self.fc(out)
        out = self.relu(out)
        return out

```

* **`nn.LayerNorm(embed_size)`**：对每个样本的 `128` 维特征独立计算均值 $\mu$ 和方差 $\sigma^2$，将其拉回均值为 0、方差为 1 的标准分布，再乘以可学习的缩放参数 $\gamma$ 并加上偏置 $\beta$。
* **Pre-LN 顺序**：这里采用了先 `LayerNorm` 再 `Linear` 和 `ReLU` 的设计。这意味着无论上一层传来的特征数值有多大，进入全连接层（`self.fc`）之前都会被重新规范化到受控范围内，从源头上防止了激活值爆炸。

### 2. 对照组 `NoLayerNormModel`

去掉了所有的 `nn.LayerNorm`，仅保留 `Linear + ReLU`。在没有归一化的情况下，线性层的矩阵乘法和 ReLU 激活会逐层放大输入数据的尺度（Scale）。

---

## 三、 四大验证维度的核心原理解析

代码后半部分通过 `test_input = torch.randn(4, 128) * 2 + 5` 模拟了真实场景中常见的**协变量偏移（Covariate Shift）**，并从四个角度量化了 LayerNorm 的作用：

| 验证维度 | 评估指标 | 背后的数学与深度学习原理 |
| --- | --- | --- |
| **维度 1：统计量对比** | `mean()` 与 `std()` | 验证**尺度不变性（Scale & Shift Invariance）**。由于 LayerNorm 在第一层就减去了均值、除以了标准差，输入端的平移（`+5`）和缩放（`*2`）在进入第一层 `self.layer_norm` 的瞬间就被数学公式抵消了，因此最终输出的均值与标准差依然维持在零点附近的平稳区间。 |
| **维度 2：向量相似度** | `cosine_similarity` 与 `mse_loss` | 验证**特征空间一致性**。虽然模型仅训练了 1 步（权重基本还是随机初始化的），但由于第一层对输入做了归一化，同一个样本在加了线性偏移前后，其归一化后的方向向量高度相似，防止了特征表示发生剧烈畸变。 |
| **维度 3：Softmax 置信度** | `max_prob`（最大概率值） | 验证**防止模型过度自信（Overconfidence）**。在分类任务中，如果 Logits（未归一化的输出）数值过大（例如 `[100, 2, -50]`），经过 `Softmax` 后最大概率会直接变成 `1.0000`，导致交叉熵梯度趋近于 0（梯度消失）。LayerNorm 限制了 Logits 的幅值，使输出概率保持在健康的平滑分布。 |
| **维度 4：极端对照实验** | `* 100 + 50` 下的统计量 | 直观展示**数值爆炸（Numerical Explosion）**。在 `NoLayerNormModel` 中，输入放大 100 倍经过 3 层 `Linear + ReLU` 后，数值会呈几何级数暴增（标准差可达数千甚至上万）；而 `ln_model` 凭借第一层的归一化直接将 `100` 倍的缩放系数抹平，输出量级与正常输入几乎完全一致。 |

## 五、 补充细节：为何测试前后 `output` 与 `test_output` 仍有轻微差异？

细心观察代码会发现两个导致 `output` 和 `test_output` 并非 100% 相同的因素：

1. **随机噪声不同**：`input_data` 和 `test_input` 是两次独立调用 `torch.randn` 生成的随机矩阵，本身的相对大小关系不同。
2. **模型参数已更新**：在计算 `output` 之后、计算 `test_output` 之前，代码执行了一次 `optimizer.step()`，模型权重已经发生了一次微小的梯度更新。

如果对**同一个输入张量 `x` 分别直接输入 `ln_model(x)` 和 `ln_model(x * 100 + 50)`（不更新权重），由于 LayerNorm 的数学性质 $\text{LN}(a \cdot x + b) = \text{LN}(x)$（在忽略极小值 $\epsilon$ 时），两者的输出结果将会是完全一致的。
