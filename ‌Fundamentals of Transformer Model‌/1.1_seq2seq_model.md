seq2seq_model.py这段代码是一个经典的基于 **PyTorch** 实现的 **Seq2Seq（Sequence-to-Sequence）模型** 基础架构。它采用了 **Encoder-Decoder（编码器-解码器）** 结构，底层使用 **LSTM（长短期记忆网络）**，并包含了 **Teacher Forcing（教师强制）** 机制。

下面逐模块详细拆解这段代码：

---

* **作用**：深度学习训练中由于涉及大量的随机初始化（如权重、Dropout、数据打乱等），每次运行的结果往往不同。固定随机种子可以确保每次运行代码时，生成的随机数完全一致，从而**保证实验结果可复现**。

### 二、 编码器（`Encoder`）

编码器的任务是将输入序列（Source Sequence）逐步压缩并转化为一个固定维度的上下文表示（隐藏状态）。

```python
class Encoder(nn.Module):
    def __init__(self, input_dim, emb_dim, hidden_dim, n_layers, dropout):
        super(Encoder, self).__init__()
        self.embedding = nn.Embedding(input_dim, emb_dim) # 词嵌入层：将离散的词索引转为稠密向量
        self.rnn = nn.LSTM(emb_dim, hidden_dim, n_layers, dropout=dropout, batch_first=True)
        self.dropout = nn.Dropout(dropout)

    def forward(self, src):
        # src: (batch_size, src_len)
        embedded = self.dropout(self.embedding(src))  # (batch_size, src_len, emb_dim)
        outputs, (hidden, cell) = self.rnn(embedded)  # outputs: 序列所有时间步的输出
        return hidden, cell  # 返回最终的隐藏状态和细胞状态作为上下文

```

* **工作流**：
1. 输入的词索引张量先通过 `Embedding` 层变成词向量。
2. 经过 `Dropout` 防止过拟合。
3. 传入 `LSTM`。这里设置了 `batch_first=True`，意味着输入和输出张量的第一维是 `batch_size`。
4. **返回值**：Encoder 会忽略中间的所有 `outputs`，只把最后时刻的隐藏状态 `hidden` 和细胞状态 `cell`（统称为 Context Vector）传递给解码器。



---

### 三、 解码器（`Decoder`）

解码器的任务是根据编码器传来的上下文状态，以及上一步生成的词，逐步预测下一个词。

```python
class Decoder(nn.Module):
    def __init__(self, output_dim, emb_dim, hidden_dim, n_layers, dropout):
        super(Decoder, self).__init__()
        self.embedding = nn.Embedding(output_dim, emb_dim)
        self.rnn = nn.LSTM(emb_dim, hidden_dim, n_layers, dropout=dropout, batch_first=True)
        self.fc_out = nn.Linear(hidden_dim, output_dim) # 全连接层：将隐藏状态映射回词表大小，用于分类预测
        self.dropout = nn.Dropout(dropout)

    def forward(self, trg, hidden, cell):
        trg = trg.unsqueeze(1)  # 增加时间步维度 (batch_size, 1)，因为解码器通常是单步（step-by-step）输入的
        embedded = self.dropout(self.embedding(trg))  # (batch_size, 1, emb_dim)
        output, (hidden, cell) = self.rnn(embedded, (hidden, cell))  # 单步前向传播
        prediction = self.fc_out(output.squeeze(1))  # 映射到词表，输出形状: (batch_size, output_dim)
        return prediction, hidden, cell

```

* **工作流**：解码器在训练和推理时通常**每次只处理一个词**（时间步长度为 1），因此需要用 `unsqueeze(1)` 扩展维度。通过线性层 `fc_out` 输出预测的词表概率分布（Logits）。

### 四、 Seq2Seq 整体模型与 Teacher Forcing（`Seq2Seq`）

这是整个架构的核心粘合剂，连接了 Encoder 和 Decoder，并实现了训练时的关键机制——**Teacher Forcing**。

```python
class Seq2Seq(nn.Module):
    def __init__(self, encoder, decoder, device):
        super(Seq2Seq, self).__init__()
        self.encoder = encoder
        self.decoder = decoder
        self.device = device

    def forward(self, src, trg, teacher_forcing_ratio=0.5):
        batch_size = trg.shape[0]
        trg_len = trg.shape[1]
        trg_vocab_size = self.decoder.fc_out.out_features

        # 创建张量用于存储解码器每一步的输出
        outputs = torch.zeros(batch_size, trg_len, trg_vocab_size).to(self.device)

        # 1. 编码器编码，获取初始隐藏状态
        hidden, cell = self.encoder(src)
        
        # 2. 解码器的第一个输入通常是序列的起始符（这里取目标序列的第一列，即 <sos>）
        input = trg[:, 0]  

        # 3. 循环逐步解码
        for t in range(1, trg_len):
            output, hidden, cell = self.decoder(input, hidden, cell)
            outputs[:, t] = output  # 记录当前步的预测结果
            
            # 4. Teacher Forcing 策略
            teacher_force = random.random() < teacher_forcing_ratio
            top1 = output.argmax(1)  # 模型自己预测出的最高概率的词索引
            
            # 如果触发 Teacher Forcing，下一个输入使用真实标签 trg[:, t]；
            # 否则，使用模型上一步自己预测出的词 top1 作为下一个输入。
            input = trg[:, t] if teacher_force else top1

        return outputs

```

* **什么是 Teacher Forcing？**
* 在训练时，如果模型在第 $t$ 步预测错了，如果不加干预，第 $t+1$ 步的输入就是错的，错误会像滚雪球一样放大（误差累积）。
* **Teacher Forcing** 以一定的概率（如 `0.5`）强制将真实标签（Ground Truth）作为下一步的输入，这能极大地加速模型在初期的收敛速度。

### 五、 训练函数与梯度裁剪（`train`）

```python
def train(model, iterator, optimizer, criterion, clip):
    model.train()
    epoch_loss = 0
    for src, trg in iterator:
        src = src.to(DEVICE)
        trg = trg.to(DEVICE)

        optimizer.zero_grad()
        output = model(src, trg) # 前向传播
        
        # 维度调整：CrossEntropyLoss 要求输入形状为 (N, C)，目标形状为 (N)
        output_dim = output.shape[-1]
        output = output[:, 1:].reshape(-1, output_dim) # 略过第一个 <sos> 标记
        trg = trg[:, 1:].reshape(-1)
        
        loss = criterion(output, trg) # 计算交叉熵损失
        loss.backward()               # 反向传播求梯度
        
        # 梯度裁剪（Gradient Clipping）：防止 RNN 中常见的梯度爆炸（Exploding Gradient）问题
        torch.nn.utils.clip_grad_norm_(model.parameters(), clip)
        
        optimizer.step()              # 更新权重
        epoch_loss += loss.item()
        
    return epoch_loss / len(iterator)

```

* **关键点**：
* **形状变形（Reshape）**：PyTorch 的 `CrossEntropyLoss` 期望输入是二维的 `(batch_size * seq_len, vocab_size)`。因此这里通过切片 `output[:, 1:]`（去掉起始符）并 `reshape` 来匹配损失函数的要求。
* **梯度裁剪 (`clip_grad_norm_`)**：循环神经网络（RNN/LSTM）由于在时间轴上展开，极易发生梯度消失或梯度爆炸。裁剪可以将梯度的模长限制在阈值（如 `CLIP = 1`）以内，保证训练稳定性。
