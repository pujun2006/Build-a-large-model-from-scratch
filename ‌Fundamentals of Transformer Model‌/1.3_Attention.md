Attention.py代码实现了一个基于 PyTorch 的**多头注意力机制（Multi-Head Attention）**，代码结构非常清晰，采用了爱因斯坦求和约定（`torch.einsum`）来处理多头维度的矩阵乘法。

下面详细拆解和分析。

---

## 一、 代码整体架构概述

代码主要包含三个部分：

1. **`SelfAttention` 类**：核心实现类，完成了多头切分、Q/K/V 线性变换、缩放点积注意力计算、多头拼接和最后的线性映射。
2. **测试脚本（前向传播）**：定义了超参数、随机生成输入张量（Batch、Seq_length、Embed_size），并进行了一次完整的前向推理。
3. **`SelfAttentionWithWeights` 子类**：继承自核心类，重写了 `forward` 方法，额外返回了中间计算的**注意力权重（Attention Weights）**，用于可视化或分析。

---

## 二、 核心类 `SelfAttention` 逐段解析

### 1. 初始化 (`__init__`)

```python
def __init__(self, embed_size, heads):
    super(SelfAttention, self).__init__()
    self.embed_size = embed_size
    self.heads = heads
    self.head_dim = embed_size // heads

    assert (
        self.head_dim * heads == embed_size
    ), "Embedding size需要是heads的整数倍"

    # 线性变换用于生成Q、K、V矩阵
    self.values = nn.Linear(self.head_dim, self.head_dim, bias=False)
    self.keys = nn.Linear(self.head_dim, self.head_dim, bias=False)
    self.queries = nn.Linear(self.head_dim, self.head_dim, bias=False)
    self.fc_out = nn.Linear(heads * self.head_dim, embed_size)

```

* **维度划分**：将总嵌入维度 `embed_size` 均分给各个头，每个头的维度为 `head_dim = embed_size // heads`。断言（`assert`）确保两者能整除。
* **线性层定义**：
* 这里为每个头分别定义了 `values`、`keys`、`queries` 的线性变换层。
* *注：在标准 Transformer 经典实现（如 Vaswani 等人的论文）中，通常是用一个全尺寸的 `nn.Linear(embed_size, embed_size)` 一次性映射出所有的头，然后通过 `view` 和 `permute` 拆分。而这里作者采用了**先切分再用独立小线性层**或等效的方式处理（此处输入的最后一维是 `self.head_dim`，见 forward 中的 view 步骤）。*


* **输出投影层 (`self.fc_out`)**：将多头拼接后的特征（维度为 `heads * head_dim`，即总维度 `embed_size`）再通过一个线性层进行特征融合。

---

### 2. 前向传播 (`forward`)

#### 步骤 ①：分头（Reshape）

```python
N = query.shape[0] # Batch size
value_len, key_len, query_len = values.shape[1], keys.shape[1], query.shape[1]

# 分头计算Q, K, V矩阵
values = values.view(N, value_len, self.heads, self.head_dim)
keys = keys.view(N, key_len, self.heads, self.head_dim)
queries = query.view(N, query_len, self.heads, self.head_dim)

```

* 输入张量的原始形状是 `(N, seq_len, embed_size)`。
* 通过 `.view()` 将其变形为 `(N, seq_len, heads, head_dim)`，把嵌入维度拆成了“多头”和“每个头的维度”两个维度。

#### 步骤 ②：线性变换

```python
values = self.values(values)
keys = self.keys(keys)
queries = self.queries(queries)

```

* 对切分后的张量分别通过对应的线性层（作用于最后一个维度 `head_dim`），得到各自的 Q、K、V。

#### 步骤 ③：计算相似度能量 (Energy)

```python
# 计算Q与K的点积除以缩放因子
energy = torch.einsum("nqhd,nkhd->nhqk", [queries, keys]) / (self.head_dim ** 0.5)

```

* **`torch.einsum`（爱因斯坦求和约定）**：
* `nqhd` 代表 Query 维度：`n` (Batch), `q` (Query 序列长度), `h` (Heads), `d` (Head dim)。
* `nkhd` 代表 Key 维度：`n` (Batch), `k` (Key/Value 序列长度), `h` (Heads), `d` (Head dim)。
* `nhqk` 是输出维度：对 `d` 维度（点积求和）进行缩并，最终保留 `n`、`h`、`q`、`k`。


* **缩放**：除以 $\sqrt{d_k}$（即 `self.head_dim ** 0.5`），防止点积数值过大导致 softmax 梯度消失。

#### 步骤 ④：应用 Mask（掩码）与 Softmax

```python
if mask is not None:
    energy = energy.masked_fill(mask == 0, float("-1e20"))

# 计算注意力权重
attention = torch.softmax(energy, dim=-1)

```

* **Mask 机制**：如果传入了 `mask`（例如在解码器中用于遮挡未来的词），会将对应位置的值替换为一个极小负数（`-1e20`），这样经过 softmax 后其权重就会趋近于 0。
* **Softmax**：在最后一个维度（Key 的长度维度 `k`）上计算归一化权重，得到注意力权重矩阵 `attention`，形状为 `(N, heads, query_len, key_len)`。

#### 步骤 ⑤：加权求和与多头拼接

```python
# 注意力权重乘以V
out = torch.einsum("nhql,nlhd->nqhd", [attention, values]).reshape(
    N, query_len, self.heads * self.head_dim
)

return self.fc_out(out)

```

* 第二次 `einsum`：
* `nhql`（注意力权重）：Batch, Heads, Query长, Key/Value长。
* `nlhd`（Value）：Batch, Key/Value长, Heads, Head dim。
* 对 `l`（Key/Value 长度）维度求和，得到 `nqhd`（Batch, Query长, Heads, Head dim）。


* **Reshape 拼接**：将多头维度和特征维度压平：`.reshape(N, query_len, self.heads * self.head_dim)`，这就完成了多头的 **Concat** 操作。
* **线性输出**：通过 `self.fc_out` 得到最终输出。

## 三、 测试与运行结果分析

在脚本的后半部分，设置了以下参数并运行：

* `embed_size = 128`
* `heads = 8` （因此每个头的维度 `head_dim = 128 // 8 = 16`）
* `seq_length = 10`
* `batch_size = 2`

运行输出结果的关键点：

1. **输出形状 (`output.shape`)**：输出为 `torch.Size([2, 10, 128])`。这说明经过多头注意力机制和最后的线性层后，输入的张量形状被完美保持（Batch Size 和序列长度不变，特征维度恢复为了原本的 `embed_size`）。
2. **注意力权重形状 (`attention_weights.shape`)**：形状为 `torch.Size([2, 8, 10, 10])`。
* `2` 代表 Batch size。
* `8` 代表 8 个注意力头（Heads）。
* `10 x 10` 代表由 10 个 Query 和 10 个 Key 计算出的互相关联矩阵（每一行的和为 1）。

## 四、 代码的优缺点与小建议

* **优点**：
* 使用 `torch.einsum` 让多维张量的矩阵乘法和转置变得非常直观、代码行数极少，避免了繁琐的 `permute` 和 `transpose`。
* 逻辑结构严格贴合 Transformer 论文中的数学定义。


* **一个小细节（可以优化的地方）**：
* 在标准的 Transformer 实现中（如 Hugging Face 或官方 PyTorch 的 `nn.MultiheadAttention`），`Q`、`K`、`V` 的线性变换通常是**在分头之前**完成的（即先用一个大矩阵映射，再 `view` 和 `permute` 调换维度顺序）。
* 而本代码中是先通过 `.view()` 拆出 `heads` 维度，再用 `nn.Linear` 分别对每个头进行变换。因为 PyTorch 的 `nn.Linear` 支持对任意多维张量的最后一个维度进行线性变换，所以这种写法在数学上同样可行且等效，但标准主流写法更常采用 `permute(0, 2, 1, 3)` 来管理多头维度。
