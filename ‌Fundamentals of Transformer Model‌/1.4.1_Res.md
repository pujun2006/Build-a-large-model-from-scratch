Res.py代码在 PyTorch 中实现了一个简化版的 **ResNet（残差网络）** 架构，并完整演示了其前向传播、损失计算、反向传播（梯度更新）的过程。它完美展示了残差连接（Residual Connection）在实际 CNN 网络中的代码落地。

下面详细拆解和分析。

---

## 一、 代码整体架构概述

代码主要包含三个部分：

1. **`ResidualBlock` 类**：核心残差块，实现了带卷积、批归一化（BatchNorm）、激活函数以及残差跨步相加（Skip Connection）的结构。
2. **`ResNetLike` 类**：整体网络模型，将初始卷积层、多个 `ResidualBlock`、自适应平均池化层以及全连接分类层组合在一起。
3. **测试与训练模拟脚本**：构造了一个模拟的图像输入（如 CIFAR-10 的 $3 \times 32 \times 32$ 图像），执行了一次完整的前向传播、交叉熵损失计算、反向梯度回传（Backpropagation），并打印了参数梯度。

---

## 二、 `ResidualBlock`（残差块）逐段解析

残差块是 ResNet 的灵魂。它的主要逻辑是：**输入 `x` 经过一系列卷积变换后，再与原本的输入 `x`（可能经过维度调整）相加。**

### 1. 初始化 (`__init__`)

```python
def __init__(self, in_channels, out_channels, stride=1, downsample=None):
    super(ResidualBlock, self).__init__()
    # 第一个卷积层（可能改变步长，用于下采样降维）
    self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=stride, padding=1, bias=False)
    self.bn1 = nn.BatchNorm2d(out_channels)
    # 第二个卷积层（步长固定为1，保持维度）
    self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1, bias=False)
    self.bn2 = nn.BatchNorm2d(out_channels)
    self.downsample = downsample
    self.relu = nn.ReLU(inplace=True)

```

* `stride` 和 `downsample`：当输入和输出的通道数（Channels）不同，或者空间尺寸（Height/Width）发生改变时（如 `layer3` 中步长为 2），主干路的张量形状会发生变化。此时，残差支路（即输入 `x`）必须通过一个 `downsample`（通常包含一个 $1 \times 1$ 卷积和 BatchNorm）来调整形状，使其能够与主干路相加。
* **`bias=False`**：在使用了 BatchNorm 的卷积层中，通常会把偏置项 `bias` 设为 `False`，因为 BatchNorm 自带偏置参数（$\beta$），原卷积的偏置会被抵消，多此一举。

### 2. 前向传播 (`forward`)

```python
def forward(self, x):
    identity = x  # 保存残差支路的原始输入（即 x）
    
    # 如果需要对维度进行调整（匹配通道或尺寸）
    if self.downsample is not None:
        identity = self.downsample(x)

    # 主干路：Conv1 -> BN -> ReLU
    out = self.conv1(x)
    out = self.bn1(out)
    out = self.relu(out)

    # 主干路：Conv2 -> BN
    out = self.conv2(out)
    out = self.bn2(out)

    # 【关键的残差连接】：将输入（identity）添加到主干路输出（out）上
    out += identity
    out = self.relu(out) # 相加后再做一次激活

    return out

```

* `out += identity`：实现了数学表达式 $y = F(x) + x$。这保证了即使主干路的卷积学不到好特征，梯度也能通过 `identity` 无损地回传。

## 三、 `ResNetLike`（整体网络）逐段解析

```python
class ResNetLike(nn.Module):
    def __init__(self, num_classes=10):
        super(ResNetLike, self).__init__()
        # 初始特征提取层
        self.layer1 = nn.Conv2d(3, 64, kernel_size=3, stride=1, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)

        # 使用残差块构建网络
        self.layer2 = ResidualBlock(64, 64)  # 输入输出通道相同 (64 -> 64)
        self.layer3 = ResidualBlock(64, 128, stride=2, downsample=nn.Sequential(
            nn.Conv2d(64, 128, kernel_size=1, stride=2, bias=False),
            nn.BatchNorm2d(128)
        )) # 通道数翻倍 (64 -> 128)，空间尺寸减半，启用 downsample
        self.layer4 = ResidualBlock(128, 128) # 输入输出通道相同 (128 -> 128)

        # 全局平均池化和全连接分类层
        self.avgpool = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(128, num_classes)

```

### 数据流向分析 (`forward`)：

1. 输入张量 `x` 的形状是 `(1, 3, 32, 32)`（Batch=1, 通道=3, 高宽=32x32）。
2. 经过 `layer1`、`bn1`、`relu` 后，变为 `(1, 64, 32, 32)`。
3. 经过 `layer2`，通道和尺寸不变：`(1, 64, 32, 32)`。
4. 经过 `layer3`，步长为 2 导致高宽减半，同时通道数变为 128：`(1, 128, 16, 16)`（此时触发了 `downsample` 调整 `identity` 形状）。
5. 经过 `layer4`，形状保持：`(1, 128, 16, 16)`。
6. **`self.avgpool(x)`**：自适应平均池化将任意大小的高宽压扁为 `1x1`，形状变为 `(1, 128, 1, 1)`。
7. **`torch.flatten(x, 1)`**：展平为二维矩阵，形状变为 `(1, 128)`。
8. **`self.fc(x)`**：通过全连接层映射为分类结果，形状变为 `(1, 10)`（对应 10 个类别的 Logits）。

## 四、 模拟训练与梯度检查

```python
# 损失和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 模拟训练步骤
target = torch.tensor([1])  # 假设的目标类别（第1类）
optimizer.zero_grad()       # 清空历史梯度
loss = criterion(output, target) # 计算交叉熵损失
loss.backward()             # 反向传播，计算梯度
optimizer.step()            # 优化器根据梯度更新权重

print("训练损失:", loss.item())

# 检查残差块中的参数更新情况
for name, param in model.layer2.named_parameters():
    print(f"{name}: {param.grad}")

```

* **`loss.backward()` 的秘密**：得益于残差连接（`out += identity`），在反向传播时，误差梯度不仅会流经 `conv1` 和 `conv2` 这条繁重的计算支路，还会有一条支路通过 `identity` 直接无损地加回到输入端。这种“高速公路”机制彻底解决了深层 CNN 中的梯度消失问题。
* **`param.grad` 打印**：最后一段代码会打印出 `model.layer2` 中各个权重矩阵（如 `conv1.weight` 等）对应的梯度数值。你可以看到它们不再是 `None` 或全 0，说明梯度已经通过残差结构成功回传并计算出来了。
