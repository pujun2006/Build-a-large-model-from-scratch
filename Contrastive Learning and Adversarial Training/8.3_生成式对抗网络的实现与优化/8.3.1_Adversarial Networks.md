Adversarial Networks.py这段代码实现了一个基于 PyTorch 的基础 **GAN（生成式对抗网络）**，用于在经典手写数字数据集 **MNIST** 上进行无监督图像生成训练。

以下是代码各个核心部分的详细拆解说明：

---

### 一、 运行环境与设备初始化

```python
import os
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
import torchvision.utils as vutils
import matplotlib.pyplot as plt
from torch.utils.data import DataLoader

# 检查设备
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

```

* **设备自适应**：脚本会自动检测当前环境是否有可用的 NVIDIA GPU (`cuda`)。如果有，模型和后续的数据会放入显卡加速；如果没有，则退回到 CPU 运行。

---

### 二、 网络架构定义

GAN 的核心是由两个互相对抗的网络组成：

#### 1. 生成器（Generator）

```python
class Generator(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(True),
            nn.Linear(256, 512),
            nn.ReLU(True),
            nn.Linear(512, 1024),
            nn.ReLU(True),
            nn.Linear(1024, output_dim),
            nn.Tanh()
        )

    def forward(self, x):
        return self.model(x)

```

* **作用**：输入一个随机噪声向量（维度为 `latent_dim`），通过多层全连接（Linear）网络和非线性激活函数（ReLU），逐步放大维度，最终输出一个与图像展平后大小相同的向量（`output_dim`，即 $784$）。
* **输出激活函数**：最后一层使用 `Tanh()` 激活函数，将输出值映射到 $[-1, 1]$ 区间，这与经过同样归一化处理的真实图像数据范围相匹配。

#### 2. 判别器（Discriminator）

```python
class Discriminator(nn.Module):
    def __init__(self, input_dim):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(input_dim, 1024),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(1024, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.model(x)

```

* **作用**：接收一个图像向量（真实图像或生成器产生的假图像），通过多层全连接网络进行特征提取和二分类判断。
* **激活函数**：中间层使用 `LeakyReLU`（负斜率为 0.2），防止神经元坏死；最后一层使用 `Sigmoid()`，将输出压缩到 $[0, 1]$ 的概率区间，表示输入图像为“真实图像”的置信度。

### 三、 超参数与数据集准备

```python
# 超参数设置
latent_dim = 100        # 生成器输入的噪声维度
image_dim = 28 * 28     # MNIST图像展开后的维度 (784)
lr = 0.0002             # 学习率
batch_size = 64         # 批大小
epochs = 50             # 训练轮数

# 数据加载
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5])  # 归一化到[-1, 1]
])

dataset = datasets.MNIST(root='./data', train=True, transform=transform, download=True)
dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

```

* **数据预处理**：`transforms.ToTensor()` 将 PIL 图像转换为张量并将像素值缩放到 $[0, 1]$；`Normalize([0.5], [0.5])` 将其进一步线性变换到 $[-1, 1]$，以配合生成器最后的 `Tanh` 激活输出。
* **数据加载器**：利用 `DataLoader` 将 MNIST 数据集分批（每批 64 张）打乱加载。

---

### 四、 损失函数与优化器初始化

```python
# 初始化生成器和判别器并移动到设备
generator = Generator(latent_dim, image_dim).to(device)
discriminator = Discriminator(image_dim).to(device)

# 损失函数和优化器
criterion = nn.BCELoss()
optimizer_G = optim.Adam(generator.parameters(), lr=lr)
optimizer_D = optim.Adam(discriminator.parameters(), lr=lr)

```

* **损失函数**：使用二元交叉熵损失（`BCELoss`），用于衡量判别器预测结果与真实标签（真为 1，假为 0）之间的差距。
* **优化器**：均采用 `Adam` 优化器，学习率统一设为 `0.0002`（这是 GAN 训练中比较经典且稳健的超参数选择）。

---

### 五、 核心训练循环

整个训练过程通过双重循环（Epoch 轮数 $\rightarrow$ Batch 批次）展开，每批次分为**训练判别器**和**训练生成器**两个步骤：

```python
for epoch in range(epochs):
    for i, (real_images, _) in enumerate(dataloader):
        current_batch_size = real_images.size(0)
        real_images = real_images.view(current_batch_size, -1).to(device)

        # 创建真实标签和虚假标签
        real_labels = torch.ones(current_batch_size, 1).to(device)
        fake_labels = torch.zeros(current_batch_size, 1).to(device)

```

#### 1. 训练判别器（Maximizing Discriminator's performance）

判别器的目标是：**对真图输出接近 1 的概率，对假图输出接近 0 的概率**。

```python
        optimizer_D.zero_grad()
        
        # A. 判别真实图像
        outputs = discriminator(real_images)
        d_loss_real = criterion(outputs, real_labels)

        # B. 生成假图像并判别
        z = torch.randn(current_batch_size, latent_dim).to(device)
        fake_images = generator(z)
        # 使用 .detach() 阻断梯度传回生成器，确保此时只更新判别器参数
        outputs = discriminator(fake_images.detach())
        d_loss_fake = criterion(outputs, fake_labels)

        # C. 汇总判别器总损失并反向传播更新
        d_loss = d_loss_real + d_loss_fake
        d_loss.backward()
        optimizer_D.step()

```

#### 2. 训练生成器（Minimizing Generator's loss / Fooling Discriminator）

生成器的目标是：**让判别器把生成的假图像错判为真实图像（即让判别器输出接近 1）**。

```python
        optimizer_G.zero_grad()
        
        # 将刚才（或重新）生成的假图像再次输入判别器
        outputs = discriminator(fake_images)
        # 此时标签设为 real_labels (1)，代表生成器希望判别器认为它们是真的
        g_loss = criterion(outputs, real_labels)
        
        g_loss.backward()
        optimizer_G.step()

```

* **博弈逻辑**：在这一步中，由于用了 `fake_images` 直接通过判别器，梯度会通过判别器回传给生成器，促使生成器学会调整自身的权重，吐出更逼真的图像。

### 六、 图像生成与本地保存

```python
def show_generated_images(generator, latent_dim, num_images=25, save_path="generated_images.png"):
    generator.eval() # 切换到评估模式
    with torch.no_grad(): # 禁用梯度计算以节省内存
        z = torch.randn(num_images, latent_dim).to(device)
        generated_images = generator(z).view(-1, 1, 28, 28).cpu()

    # 将多张图像拼接成一个网格 (5x5)
    grid_img = vutils.make_grid(generated_images, nrow=5, normalize=True)

    plt.figure(figsize=(6, 6))
    plt.imshow(grid_img.permute(1, 2, 0).squeeze(), cmap="gray")
    plt.axis('off')

    # 保存图像到本地
    plt.savefig(save_path, bbox_inches='tight', pad_inches=0.1)
    plt.close()  # 关闭画布，释放内存
    print(f"图像已成功保存至: {os.path.abspath(save_path)}")

show_generated_images(generator, latent_dim)

```

* 训练结束后，代码会随机抽取一组噪声向量输入已经训练好的生成器，得到一批手写数字图像张量。
* 利用 `torchvision.utils.make_grid` 将这 25 张图像拼成一个 $5 \times 5$ 的网格矩阵，并使用 `matplotlib` 渲染成灰度图，最终以无白边、紧凑的格式保存在本地路径下。
