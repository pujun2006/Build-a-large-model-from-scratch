### 三、 模型架构设计 (`BertClassifier`)

```python
class BertClassifier(nn.Module):
    def __init__(self):
        super(BertClassifier, self).__init__()
        self.bert = BertModel.from_pretrained('bert-base-uncased')
        self.classifier = nn.Linear(self.bert.config.hidden_size, 2)  # 二分类
        
    def forward(self, input_ids=None, attention_mask=None, inputs_embeds=None):
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask, inputs_embeds=inputs_embeds)
        cls_output = outputs.last_hidden_state[:, 0, :]  # [CLS] token的输出
        return self.classifier(cls_output)

```

* **主干网络**：加载预训练的 `BertModel`，提取文本深层语义特征。
* **兼容性设计**：`forward` 函数同时支持标准的 `input_ids`（离散索引输入）和 `inputs_embeds`（对抗训练时传入的连续嵌入向量输入）。
* **分类头**：提取 BERT 输出序列中第一个特殊的 `[CLS]` 标记（常用于整句分类任务），通过一个线性层（`nn.Linear`）映射为 2 维向量，对应二分类的 Logits。

### 四、 FGM 对抗训练核心类 (`FGM`)

对抗训练的核心思想是在输入（或嵌入空间）中人为加入微小的、恶意的“扰动”，迫使模型学习抵抗这些扰动，从而提高模型的鲁棒性和泛化能力。

```python
class FGM:
    def __init__(self, model):
        self.model = model
        self.backup = {}

    def attack(self, epsilon=1.0, emb_name='word_embeddings'):
        # 1. 寻找嵌入层参数，备份原始参数，并根据梯度添加扰动
        for name, param in self.model.named_parameters():
            if param.requires_grad and emb_name in name:
                self.backup[name] = param.data.clone()
                norm = torch.norm(param.grad)
                if norm != 0 and not torch.isnan(norm):
                    r_at = epsilon * param.grad / norm
                    param.data.add_(r_at)

    def restore(self, emb_name='word_embeddings'):
        # 2. 恢复模型的原始嵌入参数
        for name, param in self.model.named_parameters():
            if param.requires_grad and emb_name in name:
                if name in self.backup:
                    param.data.copy_(self.backup[name])
        self.backup = {}

```

* **`attack` 方法**：锁定 BERT 的词嵌入层（`word_embeddings`），计算当前损失关于嵌入层的梯度 $\nabla_{emb}$。根据梯度的方向，沿着最容易使损失变大的方向施加大小为 $\epsilon$（`epsilon=1.0`）的微小扰动。
* **`restore` 方法**：在对抗前向传播计算完毕后，将嵌入层的参数恢复为原始数值，保证正常的优化器步骤（Optimizer Step）不受污染。

### 五、 训练循环与对抗优化过程

训练循环展示了标准的 **FGM 对抗训练五步法**：

```python
for epoch in range(5):
    for input_ids, attention_mask, labels in dataloader:
        # 1. 正常前向传播与损失计算
        optimizer.zero_grad()
        outputs = model(input_ids=input_ids, attention_mask=attention_mask)
        loss = criterion(outputs, labels)
        
        # 2. 对正常损失进行反向传播，计算出嵌入层的梯度
        loss.backward(retain_graph=True)
        
        # 3. 对抗训练：在嵌入空间添加扰动
        fgm.attack(epsilon=1.0, emb_name='word_embeddings')
        
        # 4. 再次前向传播（基于对抗扰动后的嵌入）
        embedding_output = model.bert.embeddings(input_ids)
        adv_outputs = model(inputs_embeds=embedding_output, attention_mask=attention_mask)
        adv_loss = criterion(adv_outputs, labels)
        
        # 5. 对抗损失反向传播，并恢复原始嵌入参数后更新优化器
        adv_loss.backward()
        fgm.restore(emb_name='word_embeddings')
        optimizer.step()

```

1. **正常前向+反向**：计算基础交叉熵损失，并保留计算图（`retain_graph=True`）以获取梯度。
2. **FGM 攻击**：利用刚才算出的梯度，对词嵌入层加扰动。
3. **对抗前向**：传入加了扰动后的嵌入计算对抗损失（`adv_loss`）。
4. **累加梯度并恢复**：对抗损失反向传播（梯度会累加到模型参数中），随后调用 `restore` 恢复干净的嵌入权重。
5. **参数更新**：调用 `optimizer.step()`，让模型同时从正常样本和对抗样本中学习。

### 六、 推理预测函数 (`predict`)

```python
def predict(text):
    model.eval()
    tokens = dataset.tokenizer(text, padding='max_length', truncation=True, max_length=128, return_tensors='pt')
    input_ids, attention_mask = tokens['input_ids'].to(device), tokens['attention_mask'].to(device)
    
    with torch.no_grad():
        output = model(input_ids=input_ids, attention_mask=attention_mask)
        prediction = torch.argmax(output, dim=1)
    return "Positive" if prediction.item() == 1 else "Negative"

```

* 将模型切入评估模式（`model.eval()`），关闭梯度计算（`torch.no_grad()`），对输入文本进行分词后送入模型，通过 `torch.argmax` 获取概率最大的类别索引（0 代表 Negative，1 代表 Positive）。
