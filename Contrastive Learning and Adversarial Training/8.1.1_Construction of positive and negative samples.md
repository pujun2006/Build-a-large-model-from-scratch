Construction of positive and negative samples.py这段代码实现了一个基于 **三元组（Triplet Loss）范式的简易对比学习框架**。它使用 PyTorch 在 CIFAR-10 数据集上演示了如何让模型通过“拉近正样本、推远负样本”来无监督地学习图像特征。

下面详细拆解这段代码的运行机制与核心逻辑。

---

### 一、 数据准备与增强模块（Data Augmentation & Dataset）

对比学习成败的关键在于**数据增强的质量**。代码中定义了两种不同的增强流派：

```python
transform1 = transforms.Compose([
    transforms.RandomResizedCrop(32),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor()
])

transform2 = transforms.Compose([
    transforms.RandomResizedCrop(32),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.4, contrast=0.4),
    transforms.ToTensor()
])

```

* `transform1` 与 `transform2`：它们都包含随机裁剪（`RandomResizedCrop`）和水平翻转（`RandomHorizontalFlip`）。但 `transform2` 额外加了**颜色抖动（`ColorJitter`）。
* **设计意图**：通过不同的增强组合，使同一张图片生成两个视觉上略有差异的“视图”（View）。模型如果能认出它们是同一个东西，就必须忽略颜色和局部的干扰，学到图像本质的语义。

#### 自定义数据集 `ContrastiveDataset`

```python
class ContrastiveDataset(Dataset):
    def __init__(self, dataset):
        self.dataset = dataset  # 传入的是未经过 transform 的原始 CIFAR-10（返回 PIL Image）

    def __getitem__(self, index):
        img, _ = self.dataset[index]

        # 1. 锚点与正样本：同一张图做两次不同增强
        anchor = transform1(img)
        positive = transform2(img)

        # 2. 负样本：随机挑选另一张完全不同的图
        neg_index = np.random.choice(len(self.dataset))
        while neg_index == index:
            neg_index = np.random.choice(len(self.dataset))
        neg_img, _ = self.dataset[neg_index]
        negative = transform1(neg_img)

        return anchor, positive, negative

```

* **核心产出**：每次迭代返回三个张量：
1. **Anchor（锚点）**：经过 `transform1` 的原图。
2. **Positive（正样本）**：同一张原图经过 `transform2`（包含颜色抖动）的视图。
3. **Negative（负样本）**：随机抽取的另一张不同图片的增强视图。


* 这样就构成了标准的 **Triplet（三元组）** 结构：`(Anchor, Positive, Negative)`。

### 二、 网络结构模块（Encoder）

```python
class Encoder(nn.Module):
    def __init__(self):
        super(Encoder, self).__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, stride=2, padding=1),  # 输出尺寸: 64 x 16 x 16
            nn.ReLU(),
            nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1), # 输出尺寸: 128 x 8 x 8
            nn.ReLU(),
            nn.Flatten(),
            nn.Linear(128 * 8 * 8, 256)                            # 展平后全连接映射到 256 维特征向量
        )

    def forward(self, x):
        return self.conv(x)

```

* **骨干网络（Backbone）**：这里使用了一个轻量级的纯 CNN 结构。
* **维度推导**：
* 输入 CIFAR-10 图像尺寸为 $3 \times 32 \times 32$。
* 经过第一个 `stride=2` 的卷积后，尺寸减半为 $16 \times 16$。
* 经过第二个 `stride=2` 的卷积后，尺寸再次减半为 $8 \times 8$，通道数变为 128。
* 使用 `nn.Flatten()` 展平后，特征总维数是 $128 \times 8 \times 8 = 8192$。
* 最终通过 `nn.Linear` 映射到 256 维的特征空间中。

### 三、 损失函数模块（ContrastiveLoss / Triplet Loss）

```python
class ContrastiveLoss(nn.Module):
    def __init__(self, margin=1.0):
        super(ContrastiveLoss, self).__init__()
        self.margin = margin

    def forward(self, anchor, positive, negative):
        # 计算 Anchor 与 Positive 之间的欧氏距离
        pos_dist = torch.nn.functional.pairwise_distance(anchor, positive, p=2)
        # 计算 Anchor 与 Negative 之间的欧氏距离
        neg_dist = torch.nn.functional.pairwise_distance(anchor, negative, p=2)
        
        # 目标：让 pos_dist 尽可能小，neg_dist 尽可能大（且拉开至少 margin 的距离）
        loss = torch.mean(torch.clamp(pos_dist - neg_dist + self.margin, min=0.0))
        return loss

```

* **距离计算**：使用欧氏距离（$L_2$ 范数距离）衡量特征向量间的相似程度。
* **核心优化目标**：
* 我们希望 **`pos_dist`（正样本对距离）** 越小越好。
* 我们希望 **`neg_dist`（负样本对距离）** 越大越好，并且要比正样本距离大出至少一个边界值 `margin`（此处设为 1.0）。
* `torch.clamp(..., min=0.0)` 确保当负样本已经足够远（满足 `neg_dist > pos_dist + margin`）时，损失降为 0，避免模型过度优化已经学得很好的样本。

### 四、 训练循环模块（Training Loop）

```python
encoder = Encoder()
contrastive_loss = ContrastiveLoss(margin=1.0)
optimizer = optim.Adam(encoder.parameters(), lr=0.001)

# 训练过程
for epoch in range(5):
    total_loss = 0
    for anchor_img, positive_img, negative_img in dataloader:
        # 1. 前向传播：将三组图像分别送入同一个编码器，提取特征向量
        anchor_emb = encoder(anchor_img)
        positive_emb = encoder(positive_img)
        negative_emb = encoder(negative_img)
        
        # 2. 计算三元组对比损失
        loss = contrastive_loss(anchor_emb, positive_emb, negative_emb)
        
        # 3. 反向传播与参数更新
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    
    print(f"Epoch {epoch + 1}, Loss: {total_loss / len(dataloader):.4f}")

```

* **共享权重（Siamese Network 思想）**：`anchor_img`、`positive_img` 和 `negative_img` 都是通过同一个 `encoder` 提取特征的，这保证了特征空间的统一性。
* **梯度下降**：通过不断调整 CNN 的权重参数，让同一个物体的不同增强视图在 256 维空间中靠拢，而不同物体的特征被推开。

### 六、 总结

这段代码虽然结构精简（没有采用 SimCLR 的大规模 Batch 或 BYOL 的动量网络），但它完美勾勒出了**对比学习的核心闭环**：

1. **数据层面**：巧用增强制造“孪生兄弟”（正样本对）。
2. **架构层面**：用神经网络将图像投影到稠密向量空间。
3. **优化层面**：通过距离约束（Triplet Loss），迫使模型在无任何人工标签的监督下，自动提取出对图像旋转、裁剪、颜色变化具有**不变性**的核心视觉特征。
