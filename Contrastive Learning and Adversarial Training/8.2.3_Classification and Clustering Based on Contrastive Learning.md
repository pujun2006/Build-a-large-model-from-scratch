Classification and Clustering Based on Contrastive Learning.py代码实现了一个基于 PyTorch 的完整图像分类流程。它使用 **CIFAR-10 数据集**，构建了一个包含卷积特征提取器（Encoder）**和**全连接分类头（Classification Head）的神经网络，完成了模型的训练、验证，并最终利用 **t-SNE** 降维技术对模型学习到的高维特征空间进行了可视化。

下面为您对代码的各个核心模块进行详细拆解和说明：

---

### 一、 整体架构与流程

整个脚本可以分为五个主要部分：

1. **数据准备与加载**：下载 CIFAR-10 数据集，进行预处理并划分训练集与验证集。
2. **模型结构定义**：构建卷积特征提取器 `FeatureEncoder` 和分类模型 `ClassificationModel`。
3. **训练与验证逻辑**：实现标准的监督学习训练循环（前向传播、计算损失、反向传播、参数更新）及验证评估。
4. **模型训练**：实例化模型、定义损失函数与优化器，并开始训练。
5. **特征可视化（t-SNE）**：提取验证集中样本的 128 维特征，通过 t-SNE 降维到 2 维并在散点图中展示不同类别的分布。

### 二、 模块详细拆解

#### 1. 数据准备 (Data Preparation)

```python
transform = transforms.Compose([
    transforms.Resize((32, 32)),
    transforms.ToTensor()
])

dataset = datasets.CIFAR10(root="./data", train=True, transform=transform, download=True)
train_size = int(0.8 * len(dataset))
val_size = len(dataset) - train_size
train_dataset, val_dataset = random_split(dataset, [train_size, val_size])

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)

```

* **数据增强/预处理**：将图像统一调整为 $32 \times 32$ 分辨率，并通过 `ToTensor()` 将 PIL 图像或 `numpy` 数组转换为 PyTorch 的 `Tensor`（并将像素值归一化到 `[0.0, 1.0]`）。
* **数据集划分**：使用 `random_split` 将 50,000 张训练集图片按 8:2 的比例划分为训练集（40,000张）和验证集（10,000张）。
* **DataLoader**：将数据集包装成批次（Batch Size = 64），训练集开启 `shuffle=True`（打乱顺序以增加随机性），验证集保持 `shuffle=False`。

#### 2. 模型定义 (Model Definition)

```python
class FeatureEncoder(nn.Module):
    def __init__(self):
        super(FeatureEncoder, self).__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, stride=1, padding=1),  # [B, 3, 32, 32] -> [B, 64, 32, 32]
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                                   # [B, 64, 32, 32] -> [B, 64, 16, 16]
            nn.Conv2d(64, 128, kernel_size=3, stride=1, padding=1), # [B, 64, 16, 16] -> [B, 128, 16, 16]
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                                   # [B, 128, 16, 16] -> [B, 128, 8, 8]
            nn.Flatten(),                                         # [B, 128, 8, 8] -> [B, 128 * 8 * 8]
            nn.Linear(128 * 8 * 8, 128)                           # [B, 8192] -> [B, 128]
        )

    def forward(self, x):
        return self.conv(x)

class ClassificationModel(nn.Module):
    def __init__(self, encoder, num_classes=10):
        super(ClassificationModel, self).__init__()
        self.encoder = encoder
        self.fc = nn.Linear(128, num_classes) # 将 128 维特征映射到 10 个类别

    def forward(self, x):
        features = self.encoder(x)
        return self.fc(features)

```

* **`FeatureEncoder`**：充当特征提取器。包含两个卷积块（卷积层 + ReLU 激活 + 最大池化层），将输入的 3 通道彩色图像（$32 \times 32$）逐步降采样并提取特征，最后通过全连接层将高维特征压缩为 **128 维的嵌入向量（Embedding）**。
* **`ClassificationModel`**：组合模型。它包含上面定义的 `encoder` 和一个线性分类头 `fc`，最终输出 10 个类别的 Logits（对应 CIFAR-10 的 10 个类别：飞机、汽车、鸟等）。

#### 3. 训练与验证逻辑 (Training & Validation)

* **`train_model`**：
* 设置模型为训练模式 (`model.train()`)。
* 遍历每个 Epoch 中的每个 Batch：清空梯度 (`optimizer.zero_grad()`) $\rightarrow$ 前向传播计算输出 $\rightarrow$ 计算交叉熵损失 (`criterion`) $\rightarrow$ 反向传播 (`loss.backward()`) $\rightarrow$ 优化器更新权重 (`optimizer.step()`)。
* 实时统计并打印每个 Epoch 的平均损失（Loss）和准确率（Accuracy）。


* **`validate_model`**：
* 设置模型为评估模式 (`model.eval()`)。
* 使用 `torch.no_grad()` 关闭梯度计算，节省显存并加快计算速度。
* 在验证集上计算整体的 Loss 与 Accuracy，评估模型的泛化能力。

#### 4. 特征可视化 (t-SNE Visualization)

```python
def visualize_embeddings(encoder, loader):
    encoder.eval()
    embeddings = []
    labels = []
    with torch.no_grad():
        for images, label in loader:
            emb = encoder(images).detach().cpu().numpy()
            embeddings.extend(emb)
            labels.extend(label.numpy())

    embeddings = TSNE(n_components=2, random_state=42).fit_transform(embeddings)
    plt.figure(figsize=(8, 8))
    for i in range(10):
        indices = [j for j, lbl in enumerate(labels) if lbl == i]
        plt.scatter(embeddings[indices, 0], embeddings[indices, 1], label=f'Class {i}', alpha=0.6, s=10)
    plt.legend()
    plt.title("t-SNE Visualization of Encoder Features")
    plt.show()

```

* **特征提取**：遍历验证集数据，输入到训练好的 `encoder` 中，获取每个样本的 **128 维特征向量**，并将其转为 NumPy 数组。
* **t-SNE 降维**：使用 `sklearn.manifold.TSNE` 将高维的 128 维特征空间降维到 **2 维平面**。
* **绘图展示**：通过 `matplotlib` 绘制散点图，将 10 个不同类别的样本用不同颜色标出。如果模型训练得当，图上相同类别的点会聚集成团（Cluster），说明编码器成功学会了具区分度的特征表达。
