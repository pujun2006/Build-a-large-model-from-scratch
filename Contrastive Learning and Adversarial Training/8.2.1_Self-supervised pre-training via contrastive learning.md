Self-supervised pre-training via contrastive learning.py代码实现了一个完整的基于 **SimCLR** 框架的自监督对比学习预训练脚本。可以在 PyTorch 中顺利运行并完成训练。

下面详细介绍该代码：

---

### 一、 数据预处理与增强 (`transforms` & `ContrastiveLearningDataset`)

对比学习的灵魂在于**数据增强（Data Augmentation）**。自监督模型没有人工标签，它通过“不变性（Invariance）”来学习特征：无论图像经历何种变换，同一个源图派生出的两个视图在特征空间中都应该是彼此最靠近的。

```python
transform = transforms.Compose([
    transforms.RandomResizedCrop(size=32),  # 随机裁剪并缩放到32x32
    transforms.RandomHorizontalFlip(),  # 50%概率水平翻转
    transforms.ColorJitter(0.4, 0.4, 0.4, 0.4),  # 随机调整亮度、对比度、饱和度、色调
    transforms.ToTensor(),
])

```

* **`ContrastiveLearningDataset`**：
* 重写了 `__getitem__`。当读取数据集中的第 `index` 张图片时，**连续两次调用 `self.transform(img)**`，对同一张原始图片独立进行两次随机增强，生成两个不同的视图 `img1` 和 `img2`（即正样本对）。


* **`DataLoader`**：
* 设置 `batch_size=64`，并开启了 **`drop_last=True`**。这一步至关重要：丢弃最后一个不足 64 张图片的批次，确保每一个 batch 的大小严格一致，从而保证后续损失函数中张量维度的整齐。



---

### 二、 编码器网络 (`Encoder`)

编码器负责将输入图像（$3 \times 32 \times 32$）提取为高维特征表示。

```python
class Encoder(nn.Module):

  def __init__(self):
    super(Encoder, self).__init__()
    self.conv_layers = nn.Sequential(
        nn.Conv2d(3, 64, kernel_size=3, stride=2, padding=1),  # 输出: 64x16x16
        nn.ReLU(),
        nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1),  # 输出: 128x8x8
        nn.ReLU(),
        nn.Conv2d(128, 256, kernel_size=3, stride=2, padding=1),  # 输出: 256x4x4
        nn.ReLU(),
    )
    # 256通道 * 4高度 * 4宽度 = 4096维
    self.fc = nn.Linear(256 * 4 * 4, 128)

  def forward(self, x):
    x = self.conv_layers(x)
    x = x.view(x.size(0), -1)  # 展平为 (BatchSize, 4096)
    return self.fc(x)  # 输出 (BatchSize, 128)

```

* **尺寸推导**：
1. 输入：$32 \times 32$。
2. 经过第 1 层 `stride=2` 卷积后：$32 / 2 = 16$。
3. 经过第 2 层 `stride=2` 卷积后：$16 / 2 = 8$。
4. 经过第 3 层 `stride=2` 卷积后：$8 / 2 = 4$。
5. 最终特征图大小为 $4 \times 4$，通道数是 256，因此展平后为 $256 \times 4 \times 4 = 4096$。全连接层将其映射为 128 维特征。



---

### 三、 投影头 (`ProjectionHead`)

```python
class ProjectionHead(nn.Module):

  def __init__(self, input_dim=128, output_dim=64):
    super(ProjectionHead, self).__init__()
    self.layers = nn.Sequential(
        nn.Linear(input_dim, 128), nn.ReLU(), nn.Linear(128, output_dim)
    )

  def forward(self, x):
    return self.layers(x)

```

* **作用**：SimCLR 论文指出，在编码器后外接一个非线性的 MLP 投影头（将特征映射到更低维空间，如 64 维），可以帮助编码器保留更多对下游任务（如分类）有用的底层/中层特征。
* *注：在预训练完成后，这个投影头通常会被丢弃，只保留 `Encoder` 用于后续的微调或线性探测。*

---

### 四、 核心损失函数：NT-Xent 损失 (`NTXentLoss`)

这是整个代码最精妙、最核心的部分，全称为**归一化温度缩放交叉熵损失（Normalized Temperature-scaled Cross Entropy Loss）**。

其核心逻辑是：**在一个 Batch 中，如果批大小为 $N$，那么会产生 $2N$ 个视图。对于任意一个视图，我们要让它和它的“孪生视图”（正样本）的相似度最高，同时和其他 $2N-2$ 个视图（负样本）的相似度拉开差距。**

```python
class NTXentLoss(nn.Module):

  def __init__(self, temperature=0.5):
    super(NTXentLoss, self).__init__()
    self.temperature = temperature
    self.criterion = nn.CrossEntropyLoss()

  def forward(self, z_i, z_j):
    batch_size = z_i.size(0)  # 即 N (例如 64)

    # 1. L2 归一化：将投影特征投影到单位超球面上 (模长为 1)
    # 这样点积等价于余弦相似度
    z_i = F.normalize(z_i, dim=1)
    z_j = F.normalize(z_j, dim=1)

    # 2. 拼接两个视图的特征：形状从 (N, Dim) 变为 (2N, Dim)
    representations = torch.cat([z_i, z_j], dim=0)

    # 3. 计算全量相似度矩阵：形状为 (2N, 2N)
    # 矩阵中第 (a, b) 个元素代表第 a 个视图和第 b 个视图的相似度分数
    similarity_matrix = (
        torch.matmul(representations, representations.T) / self.temperature
    )

    # 4. 构造对称的目标标签 (大小为 2N)
    # 如果前 N 个是 view1，后 N 个是 view2：
    # 那么第 i 个样本的正样本在 i + N 位置；第 i + N 个样本的正样本在 i 位置
    labels = torch.cat(
        [torch.arange(batch_size) + batch_size, torch.arange(batch_size)], dim=0
    )
    labels = labels.to(z_i.device)

    # 5. 屏蔽自身与自身的相似度
    # 对角线元素是样本与自身的相似度，将其设为负无穷 (-inf)，让 CrossEntropy 忽略它
    mask = torch.eye(2 * batch_size, dtype=bool).to(z_i.device)
    similarity_matrix.masked_fill_(mask, -float('inf'))

    # 6. 计算多分类交叉熵损失
    # 这相当于一个 (2N - 1) 分类任务：模型需要在其余 2N-1 个候选里精准挑出正样本
    loss = self.criterion(similarity_matrix, labels)
    return loss

```

---

### 五、 训练循环与设备适配 (`Training Loop`)

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
encoder = Encoder().to(device)
projection_head = ProjectionHead().to(device)
criterion = NTXentLoss(temperature=0.5)
optimizer = optim.Adam(
    list(encoder.parameters()) + list(projection_head.parameters()), lr=1e-3
)

encoder.train()
projection_head.train()
for epoch in range(5):
  epoch_loss = 0
  for img1, img2 in dataloader:
    # 将双视图数据移动到 GPU 或 CPU
    img1, img2 = img1.to(device), img2.to(device)

    # 1. 前向传播：提取特征并投影
    h_i = encoder(img1)
    h_j = encoder(img2)
    z_i = projection_head(h_i)
    z_j = projection_head(h_j)

    # 2. 计算对比损失
    loss = criterion(z_i, z_j)

    # 3. 反向传播与参数更新
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    epoch_loss += loss.item()

  print(f"Epoch [{epoch + 1}/5], Loss: {epoch_loss / len(dataloader):.4f}")

```

* **端到端训练流**：每轮迭代从 DataLoader 拿出一批双视图，经过 Encoder 和 ProjectionHead 得到投影向量，代入 NT-Xent 损失函数计算出当前批次的对比损失，随后通过梯度下降同时优化编码器和投影头的参数。随着训练推进，Loss 会平稳下降，代表编码器逐渐学会了识别图像的本质特征。
