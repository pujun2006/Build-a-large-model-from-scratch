Downstream Fine-tuning for Contrastive Learning.py代码实现了一个在 PyTorch 中使用预训练编码器（Pre-trained Encoder，如通过 SimCLR 等自监督学习方法训练得到的模型）**进行**线性探测（Linear Probing）的完整流程。

线性探测是评估自监督学习特征质量的经典方法：**固定（冻结）编码器的权重，只训练新接入的线性分类头（Linear Head）**。

下面详细拆解和说明代码：

---

### 1. 编码器结构（`Encoder`）

```python
class Encoder(nn.Module):
    def __init__(self):
        super(Encoder, self).__init__()
        self.conv_layers = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, stride=2, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1),
            nn.ReLU(),
            nn.Conv2d(128, 256, kernel_size=3, stride=2, padding=1),
            nn.ReLU()
        )
        self.fc = nn.Linear(256 * 4 * 4, 128)

```

* **作用**：这是一个基于卷积神经网络（CNN）的特征提取器。
* **输入输出**：输入是 3 通道的彩色图像（如 CIFAR-10 的 $3 \times 32 \times 32$ 图像）。经过三次 `stride=2` 的卷积层后，空间分辨率缩小了 $2^3 = 8$ 倍（$32 \times 32 \rightarrow 16 \times 16 \rightarrow 8 \times 8 \rightarrow 4 \times 4$）。
* **全连接层**：将最终的特征图展平（Flatten），维度为 $256 \times 4 \times 4$，并通过线性层映射到一个 128 维的特征向量。

```python

```

* **数据集**：使用经典图像分类数据集 CIFAR-10（包含 10 个类别的 32x32 彩色图像）。
* **数据划分**：使用 `random_split` 将官方训练集按 8:2 的比例切分为训练集和验证集。
* **DataLoaders**：配置了批大小 `batch_size=64`，并在训练集上开启了 `shuffle=True` 以打乱数据。

### 3. 分类器网络（`Classifier`）

```python
class Classifier(nn.Module):
    def __init__(self, encoder, num_classes=10):
        super(Classifier, self).__init__()
        self.encoder = encoder  
        self.fc = nn.Linear(128, num_classes)  # 添加线性分类头

    def forward(self, x):
        with torch.no_grad():  # 冻结编码器特征提取过程
            features = self.encoder(x)
        return self.fc(features)

```

* **核心思想**：组合了预训练的 `encoder` 和一个新的线性分类头 `fc`。
* **冻结特征（`torch.no_grad()`）**：在 `forward` 函数中使用了 `with torch.no_grad():`，这意味着在训练时**不会计算和更新编码器的梯度**。编码器只负责把输入图像提取成 128 维的特征向量，只有最后的 `self.fc`（128 $\rightarrow$ 10）参与梯度更新。这就是“线性探测”的标准做法，用于检验预训练特征的好坏。

---

### 4. 优化器与损失函数

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

pretrained_encoder = Encoder()
pretrained_encoder = pretrained_encoder.to(device)

classifier = Classifier(pretrained_encoder, num_classes=10).to(device)

# 只对分类头（fc）的参数进行优化（线性探测的标准做法）
optimizer = optim.Adam(classifier.fc.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

```

* **优化目标**：`optimizer = optim.Adam(classifier.fc.parameters(), ...)` 明确指出了**只优化分类头的参数** (`classifier.fc.parameters()`)，编码器的参数保持不变。
* **损失函数**：多分类常用的交叉熵损失 `nn.CrossEntropyLoss()`。

* **验证函数 (`validate`)**：在不计算梯度的前提下（`torch.no_grad()`），在验证集上评估当前模型的平均 Loss 和分类准确率（Accuracy）。

```python
def fine_tune(model, train_loader, val_loader, criterion, optimizer, num_epochs=5, device=device):
    for epoch in range(num_epochs):
        model.train()
        ...
        for images, labels in train_loader:
            images, labels = images.to(device), labels.to(device)
            
            optimizer.zero_grad()
            outputs = model(images)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()
            ...
        # 每个 epoch 结束后评估验证集表现
        val_loss, val_accuracy = validate(model, val_loader, criterion, device)

```

* **训练流程**：标准的 PyTorch 训练循环（前向传播 $\rightarrow$ 计算损失 $\rightarrow$ 清空梯度 $\rightarrow$ 反向传播 $\rightarrow$ 参数更新）。虽然函数名叫 `fine_tune`，但由于内部冻结了编码器，这里实际上执行的是**线性探测（Linear Probing）**。如果想做真正的全量微调（Fine-tuning），可以去掉 `with torch.no_grad()` 并把优化器参数设为 `classifier.parameters()`。
