Data Parallel.py代码是一个基于 **PyTorch** 和 **ResNet-18** 的完整图像分类训练脚本。它使用了经典的 **CIFAR-10 数据集**，并且具备良好的工程实践（如现代预训练权重加载、多卡自动适配等）。

下面对代码的各个组成部分进行由浅入深的逐段详细拆解：

---

### 一、 数据准备与加载

```python
# 1. 数据预处理
transform = transforms.Compose(
    [transforms.Resize((224, 224)), transforms.ToTensor()]
)

# 使用 CIFAR-10 数据集
train_dataset = datasets.CIFAR10(
    root="./data", train=True, download=True, transform=transform
)
# 开启 num_workers 加快数据加载速度
train_loader = DataLoader(
    train_dataset, batch_size=64, shuffle=True, num_workers=2
)

```

1. **数据预处理（`transforms.Compose`）**：
* `transforms.Resize((224, 224))`：CIFAR-10 的原始图片尺寸较小（$32 \times 32$），而 ResNet-18 默认接受 $224 \times 224$ 的输入，这里将其缩放以适配网络。
* `transforms.ToTensor()`：将 PIL 图像或 NumPy 数组转换为 PyTorch 的 `Tensor`，并将像素值归一化到 `[0.0, 1.0]` 范围。


2. **数据集下载与加载**：
* `datasets.CIFAR10` 自动从网络下载并加载训练集。
* `DataLoader` 将数据集打包成批次（`batch_size=64`），`shuffle=True` 确保每个 Epoch 开始时打乱数据顺序。
* `num_workers=2` 启用多进程异步加载数据，防止 GPU 等待 CPU 数据传输造成性能瓶颈。



---

### 二、 模型加载与多卡适配

```python
# 2. 模型加载（使用现代 weights 参数替代已废弃的 pretrained=True）
model = models.resnet18(weights=ResNet18_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, 10)  # 调整输出层用于 CIFAR-10

# 3. 使用 DataParallel 包装模型（多卡并行）
if torch.cuda.device_count() > 1:
  print(f"检测到 {torch.cuda.device_count()} 张 GPU，将使用 DataParallel 训练。")
  model = nn.DataParallel(model)
else:
  print("检测到单张 GPU 或 CPU 环境，按常规单机模式训练。")

# 将模型整体移动到 GPU
model = model.cuda()
model.train()

```

1. **预训练模型加载**：使用现代 PyTorch 推荐的 `weights=ResNet18_Weights.DEFAULT` 加载在 ImageNet 上预训练好的 ResNet-18 权重，能够大幅加快收敛速度并提高精度。
2. **修改全连接层（Classifier Head）**：ResNet-18 默认的输出类别数是 1000（ImageNet）。而 CIFAR-10 只有 10 个类别，因此通过 `model.fc = nn.Linear(...)` 将最后一层全连接的输出维度从 1000 改为 10。
3. **动态多卡适配（`nn.DataParallel`）**：
* 代码会检测当前机器的 GPU 数量。如果大于 1 张，就会自动使用 `nn.DataParallel(model)` 进行包装，实现数据并行。
* 如果是单卡或 CPU 环境，则自动跳过，优雅降级为单机模式，不会报错。


4. **移至 GPU**：通过 `.cuda()` 将模型参数加载到显存中，并设置 `model.train()` 确保 Dropout 和 BatchNorm 处于训练模式。

### 三、 损失函数与优化器定义

```python
# 定义损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.parameters(), lr=0.001, momentum=0.9)

```

* **损失函数**：多分类任务标准的**交叉熵损失（CrossEntropyLoss）**，它内部会自动对模型输出应用 Softmax。
* **优化器**：选用带有动量（`momentum=0.9`）的随机梯度下降（`SGD`），学习率设为 `0.001`，用于根据反向传播的梯度更新模型权重。

---

### 四、 核心训练循环（Training Loop）

```python
# 4. 训练过程
num_epochs = 2
for epoch in range(num_epochs):
  running_loss = 0.0
  for i, (inputs, labels) in enumerate(train_loader):
    inputs, labels = inputs.cuda(), labels.cuda()

    optimizer.zero_grad()

    # 前向传播
    outputs = model(inputs)
    loss = criterion(outputs, labels)

    # 反向传播与优化
    loss.backward()
    optimizer.step()

    running_loss += loss.item()

  print(f"Epoch {epoch+1}, Loss: {running_loss / len(train_loader)}")

```

这段代码执行了标准的 2 个 Epoch 训练迭代，每一步的执行逻辑如下：

1. **数据搬运**：`inputs, labels = inputs.cuda(), labels.cuda()` 将当前 Batch 的图像和标签从内存传输到 GPU 显存。
2. **梯度清零（`optimizer.zero_grad()`）**：清空上一轮迭代留下的梯度累积，防止梯度混淆。
3. **前向传播（Forward）**：将输入送入模型，得到网络预测输出 `outputs`，并计算与真实标签之间的预测误差 `loss`。
4. **反向传播与优化（Backward & Step）**：
* `loss.backward()`：通过链式法则计算网络中每个参数的梯度。
* `optimizer.step()`：根据计算出的梯度，利用 SGD 优化器更新模型的权重参数。


5. **损失累积与打印**：累加每个 Batch 的 Loss 值，并在每个 Epoch 结束时计算并打印平均 Loss，直观展示模型的收敛情况。
