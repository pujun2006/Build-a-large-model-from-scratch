Gradient Accumulation for Text Classification.py代码实现了一个基于 **PyTorch** 的完整文本分类流水线（Sentiment Analysis），使用 **Hugging Face 的 IMDB 数据集**、纯 Python 正则表达式分词、自定义词表、动态 Padding、LSTM 模型以及梯度累积（Gradient Accumulation）技术。

以下是对该代码各部分的详细拆解和说明：

---

### 一、 超参数定义

```python
batch_size = 32
accumulation_steps = 4  # 每4步累积梯度再更新
max_length = 200        # 限制文本最大长度
embedding_dim = 128     # 词嵌入维度
hidden_dim = 256        # LSTM 隐藏层维度
output_dim = 2          # 分类类别数（二分类：正向/负向）
num_epochs = 2          # 训练轮数
lr = 0.001              # 学习率

```

* **`accumulation_steps = 4`**：当显存较小、无法支撑大 Batch Size 时，可以通过梯度累积模拟大 Batch Size。每 4 个小批次（Batch）才执行一次优化器更新（`optimizer.step()`）。

---

### 二、 数据集加载、分词与词表构建

```python
# 1. 加载 IMDB 数据集
dataset = load_dataset("stanfordnlp/imdb")

# 2. 纯 Python 正则分词器
tokenizer = lambda text: re.findall(r"\w+", text.lower())

# 构建词表函数
def build_vocab(dataset_split, max_size=25000):
    counter = Counter()
    for item in dataset_split:
        counter.update(tokenizer(item['text']))
    vocab = {"<pad>": 0, "<unk>": 1} # 特殊符号
    for word, _ in counter.most_common(max_size - 2):
        vocab[word] = len(vocab)
    return vocab

```

* **`load_dataset("stanfordnlp/imdb")`**：从 Hugging Face 快速下载并加载经典电影评论情感分析数据集。
* **分词器（`re.findall`）**：通过正则表达式提取所有连续的字母和数字（`\w+`），并全部转为小写。
* **词表（`build_vocab`）**：统计训练集中所有单词的词频，取前 25,000 个高频词，并为 `<pad>`（填充，ID=0）和 `<unk>`（未知词，ID=1）预留位置。

```python
def collate_batch(batch):
    labels = [item[1] for item in batch]
    texts = [item[0] for item in batch]
    # 动态 Padding：将一个 batch 内的不同长度文本补齐到该 batch 最长文本的长度
    texts_padded = nn.utils.rnn.pad_sequence(texts, batch_first=True, padding_value=0)
    return texts_padded, torch.stack(labels)

```

* **`IMDBDataset`**：继承自 PyTorch 的 `Dataset`，负责将文本转换为对应的词表数字 ID 列表。
* **`collate_batch` 与 `pad_sequence**`：因为每条影评的长度不同，在组装成 Batch 时需要做 Padding（填充 0）。这里采用“动态 Padding”策略——每次只把当前 Batch 内的文本补齐到统一长度，而不是整个数据集都补齐到 200，从而节省显存并提高计算效率。

### 四、 LSTM 模型架构

```python
class LSTMModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, output_dim):
        super(LSTMModel, self).__init__()
        # padding_idx=0 使得 ID 为 0 的填充位不参与梯度更新，且输出全 0
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        embedded = self.embedding(x)
        _, (hidden, _) = self.lstm(embedded)
        return self.fc(hidden[-1]) # 取最后一个时间步的隐状态进行分类

```

1. **`nn.Embedding`**：将输入的词 ID 转换为稠密向量。`padding_idx=0` 非常重要，它能防止 `<pad>` 对模型训练产生干扰。
2. **`nn.LSTM`**：循环神经网络层，负责捕捉文本的上下文语序特征。`batch_first=True` 表示输入的 Tensor 形状为 `(batch_size, seq_len, embedding_dim)`。
3. **分类头（`nn.Linear`）**：提取 LSTM 最后一个时间步的隐藏状态（`hidden[-1]`），通过全连接层映射为 2 个类别的 Logits（对应负向和正向）。

### 五、 训练循环与梯度累积

```python
for epoch in range(num_epochs):
    model.train()
    running_loss = 0.0
    optimizer.zero_grad()  # 每个 Epoch 开始清空一次梯度

    for i, (texts, labels) in enumerate(train_loader):
        texts, labels = texts.cuda(), labels.cuda()

        outputs = model(texts)
        loss = criterion(outputs, labels)

        # 梯度累积：将 Loss 缩放
        loss = loss / accumulation_steps
        loss.backward()

        running_loss += loss.item() * accumulation_steps

        # 判断是否到达累积步数或最后一个 batch
        is_accumulation_step = (i + 1) % accumulation_steps == 0
        is_last_batch = (i + 1) == total_batches

        if is_accumulation_step or is_last_batch:
            optimizer.step()
            optimizer.zero_grad()

```

* **核心机制**：
1. `loss = loss / accumulation_steps`：将损失值按累积步数进行平均，确保多次累积的总梯度大小与直接使用大 Batch 相当。
2. `loss.backward()`：多次前向反向传播，将梯度累加到模型参数的 `.grad` 中。
3. 达到 `accumulation_steps` 后，才调用 `optimizer.step()` 更新权重，随后清空梯度。

### 六、 示例推理

```python
model.eval()
with torch.no_grad():
    sample_text = "The movie was fantastic with great characters and plot"
    tokens = [vocab.get(token, 1) for token in tokenizer(sample_text)]
    tokens_tensor = torch.tensor(tokens, dtype=torch.long).unsqueeze(0).cuda()

    output = model(tokens_tensor)
    prediction = torch.argmax(output, dim=1).item()
    print(f"Sample Prediction (1: positive, 0: negative): {prediction}")

```

* 将测试文本通过相同的分词器和词表转化为 ID 序列。
* 增加一个批次维度（`unsqueeze(0)`），送入训练好的模型中进行前向推理。
* 使用 `torch.argmax` 获得概率最高的类别索引（`1` 代表正向评价，`0` 代表负向评价）。
