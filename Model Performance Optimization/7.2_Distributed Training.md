Distributed Training.py代码是一个专门为 **单卡或无多卡环境（如免费版 Google Colab）** 设计的**单进程“伪分布式”调试与演练脚本**。

它巧妙地利用了 PyTorch 的 `gloo` 后端，在单张 GPU（或 CPU）上拉起一个单进程的进程组（`world_size=1`），从而能够完整跑通分布式框架的初始化、销毁等生命周期代码，而不会触发硬件不足的错误。

下面对这段代码的各个核心部分进行逐段详细拆解：

---

### 一、 分布式环境模拟初始化

```python
# 1. 模拟分布式环境初始化（使用 gloo 后端，支持单机无多卡运行）
os.environ['MASTER_ADDR'] = 'localhost'
os.environ['MASTER_PORT'] = '12355'

# 如果有 GPU 就用 cuda，没有就退回 cpu
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f'当前运行设备: {device}')

# 初始化进程组（world_size=1, rank=0）
dist.init_process_group(backend='gloo', rank=0, world_size=1)

```

* **主节点配置**：`MASTER_ADDR` 和 `MASTER_PORT` 是分布式训练中多进程通信的“寻址地名”和“端口号”。即使在单机单卡上模拟，PyTorch 也需要这两个环境变量来建立通信后台。
* **后端选择（`gloo`）**：
* 在真实的多卡服务器上，我们通常使用性能极高的 `nccl` 后端（专门针对 NVIDIA GPU 优化）。
* 这里使用了 **`gloo`** 后端，因为它支持 CPU 和简单环境，非常适合在单机或没有多张 GPU 的情况下做逻辑测试。


* **进程组初始化**：`dist.init_process_group` 启动了一个规模为 1（`world_size=1`）、编号为 0（`rank=0`）的极简进程组。

### 二、 模型定义

```python
# 2. 模型定义
class SimpleModel(nn.Module):
  def __init__(self):
    super(SimpleModel, self).__init__()
    # 注意：此处原代码带有 diff 符号和断行，实际运行需修复为 28 * 28
    self.fc = nn.Linear(28 * 28, 10)

  def forward(self, x):
    # 将 28x28 的二维图像展平为 784 维的一维向量，输入全连接层
    return self.fc(x.view(-1, 28 * 28))

```



* 这是一个极其简单的全连接神经网络，用于对手写数字（MNIST，尺寸 $28 \times 28$，共 10 个类别）进行分类。

### 三、 数据准备与加载

```python
# 3. 准备数据
transform = transforms.Compose([transforms.ToTensor()])
dataset = datasets.MNIST(
    root='./data', train=True, download=True, transform=transform
)
dataloader = DataLoader(dataset, batch_size=64, shuffle=True)

model = SimpleModel().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)

```

* **数据集**：自动下载并加载经典的 MNIST 手写数字数据集。
* **数据加载器**：由于这里是单进程模拟，所以没有使用多卡专用的 `DistributedSampler`，而是直接用标准的 `DataLoader` 配合 `shuffle=True` 抓取批次数据。
* **组件装配**：将模型加载到指定设备（`device`），并选用多分类常用的交叉熵损失函数（`CrossEntropyLoss`）以及随机梯度下降优化器（`SGD`）。

---

### 四、 标准训练循环

```python
# 4. 训练循环
for epoch in range(2):
  running_loss = 0.0
  for data, target in dataloader:
    # 将数据和标签搬运到 GPU 或 CPU 上
    data, target = data.to(device), target.to(device)

    # 1. 梯度清零
    optimizer.zero_grad()
    # 2. 前向传播
    output = model(data)
    # 3. 计算损失
    loss = criterion(output, target)
    # 4. 反向传播求导
    loss.backward()
    # 5. 更新模型参数
    optimizer.step()

    running_loss += loss.item()

  print(f'Epoch {epoch + 1}, Loss: {running_loss / len(dataloader):.4f}')

```

* 这是一个标准的、经典的 PyTorch 单机训练循环：
1. `optimizer.zero_grad()`：防止上一轮的梯度残留。
2. `model(data)`：前向计算输出预测结果。
3. `loss.backward()`：通过链式法则计算每个参数的梯度。
4. `optimizer.step()`：根据梯度调整模型权重。


* 循环执行 2 个 Epoch，并在每个 Epoch 结束时打印平均 Loss。

---

### 五、 环境清理

```python
# 清理
dist.destroy_process_group()
print('训练成功完成！')

```

* **销毁进程组**：代码运行结束前，必须调用 `dist.destroy_process_group()` 来安全释放底层的通信端口和内存资源，防止资源泄露。
