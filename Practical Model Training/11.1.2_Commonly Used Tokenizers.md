Commonly Used Tokenizers.py代码展示了如何使用 Hugging Face 的 `transformers` 库加载和对比两款经典大语言模型（BERT 与 GPT-2）的**分词器（Tokenizer）**。在自然语言处理（NLP）和大型语言模型工程中，分词器是连接原始文本与神经网络计算的桥梁。

---

下面详细拆解该代码的核心逻辑与底层机制：

### 1. 导入与初始化

```python
from transformers import BertTokenizer, GPT2Tokenizer

# 初始化分词器
bert_tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
gpt_tokenizer = GPT2Tokenizer.from_pretrained("gpt2")

```

* **作用：**
* 从 Hugging Face Hub 下载或加载预训练好的分词器配置文件及词表（Vocabulary）。
* `bert-base-uncased`：使用 **WordPiece** 分词算法，词表大小约为 30,522，且不区分大小写（uncased 会自动将输入转为小写）。
* `gpt2`：使用基于字节对编码（Byte-Level BPE）的算法，词表大小约为 50,257，对大小写和空格极其敏感。



### 2. 文本分词（Tokenization）

```python
text = "Artificial Intelligence is transforming the world."

# 1. 使用 BERTTokenizer
bert_tokens = bert_tokenizer.tokenize(text)
print("BERT 分词结果:", bert_tokens)

# 2. 使用 GPT2Tokenizer
gpt_tokens = gpt_tokenizer.tokenize(text)
print("GPT2 分词结果:", gpt_tokens)

```

* **作用：** `.tokenize()` 方法将连续的字符串切分为子词（Subword）列表。
* **底层差异：**
* **BERT：** 会将单词切分为词表支持的子词。例如，未见过的专业词汇会被拆成带 `##` 前缀的片段。
* **GPT-2：** 使用字节级 BPE，能够处理任意 Unicode 字符。你会发现其分词结果中包含特殊的空格符号（如 `Ġ`），用来标记单词前的空格，这使得它可以完美还原原始文本的空白结构。



### 3. 完整编码流水线（Padding, Truncation & Tensor Conversion）

```python
# BERT编码
bert_encoded = bert_tokenizer(
    text, 
    padding="max_length", 
    max_length=12, 
    truncation=True, 
    return_tensors="pt"
)
print("BERT 编码后的ID:", bert_encoded['input_ids'])
print("BERT Attention Mask:", bert_encoded['attention_mask'])

```

直接对文本调用分词器实例（如 `bert_tokenizer(text, ...)`）会触发完整的编码流水线，输出一个包含多个张量的字典：

* **关键参数解析：**
* `padding="max_length"`：当文本长度小于 `max_length` 时，在指定方向填充特定的填充符（Pad Token）。
* `max_length=12`：限制序列的最大长度为 12 个 Token。
* `truncation=True`：当文本长度超过 12 时自动截断，防止超出模型最大上下文限制。
* `return_tensors="pt"`：将输出结果直接转换为 PyTorch 张量（Tensor），以便直接输入到 GPU/CPU 模型中进行前向计算。


* **输出的核心字段解释：**
* **`input_ids`（输入 ID 序列）：** 文本中每个子词在词表（Vocabulary）中对应的整数索引。对于 BERT，会自动在首尾加上特殊控制符（如 `[CLS]` 和 `[SEP]`）；不足 12 位的会用 `[PAD]` 对应的 ID（通常为 `0`）补齐。
* **`attention_mask`（注意力掩码）：** 一个由 `1` 和 `0` 组成的张量。有效文本对应的位置为 `1`，而由于 `padding` 补齐的空白位置为 `0`。它告诉 Transformer 的自注意力机制（Self-Attention）在计算时**忽略**那些填充位，避免无意义的数值干扰。
