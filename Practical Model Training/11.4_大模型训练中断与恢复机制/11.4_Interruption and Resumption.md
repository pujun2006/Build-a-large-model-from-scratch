Interruption and Resumption.py代码是一个标准的、具备**断点续训（Resumption）能力**的 PyTorch 训练闭环示例。它将**模型前向传播、梯度优化、定期检查点保存以及异常中断后的状态恢复**完美整合在了一起。

下面进行详细的拆解与说明：

---

### 一、 核心模块详细拆解

#### 1. 模型定义部分 (`SimpleModel`)

```python
class SimpleModel(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(SimpleModel, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

```

* **作用：** 继承自 PyTorch 的 `nn.Module`，构建了一个经典的两层多层感知机（MLP / 全连接网络）。
* **结构：** 包含输入层到隐藏层的线性变换（`fc1`）、ReLU 激活函数（`relu`），以及将隐藏层映射到输出层的线性变换（`fc2`），用于执行基础的回归任务。

#### 2. 训练核心函数 (`train`)

```python
def train(model, criterion, optimizer, start_epoch, total_epochs, save_interval, checkpoint_dir='./checkpoints'):
    os.makedirs(checkpoint_dir, exist_ok=True)
    
    for epoch in range(start_epoch, total_epochs):
        model.train()
        
        # 模拟生成随机输入与标签
        inputs = torch.randn(32, 10)
        labels = torch.randn(32, 1)

        # 标准的 PyTorch 训练五步法
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

        current_epoch = epoch + 1

        # 定期保存检查点
        if current_epoch % save_interval == 0:
            checkpoint_path = os.path.join(checkpoint_dir, f"model_epoch_{current_epoch}.pth")
            torch.save({
                'epoch': current_epoch,  # 保存当前已完成的训练轮次
                'model_state_dict': model.state_dict(),  # 模型权重
                'optimizer_state_dict': optimizer.state_dict(),  # 优化器状态（含动量）
                'loss': loss.item(),  # 当前损失值
            }, checkpoint_path)

```

* **灵活的起始轮次 (`start_epoch`)：** 函数接收 `start_epoch` 参数，这使得它既可以从 `0` 开始全新训练，也可以从断点（例如 `10`）无缝接续。
* **状态持久化：** 在满足保存间隔（`save_interval`）时，使用 `torch.save` 将一个字典写入 `.pth` 文件。字典中不仅包含**模型权重**，还完整保存了**优化器状态**（如 Adam 的动量缓存），这是确保断点后模型能够平稳继续训练的关键。

#### 3. 断点续训恢复函数 (`resume_training`)

```python
def resume_training(checkpoint_path, model, optimizer):
    if os.path.isfile(checkpoint_path):
        checkpoint = torch.load(checkpoint_path)
        
        # 核心恢复步骤
        model.load_state_dict(checkpoint['model_state_dict'])
        optimizer.load_state_dict(checkpoint['optimizer_state_dict'])
        
        saved_epoch = checkpoint['epoch']
        loss = checkpoint['loss']
        return saved_epoch
    else:
        return 0

```

* **文件校验：** 通过 `os.path.isfile` 检查指定的检查点文件（如 `model_epoch_10.pth`）是否存在。
* **状态加载：** 若文件存在，利用 `torch.load` 加载字典，并通过 `load_string/load_state_dict` 分别恢复模型和优化器的内部张量状态，最后返回当时中断时的轮次 `saved_epoch`。

#### 4. 主控逻辑与调度 (`if __name__ == "__main__"`)

```python
if __name__ == "__main__":
    input_size = 10
    hidden_size = 20
    output_size = 1

    model = SimpleModel(input_size, hidden_size, output_size)
    criterion = nn.MSELoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001)

    checkpoint_dir = './checkpoints'
    target_checkpoint = os.path.join(checkpoint_dir, "model_epoch_10.pth")

    total_epochs = 20
    save_interval = 5

    # 1. 尝试加载历史检查点
    start_epoch = resume_training(target_checkpoint, model, optimizer)

    # 2. 根据返回值决定从头训练还是继续训练
    if start_epoch < total_epochs:
        train(model, criterion, optimizer, start_epoch=start_epoch, total_epochs=total_epochs, save_interval=save_interval, checkpoint_dir=checkpoint_dir)
    else:
        print("模型已经完成了所有训练轮次！")

```

* **自动化决策流：**
* 如果目标检查点不存在，`resume_training` 返回 `0`，脚本从头（第 1 轮）开始训练。
* 如果第 10 轮的检查点已经存在（模拟程序曾经崩溃或中断过），`resume_training` 返回 `10`。随后 `train` 函数的循环会直接从 `range(10, 20)` 开始，即跳过前 10 轮，直接执行第 11 到 20 轮的训练。
