Word Embeddings for Sentiment Classification.py代码展示了如何使用 Hugging Face 的 `transformers` 库，对一组用于情感分析的句子进行**批量分词（Tokenization）、长度对齐（Padding/Truncation）以及张量转换（Tensor Conversion）**，并直观对比了 **BERT** 与 **GPT-2** 两种不同架构模型在分词层面的差异。

下面详细拆解该代码的核心逻辑：

---

### 1. 导入与初始化（含工程最佳实践）

```python
from transformers import BertTokenizer, GPT2Tokenizer

def main():
    print("=== 1. 初始化分词器 ===")
    # 加载 BERT 和 GPT-2 分词器
    bert_tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
    gpt_tokenizer = GPT2Tokenizer.from_pretrained("gpt2")

    # 【工程最佳实践】为 GPT-2 设置 pad_token
    if gpt_tokenizer.pad_token is None:
        gpt_tokenizer.pad_token = gpt_tokenizer.eos_token

```

* **分词器加载：**
* `bert-base-uncased`：基于 **WordPiece** 算法，自动转为小写。
* `gpt2`：基于字节级 **BPE (Byte-Level BPE)** 算法。


* **填充符补齐（Pad Token）：**
* 现代自回归大模型（如 GPT-2）原生没有定义专用的填充符（Padding Token）。如果不手动将 `pad_token` 设置为结束符 `eos_token`（即 `<|endoftext|>`），在后续执行 `padding="max_length"` 时会触发警告或使用不规范的默认值。此处的代码体现了规范的工程处理。



---

### 2. 示例语料库定义

```python
    # 定义示例句子集：情感分析任务中的句子
    sentences = [
        "I love this movie! It's absolutely amazing.",
        "The plot was terrible and the acting was worse.",
        "An enjoyable experience with outstanding visuals.",
        "I wouldn't recommend it to anyone.",
        "A brilliant and heartwarming story that everyone should watch."
    ]

```

* **作用：** 模拟真实业务场景中的文本批次（Batch）。这些句子的长度各不相同（有的短，有的长），直接无法放入神经网络中进行并行计算。

---

### 3. 核心批处理与循环编码对比

代码通过 `for` 循环遍历每一条句子，分别交由 BERT 和 GPT-2 进行处理：

#### (1) BERT 处理支路

```python
        bert_tokens = bert_tokenizer.tokenize(sentence)
        bert_encoded = bert_tokenizer(
            sentence, 
            padding="max_length", 
            max_length=12, 
            truncation=True, 
            return_tensors="pt"
        )

```

* `bert_tokenizer.tokenize(sentence)`：将句子切分为独立的子词列表，直观展示 BERT 的 WordPiece 切分效果。
* `bert_tokenizer(...)`（直接调用实例）：执行完整的编码流水线：
* `padding="max_length"`：若句子长度不足 12，在右侧用 `[PAD]`（ID 为 0）补齐。
* `max_length=12`：严格限制序列最大长度为 12。
* `truncation=True`：若句子长度超过 12，自动截断，防止超出模型限制。
* `return_tensors="pt"`：将输出结果直接转换为 PyTorch 张量（Tensor），满足深度学习框架输入要求。



#### (2) GPT-2 处理支路

```python
        gpt_tokens = gpt_tokenizer.tokenize(sentence)
        gpt_encoded = gpt_tokenizer(
            sentence, 
            padding="max_length", 
            max_length=12, 
            truncation=True, 
            return_tensors="pt"
        )

```

* 逻辑与 BERT 类似，但底层分词机制不同。GPT-2 的分词结果中会包含如 `Ġ` 这样特殊的空格标记符号，并且在长度不足时会使用前面绑定的 `eos_token` 进行填充。

---

### 4. 输出结构解析

每次循环打印的内容揭示了 Transformer 输入的核心三要素：

1. **分词结果 (Tokens)：** 文本被离散化后的子词片段。
2. **编码后的 ID (`input_ids`)：** 子词在各自词表中对应的整数索引构成的张量（维度均为 `[1, 12]`）。
3. **注意力掩码 (`attention_mask`)：** 一个由 `1` 和 `0` 组成的张量。有效文本位置为 `1`，因填充补齐的位置为 `0`，用于在模型计算 Self-Attention 时屏蔽无意义的填充位。
