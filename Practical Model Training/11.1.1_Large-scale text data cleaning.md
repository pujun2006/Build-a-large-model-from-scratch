Large-scale text data cleaning.py代码实现了一个简易的 **NLP（自然语言处理）文本预处理与标注流水线（Pipeline）**。它模拟了大模型预训练和微调数据准备阶段中常见的几个核心步骤：**清洗、去重、分句与规则标注**。

下面详细拆解代码的逻辑与作用：

---

### 1. 原始文本数据定义

```python
text_data = [
    "Hello, world! This is an example text with <html> tags.",
    "Python is great!!! $$$",
    "Hello, world!    ",
    "Machine learning is fascinating! 😊",
    "Deep learning <b>models</b> are powerful."
]

```

* **作用：** 模拟从网络爬取或多源渠道收集的原始文本数据。
* **特点：** 包含了典型的“脏数据”特征，如 HTML 标签（`<html>`, `<b>`）、多余的标点与符号（`$$$`）、多余的空白字符（`    `）以及 Emoji 表情（`😊`）。

---

### 2. 文本清洗函数（`clean_text`）

```python
def clean_text(text):
    # 去除HTML标签
    text = re.sub(r'<.*?>', '', text)
    # 去除特殊字符和多余空格
    text = re.sub(r'[^a-zA-Z0-9\s]', '', text)
    # 去除多余空格
    text = re.sub(r'\s+', ' ', text).strip()
    return text

```

* **第一步（去标签）：** 使用正则表达式 `r'<.*?>'` 匹配并剔除所有 HTML 标签。例如 `<html>` 和 `<b>` 会被直接抹除。
* **第二步（去特殊符号）：** 使用正则 `r'[^a-zA-Z0-9\s]'`。其中 `^` 表示取反，这行代码的意思是：**只保留大小写字母、数字和空白字符，把其他所有字符（包括标点符号、感叹号、问号、Emoji）全部删除**。
* **第三步（规范空格）：** `r'\s+'` 将连续的多个空格、换行符折叠为一个普通空格，并通过 `.strip()` 去除首尾空白。

---

### 3. 去重操作（De-duplication）

```python
unique_data = list(set(cleaned_data))

```

* **作用：** 消除语料库中的重复文本，减少冗余并防止模型过拟合。
* **细节：** 代码中使用了 `set`（集合）去重，由于集合是无序的，这会**打乱原始数据的先后顺序**。在真实的工业级大模型预处理中，通常会使用哈希算法（如 MinHash）并在去重时尽量保持数据流的稳定性。

---

### 4. 文本分句（Sentence Splitting）

```python
def split_text(text, delimiter="."):
    return [sentence.strip() for sentence in text.split(delimiter) if sentence]

split_data = [split_text(text) for text in unique_data]

```

* **作用：** 将长文本按分隔符切分为独立的句子。

---

### 5. 规则标注（Rule-based Labeling）

```python
def label_text(text):
    if "machine learning" in text.lower():
        return "Technology"
    elif "python" in text.lower():
        return "Programming"
    elif "world" in text.lower():
        return "General"
    else:
        return "Other"

labeled_data = [{"text": text, "label": label_text(text)} for text in unique_data]

```

* **作用：** 模拟大模型微调中的弱监督数据标注（Weak Supervision）或文本分类预处理。
* **逻辑：** 通过转小写（`.lower()`）并使用关键词匹配（`in`），为每条文本打上预定义的标签（如 `Technology`、`Programming` 等），构建出类似 `{"text": ..., "label": ...}` 的结构化训练样本。
