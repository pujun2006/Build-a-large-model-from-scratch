Distributed Training.py是自适应硬件环境的 PyTorch 分布式数据并行（DDP）训练脚本，核心亮点在于**能够根据当前机器的硬件条件（是否有 GPU），自动在“多卡 GPU 高性能训练（NCCL 后端）”与“多进程 CPU 模拟训练（Gloo 后端）”之间无缝切换**。

下面拆解该代码的核心逻辑与架构设计：

---

### 1. 全局配置与数据/模型定义

```python
import os
import torch
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, Dataset
import torch.optim as optim
import torch.nn as nn
import torch.multiprocessing as mp

# 设置分布式训练通信所需的主节点地址和端口
os.environ['MASTER_ADDR'] = 'localhost'
os.environ['MASTER_PORT'] = '12355'

class RandomDataset(Dataset):
    def __init__(self, size, length):
        self.len = length
        self.data = torch.randn(length, size)

    def __getitem__(self, index):
        return self.data[index]

    def __len__(self):
        return self.len

class SimpleModel(nn.Module):
    def __init__(self, input_size, output_size):
        super(SimpleModel, self).__init__()
        self.fc = nn.Linear(input_size, output_size)

    def forward(self, x):
        return self.fc(x)

```

* **环境变量：** `MASTER_ADDR` 和 `MASTER_PORT` 是 PyTorch 分布式通信的基石，用于多进程（或多节点）之间建立连接。
* **`RandomDataset` & `SimpleModel`：** 定义了一个用于测试的随机数据集（包含 500 个样本，每个样本 10 维特征）和一个简单的全连接线性回归模型。

---

### 2. 分布式进程组生命周期管理

```python
def setup(rank, world_size, use_gpu):
    # 核心自适应：GPU 使用高效的 "nccl"，CPU 使用兼容性最好的 "gloo"
    backend = "nccl" if use_gpu else "gloo"
    dist.init_process_group(backend, rank=rank, world_size=world_size)
    torch.manual_seed(0)

def cleanup():
    dist.destroy_process_group()

```

* **`setup`：** 初始化分布式环境。`rank` 代表当前进程的编号（ID），`world_size` 代表总进程数。代码根据 `use_gpu` 的布尔值动态选择通信后端（Backend）。
* **`cleanup`：** 训练结束后安全销毁进程组，释放系统资源。

---

### 3. 核心训练函数与自适应硬件配置

```python
def train(rank, world_size, epochs=10, batch_size=32):
    use_gpu = torch.cuda.is_available()
    setup(rank, world_size, use_gpu)

    dataset = RandomDataset(10, 500)
    
    # 动态设备与模型包装
    if use_gpu:
        torch.cuda.set_device(rank)
        device = torch.device(f"cuda:{rank}")
        model = SimpleModel(10, 1).to(device)
        model = DDP(model, device_ids=[rank])  # GPU 需要指定 device_ids
    else:
        device = torch.device("cpu")
        model = SimpleModel(10, 1).to(device)
        model = DDP(model)  # CPU 的 DDP 不需要 device_ids

```

* **硬件嗅探：** 每一个启动的子进程首先调用 `torch.cuda.is_available()` 检测当前环境。
* **设备绑定策略：**
* **GPU 模式：** 绑定对应的显卡（`torch.cuda.set_device(rank)`），将模型送入显存，并通过 `device_ids=[rank]` 启用 NCCL 加速。
* **CPU 模式：** 将设备设为 `"cpu"`，并且 CPU 版本的 DDP **不能**传入 `device_ids` 参数。



---

### 4. 分布式数据采样与 DataLoader

```python
    # 分布式采样器：确保每个进程拿到互不重叠的数据子集
    train_sampler = torch.utils.data.distributed.DistributedSampler(
        dataset, num_replicas=world_size, rank=rank)
    train_loader = DataLoader(dataset, batch_size=batch_size, sampler=train_sampler)

    criterion = nn.MSELoss()
    optimizer = optim.SGD(model.parameters(), lr=0.01)

```

* **`DistributedSampler`：** 这是 DDP 训练的关键。它负责将总数据集（500个样本）切片，在每个 Epoch 开始时为不同 `rank` 的进程分配不同的数据分片，防止多进程重复训练相同的数据。

---

### 5. 训练循环与容错处理

```python
    for epoch in range(epochs):
        train_sampler.set_epoch(epoch)  # 【重要】每个 epoch 必须重置 sampler 以打乱数据顺序
        for i, data in enumerate(train_loader, 0):
            inputs = data.to(device)
            
            # 动态获取 batch 大小，完美兼容最后一个不完整的 batch
            current_batch_size = inputs.size(0)
            labels = torch.randn(current_batch_size, 1).to(device)

            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()

```

* **`set_epoch(epoch)`：** 确保每个 Epoch 中数据能够被重新随机洗牌（Shuffle），保证训练的随机性。
* **动态 Batch 适配：** 通过 `inputs.size(0)` 动态生成匹配的 `labels` 张量，彻底避免了因最后一个 Batch 样本数不足（例如剩下 26 个而不是 32 个）而引发的维度崩溃错误。

### 6. 多进程启动入口 (`main`)

```python
def main():
    if torch.cuda.is_available():
        available_gpus = torch.cuda.device_count()
        world_size = min(2, available_gpus) # 最多使用 2 张卡
        print(f"检测到 GPU 环境，将启动 {world_size} 个 GPU 进程。")
    else:
        world_size = 2  # 没有 GPU 时启动 2 个 CPU 进程模拟
        print(f"未检测到 GPU，将启动 {world_size} 个 CPU 进程进行模拟训练。")

    # 使用 PyTorch 的 multiprocessing 模块批量拉起多个训练进程
    mp.spawn(train, args=(world_size,), nprocs=world_size, join=True)

if __name__ == "__main__":
    main()

```

* **`mp.spawn`：** 负责拉起多进程的主控函数。它会同时启动 `world_size` 个独立进程，每个进程独立调用 `train(rank, world_size)` 函数（其中 `rank` 会自动从 `0` 到 `world_size-1` 传入）。`join=True` 表示主进程会阻塞，直到所有子进程训练完毕才安全退出。
