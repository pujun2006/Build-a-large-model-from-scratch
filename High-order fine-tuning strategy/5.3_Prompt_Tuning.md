Prompt_Tuning.py代码实现了一个基于 PyTorch 和 Hugging Face 库的完整 **Prompt Tuning（提示微调）** 文本分类训练流水线。它以 `bert-base-uncased` 为基底模型，展示了如何在不修改或更新主干大模型参数的前提下，通过在输入层拼接可学习的连续型向量（Soft Prompt）来实现下游文本分类任务。

以下是对这段代码各核心模块的详细拆解：

---

### 一、 核心模块详解

#### 1. `PromptTuning` 模块（可学习提示向量的定义与前向拼接）

```python
class PromptTuning(nn.Module):
  def __init__(self, prompt_length, embed_dim):
    super(PromptTuning, self).__init__()
    # 初始化软提示参数，形状为 [prompt_length, embed_dim]
    self.prompt_embeddings = nn.Parameter(
        torch.randn(prompt_length, embed_dim) * 0.02
    )

  def forward(self, embedded_input):
    batch_size = embedded_input.size(0)
    # 扩展 Batch 维度：[prompt_length, embed_dim] -> [batch_size, prompt_length, embed_dim]
    prompt_embed = self.prompt_embeddings.unsqueeze(0).expand(batch_size, -1, -1)
    # 在序列维度（dim=1）将虚拟 Prompt 拼在真实文本词嵌入的左侧
    return torch.cat((prompt_embed, embedded_input), dim=1)

```

* **作用：** 这是 Prompt Tuning 的灵魂所在。它创建了一组可学习的参数矩阵 `prompt_embeddings`（长度为 `prompt_length`，维度与模型隐藏层一致）。在前向传播时，它会为当前 Batch 中的每个样本复制一份这组 Prompt，并拼接到文本嵌入的最前方。

#### 2. `BertWithPromptTuning` 封装类（参数冻结与维度对齐）

这是整个脚本中最关键、最能体现工程严谨性的部分，主要处理了三个底层兼容问题：

* **参数冻结（Parameter Freezing）：**
```python
for param in self.bert.parameters():
  param.requires_grad = False

```


严格遵循 PEFT 规范，将 BERT 主干网络的所有参数全部冻结（`requires_grad = False`），确保反向传播时只计算和更新 Prompt 矩阵的梯度，节省显存并保护预训练知识。
* **注意力掩码扩展（Attention Mask Extension）：**
```python
extended_attention_mask = torch.cat(
    [
        torch.ones((batch_size, self.prompt_length), device=device),
        attention_mask,
    ],
    dim=1,
)

```


因为序列长度增加了 `prompt_length`，`attention_mask` 必须在左侧补上全 `1`，让模型在计算自注意力时能够正常注意到这些虚拟 Prompt。
* **位置编码对齐（Position IDs Alignment）：**
```python
seq_length = embedded_input_with_prompt.size(1)
position_ids = torch.arange(seq_length, dtype=torch.long, device=device)
position_ids = position_ids.unsqueeze(0).expand(batch_size, -1)

```


显式构造从 `0` 到 `seq_length - 1` 的位置索引并传入模型，防止由于嵌入拼接导致模型内部位置编码错乱。

#### 3. 数据准备与加载

```python
def prepare_data(texts, labels, tokenizer, max_length=128):
  encodings = tokenizer(
      texts,
      truncation=True,
      padding=True,
      max_length=max_length,
      return_tensors="pt",
  )
  input_ids, attention_mask = encodings["input_ids"], encodings["attention_mask"]
  labels = torch.tensor(labels)
  return TensorDataset(input_ids, attention_mask, labels)

```

* 使用标准 `BertTokenizer` 对文本进行分词、截断和填充，并封装为 PyTorch 的 `TensorDataset` 和 `DataLoader`，支持小批量（Batch）迭代训练。
* 脚本中精心构造了 6 个平衡的样本（3 个正向情感、3 个负向情感），用于演示稳定收敛。

#### 4. 优化策略与训练循环

```python
optimizer = optim.Adam(
    [{"params": prompt_tuned_model.prompt_tuning.parameters()}], lr=2e-5
)

```

* **精确定向优化：** 优化器 `optimizer` 的参数列表里**只传入了** `prompt_tuned_model.prompt_tuning.parameters()`。尽管 BERT 主干被包含在模型类中，但由于它的 `requires_grad` 已被设为 `False` 且未传给优化器，它不会被任何梯度更新。
* **标准训练步（`train_one_epoch`）：** 包含了经典的五部曲——前向传播 $\rightarrow$ 计算损失（CrossEntropyLoss） $\rightarrow$ 梯度清零（`zero_grad()`） $\rightarrow$ 反向传播（`backward()`） $\rightarrow$ 参数更新（`step()`），并实时统计每个 Epoch 的平均 Loss 与分类准确率（Accuracy）。

### 三、 核心技术总结

这段代码完美诠释了 Prompt Tuning 的精髓：

1. **侵入性极低：** 无需修改 BERT 内部的 Transformer 层结构。
2. **极高的参数效率：** 整个模型中只有几百个参数在参与训练（远小于全量微调的数千万参数）。
3. **工程细节完备：** 同步处理了嵌入层直通、注意力掩码扩展和位置编码对齐，是一套标准、可运行的轻量化微调落地范本。
