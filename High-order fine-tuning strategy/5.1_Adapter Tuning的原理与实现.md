Adapter Tuning（适配器微调）是参数高效微调（PEFT，Parameter-Efficient Fine-Tuning）领域中一种经典且有效的方法。它最早由 Houlsby 等人在 2019 年提出。

在大模型时代，全量微调（Full Fine-Tuning）需要更新模型的所有参数，计算和存储成本极高。而 Adapter Tuning 的核心思想是：**冻结预训练模型的大部分参数，仅在 Transformer 层的关键位置插入少量可训练的“适配器（Adapter）”模块**。

---

## 一、 Adapter Tuning 的核心原理

### 1. 结构设计：瓶颈架构（Bottleneck Architecture）

Adapter 通常被嵌入在 Transformer 层的两个特定位置：

1. **多头自注意力机制（Multi-Head Attention）之后**
2. **前馈神经网络（Feed-Forward Network, FFN）之后**

每个 Adapter 模块内部采用**降维-升维**的瓶颈结构，主要包含以下几个步骤：

* **降维（Down-projection）**：将高维特征输入 $h \in \mathbb{R}^{d}$ 通过一个线性层映射到低维空间 $r$（其中 $r \ll d$，通常 $r$ 在 8 到 64 之间），大幅减少参数量。
* **非活性激活（Non-linear Activation）**：通过激活函数（如 GELU、ReLU）引入非线性变换。
* **升维（Up-projection）**：通过另一个线性层将低维特征恢复回原有的高维空间 $d$。
* **残差连接（Residual Connection）**：将变换后的特征与原始输入相加，保证信息的无损传递。

### 2. 数学表达

设输入向量为 $h$，Adapter 的数学计算公式为：

$$f(h) = \text{LayerNorm}(h + W_{up} \cdot \sigma(W_{down} \cdot h))$$

其中：

* $h \in \mathbb{R}^{b \times s \times d}$ 是输入特征（$b$ 为批大小，$s$ 为序列长度，$d$ 为隐藏层维度）。
* $W_{down} \in \mathbb{R}^{r \times d}$ 是降维矩阵。
* $\sigma(\cdot)$ 是非线性激活函数。
* $W_{up} \in \mathbb{R}^{d \times r}$ 是升维矩阵。
* $r$ 是瓶颈维度（Bottleneck Dimension），由于 $r \ll d$，参数量极小。

---

## 二、 Adapter 的主要类型

在实际应用中，Adapter 的放置位置演化出几种经典变体：

| 变体名称 | 核心特点 | 参数量与性能 |
| --- | --- | --- |
| **Houlsby Architecture** | 在每个 Transformer 层的 Attention 后和 FFN 后各放置一个 Adapter。 | 性能最好，但引入了两次串行计算开销。 |
| **Pfeiffer Architecture** | 仅在每个 Transformer 层的 FFN 之后放置一个 Adapter，且通常串联在残差支路之外。 | 计算效率更高，性能损失微乎其微。 |
| **Parallel Adapter** | 将 Adapter 与 Transformer 层并行放置，减少对序列处理深度的影响。 | 训练速度更快，适合超大模型。 |

---

## 三、 Adapter Tuning 的核心优势

1. **极高的参数效率**：通常只需要训练原模型 **0.5% 至 5%** 的参数，显存开销和存储需求显著降低。
2. **多任务模块化管理**：
* 预训练底座模型保持冻结，多个不同任务可以共享同一个底座。
* 针对不同下游任务，只需训练和保存各自轻量级的 Adapter 权重（文件通常只有几兆到几十兆），推理时动态加载即可，完美实现“多任务热插拔”。


3. **缓解灾难性遗忘**：由于底层基础模型参数未被破坏，模型在微调时较少发生对通用能力的遗忘。

## 四、 PyTorch 代码实现示例

以下是一个标准的 PyTorch 版本的 Adapter 模块实现及其在 Transformer 层中的嵌入方式：

```python
import torch
import torch.nn as nn

class Adapter(nn.Module):
    def __init__(self, d_model: int, bottleneck_dim: int = 64):
        super().__init__()
        # 降维层：d_model -> bottleneck_dim
        self.down_proj = nn.Linear(d_model, bottleneck_dim)
        self.activation = nn.GELU()
        # 升维层：bottleneck_dim -> d_model
        self.up_proj = nn.Linear(bottleneck_dim, d_model)
        
        # 初始化权重（通常采用小方差高斯分布或零初始化）
        nn.init.normal_(self.down_proj.weight, std=1e-3)
        nn.init.zeros_(self.down_proj.bias)
        nn.init.normal_(self.up_proj.weight, std=1e-3)
        nn.init.zeros_(self.up_proj.bias)

    def forward(self, x):
        # x shape: [batch_size, seq_len, d_model]
        residual = x
        down = self.down_proj(x)
        act = self.activation(down)
        up = self.up_proj(act)
        
        # 残差连接
        return residual + up

# 模拟集成到 Transformer FFN 之后
class TransformerLayerWithAdapter(nn.Module):
    def __init__(self, d_model: int, bottleneck_dim: int = 64):
        super().__init__()
        # 模拟原有的 Transformer FFN 层（冻结）
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.GELU(),
            nn.Linear(d_model * 4, d_model)
        )
        self.layer_norm = nn.LayerNorm(d_model)
        
        # 插入的 Adapter 模块（可训练）
        self.adapter = Adapter(d_model, bottleneck_dim)

    def forward(self, x):
        # 1. 基础 FFN 前向传播
        residual = x
        x = self.layer_norm(x + self.ffn(x))
        
        # 2. 通过 Adapter
        x = self.adapter(x)
        return x

# 测试代码
if __name__ == "__main__":
    batch_size, seq_len, d_model = 2, 16, 768
    dummy_input = torch.randn(batch_size, seq_len, d_model)
    
    layer = TransformerLayerWithAdapter(d_model=d_model, bottleneck_dim=64)
    output = layer(dummy_input)
    print("输出形状:", output.shape)

```

## 五、 总结与局限性

* **总结**：Adapter Tuning 通过在模型内部“打补丁”的方式，实现了以极低代价定制大模型的能力，是现代大模型 PEFT 技术（如 LoRA、Prefix-Tuning）的先驱和基石。
* **局限性**：早期的串行 Adapter 会在推理链中增加额外的网络层深度，带来轻微的**推理延迟（Latency Overhead）**。因此在后续的发展中，如 **LoRA（Low-Rank Adaptation）** 等将低秩矩阵旁路加到注意力权重中的方法更受欢迎，因为 LoRA 在推理时可以无损融合回原模型，不增加任何额外的推理耗时。
