LoRA_Tuning.py这段代码实现了一个基于 **PyTorch** 和 **Hugging Face Transformers** 的轻量微调示例。它通过自定义的 **低秩残差模块（LoRA 思想）**，在冻结预训练 BERT 模型主体参数的前提下，仅训练低秩适应层和分类头，用于文本分类任务。

下面为你对代码的各个核心部分进行详细拆解和说明：

---

### 一、 整体架构概述

1. **预训练模型复用**：加载 `bert-base-uncased` 作为特征提取器。
2. **参数冻结 (Freezing)**：将 BERT 原有的所有参数设为不可训练（`requires_grad = False`），节省显存并防止破坏预训练知识。
3. **低秩残差注入 (LoRA-style Residuals)**：模仿 LoRA（Low-Rank Adaptation）的思想，为 BERT 的每一层隐状态增加低秩矩阵变换，作为残差补充。
4. **分类头 (Classification Head)**：提取最后一层 `[CLS]` 标记的向量，通过线性层映射为分类结果（Logits）。

---

### 二、 核心模块逐段解析

#### 1. 低秩残差模块 (`LoRA`)

```python
class LoRA(nn.Module):
    def __init__(self, input_dim, rank=4):
        super(LoRA, self).__init__()
        self.rank = rank
        self.down_proj = nn.Linear(input_dim, rank, bias=False)  # 降维矩阵
        self.up_proj = nn.Linear(rank, input_dim, bias=False)  # 升维矩阵

    def forward(self, x):
        return self.up_proj(self.down_proj(x))

```

* **原理**：LoRA 的核心思想是用两个低秩矩阵（降维 $d \to r$ 和升维 $r \to d$）来模拟参数更新。这里 `input_dim` 是 BERT 的隐层维度（768），`rank` 是低秩矩阵的秩（设为 4）。
* **优势**：相比直接微调整个大矩阵，参数量大幅减小。`bias=False` 也是标准 LoRA 实现中的常见设置。

#### 2. 带有低秩模块的 BERT 模型 (`BertWithLoRA`)

```python
class BertWithLoRA(nn.Module):
    def __init__(self, lora_rank=4, num_classes=2):
        super(BertWithLoRA, self).__init__()
        self.bert = BertModel.from_pretrained("bert-base-uncased")

        # 1. 冻结 BERT 原有参数
        for param in self.bert.parameters():
            param.requires_grad = False

        # 2. 为每层增加低秩适应模块
        self.lora_modules = nn.ModuleList([
            LoRA(self.bert.config.hidden_size, lora_rank)
            for _ in range(self.bert.config.num_hidden_layers)
        ])

        # 3. 分类头
        self.classifier = nn.Linear(self.bert.config.hidden_size, num_classes)

```

* **冻结机制**：遍历 `self.bert.parameters()` 并将 `requires_grad` 设为 `False`，确保在反向传播时 BERT 原生权重不会被更新。
* **层级残差修正**：
```python
outputs = self.bert(..., output_hidden_states=True)
hidden_states = list(outputs.hidden_states)

for i, lora in enumerate(self.lora_modules):
    hidden_states[i + 1] = hidden_states[i + 1] + lora(hidden_states[i + 1])

```


* 开启 `output_hidden_states=True` 后，BERT 会返回每一层的输出（共 13 个张量：1 个 Embedding 层输出 + 12 个 Transformer 层输出）。
* 代码中对每一层的输出特征加上了对应的 LoRA 低秩残差修正（$h' = h + \text{Up}(\text{Down}(h))$）。


* **分类输出**：
```python
cls_output = hidden_states[-1][:, 0, :]  # 取最后一层 [CLS] 向量 (shape: [batch_size, 768])
logits = self.classifier(cls_output)    # 通过线性层得到分类 logits

```

#### 4. 优化器与训练配置

```python
optimizer = optim.Adam(
    list(model.lora_modules.parameters()) + list(model.classifier.parameters()),
    lr=1e-4
)
criterion = nn.CrossEntropyLoss()

```

* **精妙之处**：优化器中**只传入了** `model.lora_modules` 和 `model.classifier` 的参数。由于 BERT 主体参数的 `requires_grad = False` 且未传给优化器，它们在训练过程中梯度保持为零，不会被更新。

#### 5. 训练循环 (`train_one_epoch`)

标准的多分类训练流程：

1. `model.train()`：开启训练模式。
2. 前向传播：计算模型预测的 `logits`。
3. 计算损失：使用交叉熵损失函数 `nn.CrossEntropyLoss()`。
4. 反向传播与优化：`optimizer.zero_grad()` $\to$ `loss.backward()` $\to$ `optimizer.step()`。
5. 统计指标：计算平均 Loss 和准确率（Accuracy）。

### 四、 总结与工程小贴士

* **教学意义**：这段代码非常清晰地展示了 **PEFT（Parameter-Efficient Fine-Tuning）** 的核心思想——**冻结主体，外挂小模块**。
* **与标准 Hugging Face PEFT/LoRA 的区别**：
* 标准的 Hugging Face `peft` 库通常是将 LoRA 矩阵注入到注意力机制的投影层（如 Query 和 Value 权重矩阵 $W_q, W_v$ 中）。
* 本代码为了教学简化，直接对每一层的隐状态（Hidden States）进行了低秩残差修正，原理上是相通的（都是通过低秩旁路注入可训参数）。
