LoRA_Tuning.py这段代码是一个精简、可运行的 **LoRA（低秩适应）微调 BERT 文本分类模型** 的完整示例。它通过“**冻结预训练主干网络 + 引入低秩旁路模块**”的方式，模拟了参数高效微调（PEFT）的核心思想。

下面为你逐段详细拆解这段代码的架构与逻辑：

---

### 一、 核心组件解析

#### 1. 低秩残差模块 (`LoRA` 类)

```python
class LoRA(nn.Module):
    def __init__(self, input_dim, rank=4):
        super(LoRA, self).__init__()
        self.rank = rank
        self.down_proj = nn.Linear(input_dim, rank, bias=False)  # 降维矩阵
        self.up_proj = nn.Linear(rank, input_dim, bias=False)  # 升维矩阵

    def forward(self, x):
        return self.up_proj(self.down_proj(x))

```

* **原理**：LoRA 的核心思想是将参数的更新量 $\Delta W$ 分解为两个低秩矩阵相乘。这里将输入维度（如 BERT 的隐层维度 768）先通过 `down_proj` 降维到极小的秩（`rank=4`），再通过 `up_proj` 升维回原维度。
* **优势**：原本全量微调需要更新 $768 \times 768$ 的参数矩阵，而使用低秩分解后，参数量骤降，极大地节省了显存和计算开销。

#### 2. 带有低秩模块的 BERT 模型 (`BertWithLoRA` 类)

```python
class BertWithLoRA(nn.Module):
    def __init__(self, lora_rank=4, num_classes=2):
        super(BertWithLoRA, self).__init__()
        self.bert = BertModel.from_pretrained("bert-base-uncased")

        # 1. 冻结 BERT 原有参数
        for param in self.bert.parameters():
            param.requires_grad = False

        hidden_size = self.bert.config.hidden_size
        num_layers = self.bert.config.num_hidden_layers

        # 2. 为每层 Transformer 创建对应的 LoRA 模块
        self.lora_modules = nn.ModuleList([
            LoRA(hidden_size, lora_rank)
            for _ in range(num_layers)
        ])

        # 3. 分类头：将最终的隐状态映射为分类类别数（2类）
        self.classifier = nn.Linear(hidden_size, num_classes)

```

* **参数冻结**：通过 `param.requires_grad = False` 锁死 BERT 原生的所有权重，确保在反向传播时它们不会被更新，保留了预训练模型的通用语言能力。
* **多层适配**：利用 `nn.ModuleList` 为 BERT 的每一层（共 12 层）独立配备了一个 `LoRA` 模块。

#### 3. 前向传播逻辑 (`forward` 方法)

```python
    def forward(self, input_ids, attention_mask):
        # 开启 output_hidden_states=True，获取 BERT 每一层的输出
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask, output_hidden_states=True)
        hidden_states = outputs.hidden_states

        # 逐层应用 LoRA 残差修正
        current_hidden = hidden_states[0]
        for i, lora in enumerate(self.lora_modules):
            layer_out = hidden_states[i + 1]
            current_hidden = layer_out + lora(layer_out)

        # 取出最后一层经过修正后的 [CLS] 标记的特征向量 (形状: [batch_size, 768])
        cls_output = current_hidden[:, 0, :]

        # 通过分类头得到分类 Logits
        logits = self.classifier(cls_output)
        return logits

```

* **特征流动与残差累加**：代码通过 `output_hidden_states=True` 拿到 BERT 各层的输出，并在每一层叠加对应的 `lora(layer_out)` 修正量（模拟残差更新）。
* **分类输出**：提取序列开头的 `[CLS]` 标记（通常用于聚合整句语义），送入线性分类头 `self.classifier` 得到预测结果。

### 二、 数据处理与训练配置

#### 1. 数据准备

```python
def prepare_data(texts, labels, tokenizer, max_length=128):
    encodings = tokenizer(texts, truncation=True, padding=True, max_length=max_length, return_tensors="pt")
    input_ids, attention_mask = encodings["input_ids"], encodings["attention_mask"]
    labels = torch.tensor(labels)
    return TensorDataset(input_ids, attention_mask, labels)

```

* 使用 BERT 官方分词器 (`BertTokenizer`) 对文本进行 Tokenize、截断和填充，转化为模型所需的张量，并打包为 `TensorDataset` 与 `DataLoader`。

#### 2. 优化器配置

```python
optimizer = optim.Adam(
    list(model.lora_modules.parameters()) + list(model.classifier.parameters()),
    lr=1e-4
)

```

* **关键点**：优化器中**仅传入了** `model.lora_modules` 和 `model.classifier` 的参数。被冻结的 BERT 主干参数没有传进去，因此在梯度更新时只有外挂的 LoRA 和分类头被训练。

### 五、 总结与工程小贴士

* **教学意义**：这段代码非常清晰地展示了 **PEFT（Parameter-Efficient Fine-Tuning）** 的核心思想——**冻结主体，外挂小模块**。
* **与标准 Hugging Face PEFT/LoRA 的区别**：
* 标准的 Hugging Face `peft` 库通常是将 LoRA 矩阵注入到注意力机制的投影层（如 Query 和 Value 权重矩阵 $W_q, W_v$ 中）。
* 本代码为了教学简化，直接对每一层的隐状态（Hidden States）进行了低秩残差修正，原理上是相通的（都是通过低秩旁路注入可训参数）。
