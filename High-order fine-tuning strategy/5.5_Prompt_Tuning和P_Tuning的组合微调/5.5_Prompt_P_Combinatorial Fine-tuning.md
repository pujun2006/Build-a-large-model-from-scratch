Prompt_P_Combinatorial Fine-tuning.py代码实现了一个基于 **P-Tuning（Prompt Tuning 的改进版之一）** 的 PyTorch 微调示例。它将可训练的连续伪提示（Continuous Prompts）拼接在输入文本的嵌入（Embedding）之前，并通过冻结 BERT 主体参数、仅优化 P-Tuning 编码器的方式，在 `bert-base-chinese` 模型上进行少样本（Few-shot）序列分类训练。

下面逐模块详细拆解该代码的核心原理与实现逻辑：

---

### 一、 P-Tuning 编码器 (`PTuningEncoder`)

P-Tuning（由清华大学提出）的核心思想是将离散的 Prompt 转换为**连续的可训练向量（Continuous Embeddings）**，并用 LSTM/MLP 来建模这些 Prompt 向量之间的关联，从而缓解由于 Prompt 离散性带来的优化困难和不稳定性。

```python
class PTuningEncoder(nn.Module):

  def __init__(self, prompt_length, embed_dim):
    super().__init__()
    self.prompt_length = prompt_length
    self.embedding = nn.Embedding(prompt_length, embed_dim)
    self.lstm = nn.LSTM(
        input_size=embed_dim,
        hidden_size=embed_dim,
        num_layers=2,
        batch_first=True,
        bidirectional=True,
    )
    self.mlp = nn.Sequential(
        nn.Linear(embed_dim * 2, embed_dim),
        nn.ReLU(),
        nn.Linear(embed_dim, embed_dim),
    )

```

1. **`nn.Embedding(prompt_length, embed_dim)`**：为每个 Prompt 位置初始化一个嵌入向量。`prompt_length = 5` 表示在每个输入文本前插入 5 个虚拟 Token。
2. **`nn.LSTM`**：使用双向 LSTM（`bidirectional=True`）对这几个嵌入进行编码。通过上下文的循环交互，让 Prompt 向量之间产生关联（不再是孤立的参数），提升表达能力。
3. **`nn.MLP`（多层感知机）**：将 LSTM 双向输出（`embed_dim * 2`）降维并映射回 Transformer 所需的隐藏层维度（`embed_dim`）。输出的张量形状为 `(batch_size, prompt_length, embed_dim)`。

---

### 二、 集成模型定义 (`BertWithPTuning`)

这个类负责将 P-Tuning 生成的虚拟 Prompt 嵌入与原文本的 Token 嵌入进行**拼接（Concatenation）**，并对注意力掩码（Attention Mask）进行相应扩展，最后送入 BERT 主干网络。

```python
class BertWithPTuning(nn.Module):

  def __init__(self, prompt_length, model):
    super().__init__()
    self.bert = model
    embed_dim = self.bert.config.hidden_size
    self.ptuning_encoder = PTuningEncoder(prompt_length, embed_dim)

  def forward(self, input_ids, attention_mask, labels=None):
    batch_size = input_ids.size(0)
    # 1. 获取原文本的 embedding
    inputs_embeds = self.bert.get_input_embeddings()(input_ids)
    # 2. 生成 P-Tuning 的 prompt 嵌入
    prompt_embeds = self.ptuning_encoder(batch_size)

    # 3. 拼接 Prompt 与文本嵌入：在序列长度维度（dim=1）拼接
    combined_embeds = torch.cat((prompt_embeds, inputs_embeds), dim=1)

    # 4. 扩展注意力掩码：为 prompt 部分补齐全 1 的 mask，让模型注意力能够覆盖到 prompt
    prompt_length = prompt_embeds.size(1)
    extended_attention_mask = torch.cat(
        [
            torch.ones((batch_size, prompt_length), device=attention_mask.device),
            attention_mask,
        ],
        dim=1,
    )

    # 5. 将拼接后的 embedding 和扩展的 mask 传入 BERT
    outputs = self.bert(
        inputs_embeds=combined_embeds,
        attention_mask=extended_attention_mask,
        labels=labels,
    )
    return outputs

```

* **拼接逻辑**：若文本长度为 $L$，Prompt 长度为 $P$，拼接后的输入序列长度变为 $P + L$。BERT 见到的输入实际上变成了 `[Prompt_1, ..., Prompt_P, Token_1, ..., Token_L]`。
* **Mask 扩展**：由于前面多出了 $P$ 个 Prompt Token，原有的 `attention_mask` 必须在左侧拼接一列长度为 $P$、全为 `1` 的张量，确保 BERT 在计算 Self-Attention 时不会忽略这些 Prompt。

### 三、 主程序：加载、训练与测试 (`if __name__ == "__main__":`)

这部分展示了完整的训练管线（Pipeline），主要包含以下三个核心步骤：

#### 1. 模型与分词器初始化

```python
model_name = "bert-base-chinese"
tokenizer = BertTokenizer.from_pretrained(model_name)
base_model = BertForSequenceClassification.from_pretrained(
    model_name, num_labels=2
)
prompt_length = 5
tuned_model = BertWithPTuning(prompt_length, base_model)

```

加载中文 BERT 分词器以及用于二分类（`num_labels=2`）的 `BertForSequenceClassification` 预训练模型，并封装进 `BertWithPTuning`。

#### 2. 冻结 BERT 主体，仅优化 P-Tuning 参数（参数高效微调 PEFT）

```python
for param in tuned_model.bert.parameters():
  param.requires_grad = False

optimizer = AdamW(tuned_model.ptuning_encoder.parameters(), lr=1e-3)

```

* **冻结**：将 `tuned_model.bert` 的所有参数 `requires_grad` 设为 `False`，在反向传播时**不更新** BERT 原本的几千万参数。
* **优化器**：仅把 `tuned_model.ptuning_encoder`（即 Embedding、LSTM、MLP）的参数传给 `AdamW`。这样可以大幅减少显存开销，并防止预训练知识遭到破坏。

#### 3. 训练循环与推理

```python
for epoch in range(15):
  optimizer.zero_grad()
  outputs = tuned_model(
      input_ids=input_ids, attention_mask=attention_mask, labels=labels
  )
  loss = outputs.loss
  loss.backward()
  optimizer.step()
  print(f"Epoch {epoch+1}/15 - Loss: {loss.item():.4f}")

```

代码使用两句简单的正向文本（标签均为 `1`，即 Positive）进行了 15 轮（Epoch）的过拟合训练。随着迭代进行，Loss 会逐渐降低。训练结束后，切换至 `eval()` 模式并打印预测结果。
