P_Tuning.py代码是一个基于 PyTorch 和 Hugging Face (`transformers`) 实现的简化版 P-Tuning（Prompt Tuning）核心代码。它以 `bert-base-uncased` 为基础模型，在输入文本的嵌入空间（Embedding Space）前拼接了可训练的虚拟 Prompt 向量，同时冻结了 BERT 的主体参数，仅对这些虚拟 Token 进行优化。

下面从**核心模块设计**、**模型集成**、**数据与训练流程**三个维度对该代码进行详细拆解说明：

---

### 一、 核心组件：`PTuning` 模块

```python
class PTuning(nn.Module):
    def __init__(self, prompt_length, embed_dim):
        super(PTuning, self).__init__()
        # 定义可学习的虚拟 Token 参数，形状为 [prompt_length, embed_dim]
        self.prompt_embeddings = nn.Parameter(torch.randn(prompt_length, embed_dim))

    def forward(self, embedded_input):
        batch_size = embedded_input.size(0)
        # 将参数扩展到整个 Batch：[prompt_length, embed_dim] -> [batch_size, prompt_length, embed_dim]
        prompt_embed = self.prompt_embeddings.unsqueeze(0).expand(batch_size, -1, -1)
        # 在序列维度（dim=1）上，将虚拟 Prompt 拼接到真实文本嵌入的前面
        return torch.cat((prompt_embed, embedded_input), dim=1)

```

* **原理体现**：这段代码直接在 Embedding 层面实现了连续型提示（Continuous Prompts）。`self.prompt_embeddings` 是形状为 `(5, 768)` 的可训练张量（`nn.Parameter`），它不对应任何真实的词表 ID，而是直接在连续向量空间中通过梯度下降进行优化。
* **维度拼接**：输入的真实文本经过 BERT 的 Embedding 层后，形状变为 `[batch_size, seq_len, embed_dim]`。通过 `.expand()` 和 `torch.cat`，最终将输入序列延长为 `[batch_size, prompt_length + seq_len, embed_dim]`。

### 二、 主体集成：`BertWithPTuning` 模块

这是将 P-Tuning 与预训练 Transformer 绑定的核心类：

```python
class BertWithPTuning(nn.Module):
    def __init__(self, prompt_length, model):
        super(BertWithPTuning, self).__init__()
        self.bert = model

        # 【核心操作】冻结 BERT 主干网络的所有参数
        for param in self.bert.parameters():
            param.requires_grad = False

        self.p_tuning = PTuning(prompt_length, embed_dim)

    def forward(self, input_ids, attention_mask):
        # 1. 获取真实文本的词嵌入
        embedded_input = self.bert.bert.embeddings(input_ids)
        
        # 2. 拼接虚拟 Prompt 嵌入
        embedded_input_with_prompt = self.p_tuning(embedded_input)

        # 3. 扩展注意力掩码（Attention Mask）以匹配新增的 Prompt 长度
        # 虚拟 Prompt 部分全部设为 1，让模型正常对其进行 Attention 计算
        extended_attention_mask = torch.cat(
            [torch.ones((attention_mask.size(0), prompt_length), device=attention_mask.device), attention_mask], dim=1
        )
        
        # 4. 将拼接后的 Embeddings 和扩充后的 Mask 传入冻结的 BERT 主干网络
        outputs = self.bert(inputs_embeds=embedded_input_with_prompt, attention_mask=extended_attention_mask)

        return outputs.logits

```

* **参数冻结**：`param.requires_grad = False` 确保了在反向传播时，BERT 原有的 ~1.1 亿参数不会发生改变，从而大幅节省显存并防止预训练知识被破坏。
* **注意力掩码扩展**：因为我们在输入前面强行塞入了 `prompt_length` 个虚拟 Token，如果不扩展 `attention_mask`，模型就会忽略这部分输入。因此这里构造了一个形状为 `[batch_size, prompt_length]`、全为 `1` 的张量拼接到原 mask 前面。
* **`inputs_embeds` 替代 `input_ids**`：因为 BERT 自带的 Embedding 层只接受词表 ID（`input_ids`），而我们的 Prompt 是连续向量，所以代码中显式提取了文本的 Embedding，拼接后再通过 `inputs_embeds` 参数整体喂给模型。

### 三、 数据准备与训练流程

#### 1. 数据处理

```python
def prepare_data(texts, labels, tokenizer, max_length=128):
    encodings = tokenizer(texts, truncation=True, padding=True, max_length=max_length, return_tensors="pt")
    input_ids, attention_mask = encodings["input_ids"], encodings["attention_mask"]
    labels = torch.tensor(labels)
    return TensorDataset(input_ids, attention_mask, labels)

```

* 使用 Hugging Face 的 `BertTokenizer` 将文本转化为标准的分词 ID（`input_ids`）和掩码（`attention_mask`），并包装成 PyTorch 的 `TensorDataset` 和 `DataLoader`。

#### 2. 优化器配置

```python
optimizer = optim.Adam([{'params': p_tuned_model.p_tuning.parameters()}], lr=1e-4)

```

* **精准更新**：优化器中只传入了 `p_tuned_model.p_tuning.parameters()`（即那 5 个虚拟 Token 的参数）。即使 BERT 主干网络的参数参与了前向传播计算，也不会被梯度下降更新。

#### 3. 训练循环（`train_one_epoch`）

* 标准的 PyTorch 监督学习训练循环：
1. 从 DataLoader 获取一个 Batch 的数据。
2. 前向传播计算 logits。
3. 通过 `CrossEntropyLoss` 计算损失。
4. `optimizer.zero_grad()` 清空梯度。
5. `loss.backward()` 反向传播（梯度只会流向 `p_tuning` 模块）。
6. `optimizer.step()` 更新虚拟 Prompt 的权重。
7. 统计并计算当前 Epoch 的平均 Loss 与准确率（Accuracy）。
