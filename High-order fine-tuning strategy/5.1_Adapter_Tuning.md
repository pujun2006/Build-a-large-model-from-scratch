Adapter_Tuning.py代码展示了如何使用 **PyTorch** 和 **Hugging Face Transformers** 库，为预训练的 BERT 模型实现 **Adapter（适配器）微调** 机制。

Adapter 是一种高效的参数微调（Parameter-Efficient Fine-Tuning, PEFT）方法。它的核心思想是：**冻结预训练模型的大部分参数，只在网络的特定位置（如每个 Transformer 层的内部）插入并训练少量的额外参数（即 Adapter 模块）**。这样可以在大幅减少训练参数量和显存开销的同时，达到接近全量微调的效果。

---

## 一、 代码核心模块详细拆解

### 1. Adapter 模块的定义 (`Adapter`)

```python
class Adapter(nn.Module):
    def __init__(self, input_dim, bottleneck_dim=64):
        super(Adapter, self).__init__()
        self.down_project = nn.Linear(input_dim, bottleneck_dim)
        self.activation = nn.ReLU()
        self.up_project = nn.Linear(bottleneck_dim, input_dim)

    def forward(self, x):
        x_down = self.down_project(x)
        x_activated = self.activation(x_down)
        x_up = self.up_project(x_activated)
        return x + x_up  # 残差连接

```

* **瓶颈结构（Bottleneck Architecture）**：Adapter 通常采用“降维 $\rightarrow$ 非线性激活 $\rightarrow$ 升维”的结构。
* `down_project`：将高维特征（如 BERT 的隐层维度 $768$）压缩到低维瓶颈（如 $64$），减少参数量。
* `activation`：使用 `ReLU` 引入非线性表达能力。
* `up_project`：将低维特征恢复回原始的特征维度。


* **残差连接（Residual Connection）**：`return x + x_up`。这确保了在训练初期，Adapter 的输出接近于 0，模型行为退化为原始的预训练模型，从而保证了训练的稳定性和平稳过渡。

### 2. 层的包装器 (`AdapterWrappedBertLayer`)

```python
class AdapterWrappedBertLayer(nn.Module):
    def __init__(self, original_layer, adapter_dim=64):
        super(AdapterWrappedBertLayer, self).__init__()
        self.layer = original_layer
        hidden_size = self.layer.output.dense.out_features
        self.adapter = Adapter(hidden_size, adapter_dim)

    def forward(self, hidden_states, *args, **kwargs):
        layer_outputs = self.layer(hidden_states, *args, **kwargs)

        if isinstance(layer_outputs, tuple):
            output_tensor = layer_outputs[0]
            adapted_tensor = self.adapter(output_tensor)
            return (adapted_tensor,) + layer_outputs[1:]
        else:
            adapted_tensor = self.adapter(layer_outputs)
            return adapted_tensor

```

* **装饰器/包装器模式**：该类接收 BERT 原有的某一层（`original_layer`），在不修改原层内部代码的前提下，在其输出端嵌入了上面定义好的 `Adapter` 模块。
* **版本兼容性处理**：Hugging Face 库在不同版本中，Transformer 层的 `forward` 返回值可能是一个纯 `Tensor`，也可能是一个包含注意力权重等的 `tuple`。代码通过 `isinstance(layer_outputs, tuple)` 进行了鲁棒性兼容，确保无论哪个版本都能正确提取并修改输出张量。

### 3. 带有 Adapter 的 BERT 模型 (`BertWithAdapter`)

```python
class BertWithAdapter(nn.Module):
    def __init__(self, adapter_dim=64, num_classes=2):
        super(BertWithAdapter, self).__init__()
        self.bert = BertModel.from_pretrained("bert-base-uncased")

        # 1. 冻结 BERT 原有参数
        for param in self.bert.parameters():
            param.requires_grad = False

        # 2. 用包装了 Adapter 的层原地替换 BERT 原有的 encoder layer
        hidden_size = self.bert.config.hidden_size
        for i, layer in enumerate(self.bert.encoder.layer):
            self.bert.encoder.layer[i] = AdapterWrappedBertLayer(layer, adapter_dim)

        # 3. 分类头
        self.classifier = nn.Linear(hidden_size, num_classes)

```

* **参数冻结**：通过 `param.requires_grad = False` 锁死整个预训练 BERT 模型的所有原始权重，防止在反向传播时被更新，从而节省显存并保留预训练知识。
* **原地替换（In-place Replacement）**：遍历 `self.bert.encoder.layer` 中的每一个 Transformer 编码器层，用带有 Adapter 的包装层直接替换掉它。这样在调用 `self.bert(...)` 时，数据会自动流经我们添加的 Adapter。
* **分类头（Classifier）**：新增了一个线性层 `self.classifier`，用于将 BERT 最后一层的 `[CLS]` 向量映射到分类结果（如二分类的 logits）。

### 4. 数据准备与分词

```python
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

def prepare_data(texts, labels, tokenizer, max_length=128):
    encodings = tokenizer(texts, truncation=True, padding=True, max_length=max_length, return_tensors="pt")
    input_ids, attention_mask = encodings["input_ids"], encodings["attention_mask"]
    labels = torch.tensor(labels)
    return TensorDataset(input_ids, attention_mask, labels)

```

* 使用 `BertTokenizer` 将输入的文本转化为模型可接受的 Token ID 和 Attention Mask。
* 使用 PyTorch 的 `TensorDataset` 和 `DataLoader` 封装示例数据，方便进行批次（Batch）训练。

### 5. 优化器与参数筛选

```python
# 收集所有需要训练的参数（遍历模型中所有的 Adapter 以及分类头）
adapter_params = [p for n, p in model.named_parameters() if "adapter" in n or "classifier" in n]
optimizer = optim.Adam(adapter_params, lr=1e-4)

```

* **关键点**：由于 BERT 主体参数已被冻结（`requires_grad = False`），如果直接把 `model.parameters()` 传给优化器，将会报错或导致无参数可训。
* 这里通过列表推导式，利用参数名称（`named_parameters`）精准过滤出包含 `"adapter"` 或 `"classifier"` 的参数，只让优化器更新这小部分参数。

### 6. 训练循环 (`train_one_epoch`)

```python
def train_one_epoch(dataloader, model, criterion, optimizer):
    model.train()
    total_loss, correct_predictions = 0, 0

    for batch in dataloader:
        input_ids, attention_mask, labels = [x.to(device) for x in batch]

        logits = model(input_ids=input_ids, attention_mask=attention_mask)
        loss = criterion(logits, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        ...

```

* 标准的 PyTorch 训练循环：
1. 将数据移动到指定设备（GPU/CPU）。
2. 前向传播计算 `logits`。
3. 计算交叉熵损失（`CrossEntropyLoss`）。
4. 梯度清零 (`zero_grad`)、反向传播 (`backward`)、参数更新 (`step`)。
5. 统计平均 Loss 和准确率（Accuracy）。

## 二、 总结与优势

这段代码是一个精简而经典的 **Parameter-Efficient Fine-Tuning (PEFT)** 教学范例。它的主要优势体现在：

1. **显存与存储效率高**：全量微调 BERT 需要更新全部约 1.1 亿个参数；而使用 Adapter 后，绝大部分 BERT 参数被冻结，实际参与训练的仅有插入的 Adapter 模块和分类头，参数量通常不到总量的 5% 左右。
2. **可扩展性强**：如果需要适应多个不同的下游任务，只需训练并保存不同任务对应的轻量级 Adapter 权重，而巨大的基础 BERT 模型可以共享，极大地节省了存储空间。
